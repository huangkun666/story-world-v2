## 安装测试分支

**已有正式版的用户，请先在插件中完整导出世界备份，并保存好聊天与原始资料，再切换版本。不要同时安装正式版和测试版。** 世界数据保存在当前浏览器的本地数据库中；下载代码 ZIP 不会备份这些数据。

普通用户不需要运行构建、安装 npm 依赖或额外世界服务器。插件使用自己的模型 API 通道，安装后仍需配置地址、密钥和模型；不会自动套用酒馆主模型设置。

在 SillyTavern 的“扩展 → 安装扩展”中填写：

- 仓库 URL：`https://github.com/huangkun666/story-world-v2`
- Branch：`codex/preview-2026-10-23`

如果安装界面没有 Branch 输入，请使用下方 Git 方式，避免误装默认分支。ST 的 Git 安装与更新需要宿主机器已安装 Git。

手动安装：进入你的 SillyTavern 第三方扩展目录，在没有同名安装目录的情况下运行：

```bash
git clone --branch codex/preview-2026-10-23 --single-branch https://github.com/huangkun666/story-world-v2.git story-world-v2
```

已有 Git 安装请先完成备份，在扩展管理中使用“切换分支”，选择本测试分支；不要重复安装到同名目录。若列表没有显示测试分支，取消后重新打开“切换分支”，宿主会重新获取可用分支。

也可在 GitHub 切换到本测试分支后下载 ZIP。解压后的插件根目录必须改名为 **`story-world-v2`**，其中直接包含 `manifest.json` 和 `settings.html`，再放入第三方扩展目录。ZIP 安装没有 Git 更新能力；后续需要重新下载对应分支，替换前保留备份。

安装或更新后硬刷新页面（桌面可用 Ctrl+Shift+R）。测试分支保留既有自动更新声明；Git 安装应确认当前跟踪测试分支，更新时获取该分支后续内容，ZIP 安装无法使用 Git 更新。

## 第一次使用

打开插件，配置模型通道，选择当前聊天可读的角色卡与世界书资料，然后点“开始新世界”。当前流程为：

**前置读取字段、设定与地点 → 确认字段 → 分包 A/B 抽象 → 统一实体身份 → 必要的相关候选整理 → 保存世界与玩家初始化。**

中途出现字段窗口时，确认后点“确认字段并继续”。等待界面明确提示世界保存完成，再开始使用。详细操作见[社区使用指南](docs/community-guide.md)。

## 测试范围与已知限制

本预览通过了离线回归，以及 Chrome 桌面、窄屏模拟和 Edge 桌面的受控浏览器流程验证。测试使用合成资料和固定模型回应，**真实模型调用为零**；不代表真实模型输出质量、任意服务商兼容或全部设备验收通过。

- 模型可能漏字段、输出不完整或达到服务商限额；不保证绝无截断。请按实际模型能力调整输出上限、超时与进包字符等设置，错误与恢复提示见调试页。
- 抽象、整理与世界推进会调用你配置的模型，产生耗时及可能的费用。停止页面任务不等于服务商停止处理或免计费。
- 大世界、超长属性与长期运行仍可能带来明显内存压力；手机真机、Firefox/WebKit 与实际宿主的全部扩展组合尚未完成验证。
- 世界保存在浏览器 IndexedDB，按访问地址的 origin 隔离；换设备、浏览器、地址或清除网站数据前，必须完整导出并在新环境导入，不提供自动同步保证。
- 快照恢复建立世界分支，不会同时回退酒馆聊天。模型抽象是否忠实原文仍需实际使用判断，格式通过不表示内容完全正确。

反馈请使用[简洁模板](docs/community-faq.md#如何反馈)，不要公开密钥、完整私人聊天、世界书或未经检查的调试报告。
