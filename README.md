# 观棋窗口 · Story World v2

> 世界的眼睛 · Story World v2

一个跑在 SillyTavern 里的**活世界引擎**。你每推进一步 RP，世界就演化一步：各方势力与角色按自己的处境和盘算行动——结盟、背叛、谋划、冲突——事件从他们的行动里长出来，带着原因和后果。

**这里没有"主角"。** 只有一枚由你控制的棋子，它的分量由客观状态算出：底层小民时世界的浪潮绕它而过，手握重权时它的一步能改棋局走向。你用两个口子与它相处——**RP 对话是你落子的手，观棋窗口是你观棋的眼**。

装上之后你会得到一扇窗：谁在谋划什么、哪件事正在落子、这个世界刚才发生了什么、它接下来想往哪走。而 RP 那一侧照常演你的戏，世界在幕后按自己的账本推进。

> **这是我第一次写酒馆插件，它还很粗糙、远不是成品。** 骨架搭出来了：世界有账、每轮推进、面板能看。但**完整的记忆引擎还没做出来**，界面是新手水平，内部接口也还会动。我把它发出来是想让人用上，也是想听人骂——哪里别扭、哪里对不上，请直接说。
>
> 另外：它接的是"世界自己会转"这件事本身，不是某一本书的插件——**任意角色卡 / 世界书都能装**。不同书的抽取效果差异很大，装之前请先读「已知限制」。

## 它做什么（三句话）

1. **世界有自己的账本。** 势力与角色、他们各自在办的事、已经发生的事与它的来龙去脉——全部记在这份账上，随每一轮对话推进而更新。账是唯一真源：面板上看到的每个数字都从账上现算，没有一处是写死的。
2. **事件必须有源。** 一件事要么由某方的行动推进出来，要么由某处处境逼出来，要么是别的事的下游。**没来路的事不会入账**——所以这个世界不会突然冒出无因的转折，也不会把上一条线凭空冻住。
3. **引擎是账房和史官，不是作者。** 它记账、守连续性、守身份、管在办事项的生死、算能见度；它**不裁胜负、不算战力、不给谁打分、不发明事实**。写场景、写台词、提议"接下来发生什么"，是模型的事。

## 安装

两种方式，任选其一。**两个前提先说在前面**：

- ⚠️ **你的机器上要装了 Git。** ST 的安装按钮背后就是 `git clone`，**ST 自己不会替你下载 Git**（这一点 ST 自己的安装页也写着）。
  没装的话先装 [git-scm.com](https://git-scm.com/downloads)，装完重启一次 ST。
- **目录名必须是 `story-world-v2`**——下面两种方式都**天然满足**这一条，只有 **zip 解压**要注意（原因见下）。

### 方式一：ST 内建安装（推荐）

在 ST 里打开 **扩展 → 安装扩展（Install extension）**，粘贴本仓库地址：

```
https://github.com/huangkun666/story-world-v2
```

安装完成后 **硬刷新页面（Ctrl+Shift+R）**。

### 方式二：手动克隆

```bash
cd <你的SillyTavern>/public/scripts/extensions/third-party
git clone https://github.com/huangkun666/story-world-v2.git story-world-v2
```

同样要 **硬刷新（Ctrl+Shift+R）**。

### ⚠️ 目录名必须是 `story-world-v2` —— 这一条不是洁癖（只针对 zip 解压）

**走上面两种方式的人可以跳过这一节**：内建安装的目录名由 ST 从仓库地址推导（本仓推导出来正是 `story-world-v2`），手动 clone 那条命令也显式写了目录名。**这一条真正针对的是 zip 解压**。

面板的窗口模板是用**固定路径**向 ST 取的：

```js
ctx.renderExtensionTemplateAsync('third-party/story-world-v2', 'settings')
```

也就是说，ST 会到 `third-party/story-world-v2/settings.html` 去取这个面板的骨架。**目录名不对（例如从 zip 解压出来的 `story-world-v2-main`），面板会退化成一个小回退窗**——能打开，但没有页签、没有内容。所以：

- `git clone` 时**显式指定目录名** `story-world-v2`（方式二那条命令已经带了）；
- 如果你是从 GitHub 的 **Code → Download ZIP** 装的，解压出来的文件夹通常带 `-main` 后缀，**请把它改名成 `story-world-v2`**；
- 装完在 ST 的扩展列表里确认一下这条扩展的目录名。

### 关于自动更新

本扩展声明了 `auto_update`。ST 的更新按钮做的是"在**这个插件目录里** `git pull` 它自己的远端"——所以：

- 用**方式一 / 方式二**（都是真正的 git clone）装的：**更新按钮可用**；
- 用 **zip 下载**装的：那个目录里没有 `.git`，更新会报错（不影响使用，更新时重新下载覆盖即可）。

装完记得看面板右下角的 `构建 <版本号>` 那行——**硬刷新之后它变了，才说明新版本真的载入了**（浏览器缓存是老朋友）。

## 第一次使用

1. **打开窗口**：点 ST 输入栏左边的**魔杖图标** → 菜单里选「**观棋窗口**」。窗口可用 `Esc` 关闭。
2. **填模型通道**：进「**设置**」页，填 **服务地址 / 密钥 / 世界模型**。密钥只在本机读取，不落库、不打印。
   - 世界推进用的是**你填的这条通道**，可以和你聊天用的模型是同一个，也可以是另一个（推荐用长上下文、听话的模型）。
3. **调单轮上限（可选，但建议看一眼）**：同一个页面有「**单轮超时（秒）**」与「**单轮输出上限（token）**」两个框。
   这两个数**因模型而异**（推理型模型"想"的部分与正文**共享**这一份预算：填小了正文会被截断，填大了网关会报错），
   插件不替你探测你的模型/网关给到多少，所以**由你填**；留空/不填就用出厂值（120 秒 / 16384）。
   - 你扮演的**名字**取自 ST 的人设名（`name1`），不需要在这里写；世界也不会替你演你的棋子。
4. **按「✨ 开始新世界」**。它会去读**角色卡 + 世界书**（自动合订），抽出这个世界的设定与名号，然后建起第一份账。
   - 这一步会真的调用模型，**大书要跑几分钟**（面板状态栏会逐段报进度；控制台里每段的字符数与耗时都有）。
   - **已经有世界时它会先问你**：确认了才会覆盖旧的。
5. **开总闸**：进「**参数**」页，把第一张卡「**插件总闸 · 自动推进**」打开。此后**每收一条 RP 回复，世界自动推进一轮**。
   - 总闸**默认是关的**：装上一个插件就让它自动跑，不礼貌。你想纯手动观棋也行——「设置」页的「▶ 推进一轮」**关着总闸也能按**。

## 日常使用

| 你想做的事 | 去哪 |
|---|---|
| 看世界现在什么样 | 「**观棋**」页：时局、在办的事、动态流、各方位置速览 |
| 看某件事的来龙去脉 | 「**编年**」→ 点事件上的「？」，展开因果链（上游怎么来的、下游牵动了谁） |
| 看很久以前的事 | 「**大事纪·旧卷**」：编年攒到阈值会自动入卷，可阅卷 |
| 看某个人/势力 | 「**角色与势力**」页：按势力/状态筛、看影响力、看它在办什么 |
| 看这个世界的规矩从哪来 | 「**设定**」页：书指纹、力量谱系、法则、社会格局、史略；每条都带你回原文条目 |
| 改世界参数 | 「**参数**」页（见下节） |
| 想反悔一步 | 「**快照**」页：每步自动留档，**保留最近 15 步**，选中即回退 |
| 换书 / 书变了 | 不用手动重抽：书指纹一变，世界会重新识别设定（已定的设定不会自己飘） |

**手动补推**：「设置」页或观棋页的「**推进一轮**」。演算失败时**世界原样不动**，状态栏会报错，可以重试。

**导入导出**：「设置」页可**导出整聊天**（含世界账，带校验）与**导入恢复**。

## 八页一览

| 页签 | 里面是什么 |
|---|---|
| **观棋** | 世界的正面：当前时局、在办的大事、此刻各方在哪、一条持续更新的动态流 |
| **编年** | 按轮次的史卷，五道筛（谋划 / 大事 / 牵动 / 暗处 / 时局）+ 因果链珠链视图 |
| **大事纪·旧卷** | 里程碑与已入卷的旧账，可点开阅卷 |
| **角色与势力** | 在册实体：影响力、四维、状态徽；按势力/状态/范围筛选与分页 |
| **设定** | 从书里抽出来的设定全文 + **每条的原文出处**；刻度（力量谱系/概念表）与法则按类分段，**并如实标明哪些每轮真的进了模型眼前** |
| **参数** | 世界参数（玩家定档、引擎照抄）+ 世界尺度 7 个旋钮 + 开关；带**撤销** |
| **快照** | 每步留档、保留 15 步、一键回退；**只回世界账，不动你的对话** |
| **设置** | 世界设定来源、模型通道（地址/密钥/模型 + **单轮超时与输出上限**）、旧卷与存储、导入导出、开始新世界 / 推进一轮 |

## 世界参数

**世界参数**是"玩家定档、引擎照抄"的档位：**天时**（大灾 / 失调 / 平常 / 风调雨顺）与**张力推手**（沉寂 / 平缓 / 暗涌 / 紧绷）由你选；**乱象**这类**结果**由引擎每轮从账上真发生的事推出来，你改不了它（面板也不会假装能改）。没定的档位显示「未定」，留空就是留空。

**世界尺度**是 7 个直接填数字的旋钮，**没有上限白名单**（填 ≥1 的整数即可）：

| 旋钮 | 出厂 | 它管什么 |
|---|---|---|
| 每轮递几条线 | 3 | 一轮里同时推进的线有几条（实测 3 → 每轮 2.25 条、6 → 6.00 条落账） |
| 每轮最多几件事件 | 6 | 一轮最多落账几件新事（真账 59 轮里一轮最多 4 件，从未撞到） |
| 每轮最多新起几件大计 | 3 | 一轮最多"新开"几件大事；**这是三道上限里最先判的一道** |
| 每轮最多入局几个新人 | 1 | 一轮最多让几个新面孔进世界 |
| 每轮给几个"冷门人"点名机会 | 12 | 名册之外额外递一份小名单（长期没轮到的人），让他们有机会自己立线 |
| 同时最多几件大计 | 15 | 在办大事的并发上限（它们分出来的小事不占名额） |
| 同时在办总数上限 | 20 | 大事 + 小事加起来的并发上限 |

> **想让一轮里多长几件事**：「每轮最多新起几件大计」和「每轮递几条线」要**一起抬**——前者是最先判的那道闸，它顶住了，后面几道连被检查的机会都没有。

**开关**：**插件总闸 · 自动推进**（关掉=插件不再自动生效，手动推进仍可用）、**写进记忆插件**（把世界状态与大事**逐字原话**投进「柚月の记忆」，不经过任何模型）。

参数改错了可以按参数页的「**撤销**」。参数改动**不会**触发快照（只有世界在动才拍）。

## 已知限制

> 这是**预览版**，下面这些是现在就存在的边界——装之前请读完前四条，它们决定"它适不适合你"。

- **要长上下文模型。** 每一轮的输入是"世界账 + 名册 + 设定锚 + 上一轮的事"，几十 k 字符量级（单轮包预算 30k token）；大书更甚。小上下文模型会降质。
- **每轮有成本、有耗时。** 一轮是一次真实的主调用（超时与输出上限都在面板「设置」页**由你填**，出厂 120 秒 / 16384 token）；抽取那一步更慢，大书可能要好几分钟。
- **📌 装上之后 RP 表现不会变——这是设计，不是没生效。** 三个注入开关（`让聊天模型按标签写行动` / `把名号表递进对话` / `把上轮世界动向递进对话`）**默认全关**，插件默认不看也不动你的对话；你要让它参一脚，得自己去「设置」页把它们打开。
  打开之后聊天模型拿到的也只是"名号对照 + 世界动向"这一点点，**不是账的全貌**；而且"世界动向"那段读的是**上一轮结算出来的**，**永远晚一轮**。
- **📌 它没有取代世界书的权威性，两边可能对不上。** 聊天模型仍然照常读你的世界书（那是 ST 在组装提示词时塞的，与插件无关），而插件又**从同一本书里**抽出设定、建起第二套账——**两套真相并行，没有任何一处对账**。
  插件**从不写你的世界书**（只读），所以分歧不是"插件把书改坏了"，而是两边各自独立地演；书改了也**不会自动重抽**（书指纹变了才会重新识别设定）。
- **抽取效果依书而异。** 有的书把设定写成条目（抽得干净），有的书把一切写进叙事（抽得少）。**抽不到就空着**——世界不会拿猜测值填满面板。
- **书的形态差异会影响"设定"页的丰富度**，但**不影响引擎照常运转**：任意编排、任意语言、有无关键词的世界书，机制都不会抛错或卡住链路。
- **记忆插件集成是可选的，而且只做了一半。** 打开「写进记忆插件」后，世界状态与大事会**逐字原话**投进「柚月の记忆」（不经过任何模型）；没装那个插件就**静默跳过**，面板不会告诉你它没投上。**完整的记忆引擎还没做出来**——现在只有这一座桥。
- **这是预览版：内部接口还会动。** 升级前建议先在「设置」页**导出一次**（带校验）。判据多不等于没问题——1078 条判据保的是"这套账算得对"，**保不了"你看着舒服"**。
- **只在 SillyTavern 1.15.0 上验过。**
- **快照只回世界账、不回对话。** 回退一步之后，面板回到第 N 轮而对话还在第 N+5 轮——**没有统一的撤销**。
- **位置是自由文本。** 不建地名册、不做字面合并，账上没有真地点时如实写「未明」；**地理位置一致性不做保证**。
- **装完不要用普通刷新判版本。** 面板是静态副本，请用 **Ctrl+Shift+R**，并以页脚的 `构建 …` 那行为准。

## 它没做什么（诚实交代）

这一条是**设计纪律**，不是免责声明：

- **不替你做决定。** 引擎从不写"你"的行动——你的行动只从你的对话里提取；世界只写**世界对你的影响**。
- **不裁胜负、不打分。** 没有"主角战力值"这种东西。书里怎么说的（`T9渡劫巅峰` 这类原话）就照抄显示，**不换算成数字**，因为拿精确的外壳装模糊的内容，会让"编的"看起来像"算的"。
- **不用词表猜书里的语义。** "这是势力还是角色"如果靠关键词表判断，换一本书就废——这个项目明令禁止这种过拟合写法。
- **不发明事实。** 抽不出来、算不出来、账上查不到的东西一律留空或标「未查」，**绝不用占位值/默认值凑**。
- **面板上的数字必须现算。** 凡是印在玩家眼前的数，都从真源现读——写死的字面量迟早变成谎话。

## 运行测试与自检

**零依赖、无构建步骤**——`git clone` 下来直接就能跑，不需要 `npm install`。**在插件目录里**执行：

```bash
node --test                # 全量测试（本版：1078 / 1078，约 3 秒）
node demo/smoke-demo.js    # 合成冒烟：50 轮曲线 + 断言（终态 8231 字节 · PASS · 警告 0）
```

两条都是**零 token、不需要密钥**的（冒烟跑的是合成世界，不打模型）。`demo/` 下还有一批开发期探针（真账只读体检、跨书通用性审计、状态总览等），那些多半需要**真实世界书目录或世界账路径**作参数——它们不是给玩家跑的，用之前先读脚本头部的用法注释。

> 注意：`node --test` **要在插件目录里**跑。

## 给开发者：结构

```
manifest.json      ST 扩展清单（id / 版本 / 入口 js+css）
settings.html      面板骨架模板（**目录名固定**，见「安装」）
web/index.js       浏览器侧：面板打开/渲染、动作总线、事件挂钩、参数存储、快照库
web/style.css      面板样式
src/               引擎（纯 ESM）：抽取 / 打包 / 校验 / 结算 / 存储 / 快照 / 渲染 / 撤销栈…全部纯函数优先、可单测
test/              node:test 全量测试
demo/              只读探针与演示（冒烟、状态总览、通用性审计、真账实测脚本）
```

- **引擎零外部依赖**：`src/` 与 `web/` 里没有一条裸模块 import，也没有 `node_modules` 与构建步骤——所以它不可能因为依赖漂移而坏掉。
- **浏览器侧零 Node 内建**：有一条测试（`test/browser-compat.test.js`）静态扫描整个浏览器面，任何 `require` / `node:` / `process` / `Buffer` 当场红。
- **真源只有一处**：同一件事两处实现是这个项目最贵的 bug 类型，凡是"面板也要用"的口径，都从生产函数 import，而不是在渲染层再推一遍。
