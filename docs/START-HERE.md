## 0. 三十秒版：这台东西是什么

一个跑在 SillyTavern 里的**活世界引擎**。你每推进一步 RP，世界演化一步：势力与角色按自己的盘算行动，事件从行动里长出来、带因果。

**没有"主角"**——只有一枚玩家棋子，分量由客观状态算出。你通过两个口子与它相处：**RP 对话是落子的手，观棋窗口是观棋的眼**。

**三者分工（承重墙，别越界）**：

| 谁 | 干什么 | 不干什么 |
|---|---|---|
| **世界书** | 作者的原稿，只读 | 一个字不改 |
| **引擎** | **账房 + 史官**：记账、守连续性、守身份、管盘算生命周期、算能见度 | **不裁胜负、不算战力、不给实体打分、不发明事实** |
| **LLM** | 读者 + 提议者 + 笔：每回合提议"接下来发生什么"，把账本写成场景 | **不记账**（写账只有引擎能做） |

## 2. 三条不可越的线（今天踩过，别重踩）

1. **不许把书里的词换算成数。** 书里的说法**照抄成文本**（实体 `实力` = 「T9渡劫巅峰」，据书）。引擎不换算、不进公式、不排序、不比较。四维浮点（兵力/权位/人脉/耳目）就是因为**没法精确表示 + 手拍值让"编的"像"算的"**被整体删除的，别再请回来。
2. **空着就是空着。** 没依据就不填值，不许用默认值/占位值冒充客观。缺数据只许记「未加载」，**绝不用空值反推"书里没有"**。
3. **改判据 = 改承重墙。** 判据要改，先出数据、再拍板、再动手；不许"顺手加个小功能"。

## 3. 动手前的规矩（四条）

1. **没命令不动代码**；机制新增**两段式**：先细案 → 用户拍板 → 再实施。
2. **数字先报批**：上限/阈值/系数都是**提案态**，先出曲线再定案。
3. **改码三件事连着做：测试 → 部署 → 台账**。缺一件 = 变更没完成。
4. **先 read 再 edit**；改哪层要声明（契约层/引擎层/渲染层/编排层，见 `dev-process.md` §9）。
