# Rejected Round Fixes Implementation Plan

**Goal:** 修复模型非法提议导致第一轮整轮空转、轮数仍推进且调试台没有拒因的问题。

**Architecture:** 沿用逐条净化和整体复核；使用现有 schema 检查每条提议的形状，保留合法提议。取消非法输出的空步兜底；没有可用提议或仍无法通过校验就失败，不保存、不推进。合法的安静步骤保留既有语义。前置查书独立保存完成后才隔离演算副本，失败不泄漏本轮正文事实或已展示标记。新事件删除按原始位次确认依赖，丢掉坏事件的依赖，幸存依赖映射到实际发号，不修写故事内容。演算失败和部分降级进入既有调试记录器。

**Tech Stack:** 原生 JavaScript ESM，Node test，既有浏览器诊断记录器；零依赖。

## 授权与范围
