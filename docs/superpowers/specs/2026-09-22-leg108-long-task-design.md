## 0. 一句话

面板上有三件事**要跑几十秒到几十分钟**（只重抽设定 / 只抽刻度 / 采用草稿），而它们跑起来
**界面上没有任何"正在跑"的样子**——玩家以为没点上，**再点一次就发出去第二串模型调用**（白等一份时间）。

## 2. 治法

**新模块 `web/long-task.js`**（顶层零 DOM ⇒ Node 里可直接 import，与 `web/action-router.js` 同一把尺）：

```js
createLongTask({ doc, setStatus }) → { wrap(action, label, fn), running(action) }
//   wrap：把一段长活儿包成"带闸 + 看得见"的处理器，返回一个与原函数**同签名**的函数
```

`wrap` 做四件事（一件都不许多做）：

1. **闸**：同一个 `action` 已在跑 ⇒ **立刻返回、绝不并发**（口径照 `createTickQueue` 的 busy）。
2. **出声**：被挡住时状态条写一句人话——「⏳ 上一次还在跑（<label>）——这一下没有重复发」。
3. **看得见**：把面板上那枚按钮（`[data-action="<action>"]`）置 `disabled` 并把文字改成「正在跑…」，
   跑完/抛错都**还原**（原文字原样存下来，不许自己编一个）。
   ★**如实说清它的边界**：长活儿跑的时候面板会重绘，重绘会把那个按钮节点换掉 ⇒
   "灰掉"是**尽力而为**、不是保证；**真正的保证是第 1 条那道闸**（它不依赖 DOM）。
4. **收尾**：`try/finally` 释放闸（抛错也必须释放，否则那一格被永久挡住——照忙闩那条先例）。

**接线（三处，每处只改"注册那一行"与"结尾那一行"）**：

```js
bus['extract-scales'] = longTask.wrap('extract-scales', '只抽刻度', async () => { …原主体一字不改… });
```

★**行数账（`web/index.js` 现 3096/3100，余量只有 4 行）**：这种包法**把 `= async () => {` 换成
`= longTask.wrap('…', '…', async () => {`、把结尾 `};` 换成 `});`** ⇒ **净增 0 行**（每处都是同一行内改）。
模块本身**没有行锁**，注释与解释一律写在那里。

## 3. 判据（新文件 `test/long-task.test.js`）

| # | 判据 | 抓什么 |
|---|---|---|
| ① | **闸真的挡**：第一次调用在飞时，第二次调用**立即返回**且内层函数只被调了 **1** 次 | 连点两下 = 两串调用（本笔的正事） |
| ② | ★**反向对照**：跑完之后再调 ⇒ **必须放行**（内层被调 2 次） | 防"闸一开就再也打不开"（那会把功能锁死） |
| ③ | ★**抛错也要放闸**：内层抛错 ⇒ 闸释放、错误照常往上抛（不许吞） | 防"一次失败把那一格永久挡住" |
| ④ | **被挡住要出声**：状态条收到一句人话，且**含"没有重复发"** | 与 leg108 刚立的 B5 同一条口径 |
| ⑤ | **按钮灰掉 + 文字改成"正在跑…"**，跑完**原样还原**（原文字逐字相同） | 看得见（并如实登记"重绘会把它换掉，真正的保证是闸"） |
| ⑥ | **接线三处**：三个动作都真的被 `wrap` 包了（源码锁，精确到那三个字面量） | 防"模块写好了没人用" |

## 5. 风险与回退

| 风险 | 处置 |
|---|---|
| 包装改了原 handler 的行为 | `wrap` 只加闸与显示，**主体一字不改**；判据 ① 断言"内层被调几次" |
| 按钮还原写错（还原成自己编的文字） | 判据 ⑤ 要求**原文字逐字相同**；找不到按钮就**什么都不做**（零阻塞） |
| 重绘把按钮换掉 ⇒ 玩家看不到"正在跑" | **如实登记**：那是尽力而为；真正的保证是闸（不依赖 DOM） |
| 出事 | 一笔独立提交；回退它只丢"看得见"，**闸那部分也不留残骸**（`bus[…]` 那一行改回原样即可） |
