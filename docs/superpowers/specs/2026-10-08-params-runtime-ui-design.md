# 参数页运行与注入布局

用户要求：“把参数页的运行和注入 ui改一下我感觉很乱而且如果我是这个插件的新手的话都不知道这些参数是干嘛的”。用户已选择“按这个布局改”。

## 已确认的布局

“运行与注入”按四块排列：自动运行、聊天如何影响世界、聊天模型能看到什么、往事怎么找。

- 自动运行：保留自动推进开关；显示当前状态，并说明关闭后仍可手动推进，以及它与下方聊天资料开关分别控制什么。
- 聊天如何影响世界：标签指令开关与一轮最多递多少条行动放在一起，说明标签用于把聊天中的行动和结果交给世界模型处理。关闭指令不意味着删除已有标签或停止其他资料注入。
- 聊天模型能看到什么：名号表、上轮世界动向、账上往事三项开关，各有贴近控件的一句用途与关闭后的影响。
- 往事怎么找：常用项为检索上下文深度与往事注入多少字，显示作用和调大/调小的影响。向量检索的相似度阈值、最大召回条数，以及正文黑白名单收进原生 details 高级设置。

参数原名与原值保留。所有控件仍使用现有 ID、data-action、data-param、data-settings、data-settings-text 和 data-inject-switch 接线；不新增存储键、默认值、数值上限、模型调用或真实数据迁移。

实施中的真实表单验证发现两处原有保存缺口：往事字数键没有登记进数字校验，相似度阈值没有调用已有的小数校验。补齐这两处接线，沿用输入框已有的合法范围和现有的小数归一，不增加数值限制或改变检索规则；补充真实表单委托的回归测试。

每项用途直接可见；较长例子可折叠。说明使用普通中文，避免“信封”“总闸”等需要另作解释的说法。保留最后一次注入读数，放在资料开关附近，不增加排查用读数。
