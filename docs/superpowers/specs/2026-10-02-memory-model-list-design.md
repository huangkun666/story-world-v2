用户要求给记忆通道增加获取模型列表，并去掉「量一批几行」按钮。

沿用世界模型通道的交互：用记忆通道自己的地址和密钥请求 `/models`，展示服务端实际返回的模型；用户点击后仅写入 `embedModel`，保留手动输入。获取列表不要求先填模型号。获取失败显示原因，不改已选模型。

列表和结果就地更新，不重建输入控件；刷新设置区域后列表仍能显示。模型名称按既有规则转义。两条通道的地址、密钥、选中项和列表状态各自独立。

删除手动容量探测的按钮、说明、动作和无调用者的探测函数。保留已有自动缩批重试；测试连通继续用最小请求读取维度。

验证真实 hub 与动作装配：独立请求地址和密钥、未填模型时获取、点击回填与持久化、失败不覆盖模型、HTML 转义、重绘状态，以及自动缩批照常运行。全量判据、冒烟和文档守门通过后同步本机预览。
