# 手机操作、可选向量、抽象来源与调试台设计

用户已于2026-10-03批准此前聊天方案并要求直接开工，补充快照恢复隔离；允许多次调用本机dsh分担工作。不再要求第二次批准。新交接仅写F盘docs。

手机页签独占一行；标题栏的操作菜单包含推进一轮和开始新世界。桌面沿用常驻操作按钮。菜单复用原动作路由，关闭、键盘及点击外部可收起。减少重复解释和设计说明，保留必要状态、错误和操作风险。

向量增加独立持久开关，缺省及缺失设置均关闭。地址/密钥/模型填齐不构成开启。关闭时后台补嵌、两条召回链不发向量请求，注入缓存失效，关键词使用完整原有容量。测试连接和取模型属于用户显式操作，不隐式开启通道。开启后立即按批次补齐全部窗口外遗漏，运行失败仍可使用关键词。保留逐条完成ID，并记录连续完成到哪一轮；只有向量和进度落盘成功才推进。当前轮次和窗口起点现算；最近窗口全文递送。暂停、刷新、部分失败可继续，旧卷同样参与补齐。

快照恢复必须取消/废弃在途向量结果，清除注入预取，重新校验索引来源和连续进度。候选必须在当前世界有效历史里，正文变化或同ID重用不能沿用旧向量。恢复后的未来旧卷和分支必须隔离；旧快照无法证实的历史不能作为当前记忆。世界/聊天/模型切换同样隔离，不改变原快照与世界书。

抽象来源设置提供默认来源和自选条目，按书分组、搜索、批量选择、正文和实际输入预览；选择保存在插件，原书不改。自选保留现有技术清理。选择统一约束正文、题名、声明补入、起根、实体补查、原文属性补缺、重抽、指纹/缓存。默认模式保留原行为，存量世界不自动重建；变化由主动重抽生效。

设置增加调试子页签：当前构建/轮次/向量开关及补齐进度，按模块和级别过滤的最近日志，模型请求耗时/HTTP状态/错误、检索和注入统计、存储和快照记录。支持复制和下载报告，密钥/Authorization脱敏；完整模型文本默认不记录，详细调试由用户明确打开。不截获其他插件的console。记录有容量边界且只保存在内存。

实施保持零依赖、模块顶层无DOM、web/index.js少于3100行，新增职责独立模块。先写涉及开关/缓存/缺口/快照/选择的实际数据流回归并观察失败；生产UI用浏览器验证手机与桌面。全量测试、冒烟、知识索引、文档守门通过后导出本机预览并核对跟踪文件；不发布远端。
