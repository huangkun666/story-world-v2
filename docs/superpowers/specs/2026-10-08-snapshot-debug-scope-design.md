# 快照重复项与诊断范围收口

日期：2026-10-08（Asia/Shanghai）。用户要求只监听本插件，快照只显示差异数量，并明确为何同轮有完整/增量两份。后续强调：相同恢复结果无需显示两份。当前读数见 `STATE.md` §1。

完整和增量只是同一个回档机制的存储表示，恢复自动还原；列表不再展示类型、大小、原始编号、具体差异和锚点说明。已有记录仍用 `restoreFrom` 还原，然后按世界内容及恢复用历史校验 `known` 合并相同状态；对象键顺序不构成差异。合并时保留已打 `current` 标记的原目标，否则保留较新的目标，不写库、不删锚点。不同轮的进度保留；同轮确有不同状态时按保存先后显示序号、最新标记及本地保存时刻。只显示与前一份不同状态相比的变更字段数量；首份没有基准，数量用横线。坏记录明确不可读取，不参与等价合并。

数量按结构字段的新增、删除和变更计数，数组新增/移除一项各计一处；不设显示截断阈值。不能仅按轮数合并，否则会隐藏同轮确实不同的回档结果。底层增量和保留策略继续工作，不需要用户选择存储形式。

诊断采集仅接收本插件的明确日志前缀、错误首个来源文件及插件自身资源 URL。宿主和其他扩展、未知来源、错误堆栈里仅在后续出现插件调用者的情况均不自动采集。全局异常来源判据改为严格归属；明确由本插件调用的 `reportTrouble` 和原有操作记录仍保留。控制台原方法、参数、接收者、返回值、脱敏及实时刷新继续保留，不转发或阻止宿主原生异常。

验证同状态 full/delta 合并及原始目标恢复、当前标记、不相邻重复、历史校验区别、字段数、坏链和对象键顺序；验证截图宿主警告与图片失败不入调试台，本插件日志/异常/资源保留且不重复。全量、冒烟、桌面和窄屏合成浏览器、文档守门及本地安装字节核对。所有新文件住 F 盘，不改真实用户账、聊天、世界书及快照，不调用真实模型，不推送。
