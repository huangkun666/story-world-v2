## 1. 全页状态词统一（这一笔的第二个实质改动）

真账渲染当场照出**同一页有三种说法**：

| 位置 | 原来写的 |
|---|---|
| 统计行 | `13 条还开着` |
| 区块标题 | `还开着的线（13）` |
| 线头那枚徽 | `还在往下长` |

⇒ 读者得自己换算（"还开着 13" 与 "11 还在往下长 + 2 挂着没了结"是同一件事的两种说法）。
**定稿：全页只认徽那三个词**——**还在往下长 / 挂着没了结 / 已收场**；**"还开着"整页退场**。

改后真账页头（B 局 88 件）：

```
18 条线 · 11 还在往下长 · 2 挂着没了结 · 5 已收场 · 88 件事 · 3 件零散的事
```

★纪律：**同一个概念，全页一套词**（换词就是让读者自己换算，那是把活儿推给用户）。
