## 1. ★★★ 交付

### 1.1 窗口按线裁（用户令①）

**口径**（leg160 交接 §5.1 逐字，用户当时就点过头）：

> **窗口管的是"看哪几条线"，不管"线里印几件"**——一条线只要有一件落在窗口内，它整条都讲
> （起头→过程→结果）；**只有整条线一件都不在窗口里，它才不上这一页**。

**代码原来是什么样**（`src/panorama.js`，leg163 到今天逐字相同的那一行）：

```js
const events = pool.filter(inWindow);   // ← 先按事件裁……
// ……再拿裁剩的事件去并线（连通分量）
```

**本笔改成两步**：

```js
const events = pool;                    // ① 分组用全量（热层 ＋ 归档里留了来路的那批）
// …（并线、求连通分量，一个字没改）
if (windowFrom != null) {               // ② 分完组，按线裁：
    for (const [root, members] of [...groups]) {
        if (members.some((id) => inWindow(evById.get(String(id))))) continue;
        groups.delete(root);            //    整组成员一件都不在窗口内 ⇒ 这条线不上这一页
        threadsOutOfWindow += 1;
    }
}
```

★**`windowFrom == null`（不传窗口 ⇒ 老调用方只读热层）时一条都不裁**——那一路**逐字节同旧**。
★新增一格读数 `stats.threadsOutOfWindow`（"整条线都不在窗口里、因而没上这一页的线数"）：
**不印给玩家**（玩家要看的是"这世界发生了什么事"，"裁掉了几条"是我们的口径），只喂判据与取证。
★`stats.events` 那一格的口径跟着改成"**这一屏真印出来几件**"（＝留下那些线的全部成员，含窗口外那几件）——
它以前量的是"窗口里恰好有几件"，那是**窗口**，不是**这一页**。
