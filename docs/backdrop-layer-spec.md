## 0. 人话版：这会怎么样

世界的"背景画布"现在是一张白纸上的一个死常数（张力恒 0.5）。大势层把它换成三样活东西：**设定的根**（世界书里抽出来的本体设定——力量分层、法则、社会、历史，抽一次管到书变为止，靠书指纹认账）；**大势的形**（结构性张力：极、方向、强度——世界现在在拧什么劲、朝哪拧、拧多狠，模型只能从书里提，引擎只按算的演化）；**环境的动**（动态环境量——引擎小步推，每几 tick 变一点，越界就落成"处境事件"上桌：醉话说漏嘴、劳役征发——这就是熵泵，世界不冷却）。冻结的归冻结（书不变不重抽），演化的归演化（引擎推、事件可改、**模型不可改**），玩家初始属性也由抽象产物自动注入。你看到的世界：张力会真的动、处境会自己冒出来、背景不再是死水。

## 1. 目标与验收判据

**目标**：设定注入缺口闭合——张力结构化 + 抽象管线复用 + 冻结/演化分离 + 玩家 attrs 自动注入 + 熵泵摩擦制造；大势仅两来源（世界书提取、盘算浪尖派生），模型不可发明第三来源。

| # | 判据 | 断言形态 |
|---|---|---|
| A-1 | **张力结构入账** | SSOT 由 `context.tension:number`（静态）升级为可选 `context.setting`：`frozen`（抽取产物+书指纹）+ `dynamic`（`tension:{polarity,direction,intensity}` + `env` 环境量）；**旧世界（仅 tension 数字）合法**——缺省形状兼容断言；黄金三锁不破 |
| A-2 | **只提取不创作** | 设定事实库每条可溯源（携带来源书条目引用或指纹）；抽取产物零创作句（延续 v1 2026-08-28 拍板：**无数量/长度约束，防编造靠纪律不靠量制**） |
| A-3 | **书指纹缓存** | 指纹不变不重抽：同指纹两次初始化只产生一次抽取调用（缓存命中断言）；书内容一变指纹即变、自动失效重抽；缓存 LRU 有界 |
| A-4 | **冻结/演化分离** | 冻结层引擎只读，涉冻结字段的世界步（actions/stateChanges/newEvents 引用）一律校验拒绝；演化层引擎小步推、事件可改（联动状态源事件）、模型不可改——check-step 断言 |
| A-5 | **大势两来源** | 设定池写入者枚举 = {抽象管线提取, 盘算浪尖派生}；冒烟断言不存在第三来源写入；模型世界步的 source 枚举不变（plot/state/ripple） |
| A-6 | **熵泵摩擦** | 环境量引擎小步推（提案：每 3 tick 一步）；越阈值落**状态驱动事件**（引擎生成器，编年可见、挂事件链、可作盘算挂因）；冒烟期间存在非模型生成的状态源事件（长跑防线验收③） |
| A-7 | **玩家 attrs 自动注入**（P-B 触发） | 抽象产物 → `e_player` 初始 attrs 自动映射（确定性映射表，产物缺失字段留默认提案值）；无玩家世界不注入（旁观兼容 P-E 语义不破） |
| A-8 | **回归** | 既有 183 全绿；确定性逐字节；黄金三锁不动；pack 输入恒 ≤4k（大势块为固定小结，不胀预算） |

## 2. 范围限制（本棒不做，防漂移）

- **冷档轮转**（500t/5MB，longrun §2.2）——双流 UI 阶段或长跑实测（100t 冒烟无法验证）；
- **里程碑阅读视图 / 设定编辑 UI**——双流 UI 阶段；本棒设定池只作为 pack 输入 + 演化源，不做界面；
- **模型润色**（摘要文本）——双流 UI 阶段可选加分；
- **兑现通道细则、方向相悖报警、实体生灭、未决点 1 深化**——队列原触发不变；
- 抽象管线的 **ST 接线**（世界书源读取、设置页按钮）——双流 UI 阶段（ST 集成）；本棒落 v2 侧契约与形状，管线本体在编排层（transport 注入式，沿用 v2 架构）。

## 3. 设计

### 3.1 设定事实库与张力 schema（未决点 4）

**形状草案**（基于附录 A 备料；拍板点 T1）：

```
context.setting = {
  frozen: {                          // 冻结层：世界书提取产物（引擎只读）
    fingerprint: string,             // 书指纹（FNV-1a，书一变即失效——v1 机制原样）
    extractedAt: string,
    canon: {                         // 形状 = v1 abstractCanon 产出（兼容，附录 A）
      powerScale: [{ level, note }],
      rules: [string],
      society: string,
      techOrMagic: string,
      historyNotes: [string],
    },
  },
  dynamic: {                         // 演化层：引擎小步推，事件可改，模型不可改
    tension: { polarity: string, direction: string, intensity: 0..1 },
    env: { /* 环境量键值：引擎推演域（键枚举见 §3.5） */ },
    derivedFrom: [string],           // 派生源引用（书条目/事件 id/浪尖盘算 id）
  },
}
```

要点：
- **tension 三件**（极/方向/强度，ANCHOR §4.6①）：`polarity`（极——两股劲的名字，原文溯源）、`direction`（当前方向——谁压谁，可空=僵持）、`intensity`（强度 0..1——**引擎确定性计算**：由演化层事件近期数量/分量比推，不是模型拍的数；公式定案后走曲线报批"强度算法参数"）；
- **兼容**：旧世界 `context.tension:0.5` 形状合法（schema 可选字段缺省），迁移期黄金锁零扰动；pack 读取路径改为"有 setting 取 dynamic，无则回退数字（现状语义）"；
- **“只提取不创作”纪律延续**：抽取 prompt 要求张力三件全部原文可溯源（polarity/direction 用原文措辞，intensity 不要求模型输出——引擎算）；净化规则复刻 v1（字符串化+去空，无数量约束）。

### 3.2 抽象管线复用（v1 对照）

v1 管线形态（备料附录 A）：世界书 chunks 合并 → 截 30000 字 → LLM 抽取（`buildWorldCanonPrompt`：只提取不创作 + 无数量约束）→ `sanitizeCanonCandidates` 净化 → 合并落库 → 书指纹缓存（FNV-1a、LRU、force 重抽）。
v2 差异与对策：
1. **形状升级三处**（ANCHOR §4.6）：①设定事实 → 结构性张力 + 环境量（§3.1 形状）②冻结/演化分离（§3.3）③两来源（§3.6）——提取 prompt 在本棒新增张力/环境两组的抽取段（仍只提取不创作）；**调用时机**沿用"初始化 + 书变重抽 + 手动 force"（v1 三时机，v2 的初始化=世界书接入时——双流 UI 阶段接线）；**手动 force 语义（v1 原样）**：玩家主动重抽——跳过指纹命中判断强制抽取、产物刷新缓存（旧条目作废）；入口=设置面板「重新抽象」按钮（ST 接线随双流 UI 阶段，属 T6 范围）；
2. **prompt 与净化**：v2 侧复刻 v1 的 8-28 拍板口径（无数量约束）；净化净化到形状合法为止；
3. **缓存键**：fingerprint 计算函数（FNV-1a）直接复用 v1 算法（读旧插件对照，原样搬）。

### 3.3 冻结/演化层分离（A-4）

- **冻结层**（frozen）：世界常数。引擎只读——`check-step` 新增拒面：世界步 `stateChanges[].entity` 涉及设定池键（`context.setting.frozen.*`）/actions 引用冻结条目 → 拒绝（与红线 1 同机制：校验拒绝、世界如实不动）；pack 大势块只读注入；
- **演化层**（dynamic）：引擎独占写。写入者 = {abstract 派生器（初始化/重抽）、环境推演器（§3.5）、盘算浪尖派生器（§3.6）}；模型無直写路径（不在任何可写 schema 面）；"事件可改"= 事件落账时可带 `settingPatch`（引擎通道，模型只是事件原料——薄裁定哲学延续，细节 T 点）。

### 3.4 玩家 attrs 自动注入（A-7，P-B 触发闭合）

- 触发点：设定池就绪（frozen.canon 落库）且世界含 `context.playerId`；
- 映射表（草案，T 点拍定）：`hardPower ← powerScale 首档 note 中力量词表命中值`（零 token 解析，v1 `powerFromNameContext` 同思路）、`office ← society 中"制度"语义条目命中`、`intel ← techOrMagic 条目命中`、`network ← 默认提案值`——**命中即用、不命中原样保留当前值**（不覆盖手填值，P-B"当前手动"优先级不变）；
- 无 playerId 世界跳过（P-E 旁观兼容）。

### 3.5 熵泵摩擦制造（A-6，longrun §2.3 收口）

- **环境推演器**（引擎，编年层外挂 tick 段）：每 `ENV_TICK=3`（提案）tick 一步——`env` 键值按确定性小步规则演化（键枚举初案：tension 推手、民生度、动乱度、天时——T 点定键表）；
- 越阈值 → 引擎生成**状态驱动事件**（source.state，照常挂链/编年/点名应答）——"醉话说漏嘴、劳役征发"类处境上桌；
- 闭环：摩擦事件 → 新盘算挂因（§4.4）→ 世界不冷却（longrun 验收③）；
- **零创作纪律**：环境事件只从环境量阈值落，模型不发明（A-5 断言覆盖）。

### 3.6 大势两来源（A-5）

写入者枚举与守卫：
1. **抽象派生器**（书提取）：初始化/重抽时落 frozen + dynamic 初值；
2. **盘算浪尖派生器**（引擎）：顶层盘算终结/取消时按 T 点规则向 dynamic 推送"浪尖"项（tension.direction 的候选来源）；
3. **不存在第三来源**：模型世界步 schema 无大势写入面（A-5 断言锁死）。

### 3.7 SSOT/schema 与成本纪律

- `ssot.schema` 扩展：`context.setting` 全可选（frozen/dynamic 均缺省合法）；`context.tension` 保留（兼容，另注"已并入 setting.dynamic.tension.intensity"）；
- **成本**：大势块在 pack 中为固定小结（摘要级：张力三件一行 + 环境量键值 ≤1k 字符），不胀 4k 预算（A-8 断言）；
- 抽象调用成本：提取仅在初始化/书变/force 三时机（调用次数曲线与 tick 数解耦——longrun 验收⑥精神）。

## 附录 A · 旧 abstractCanon 备料记录（2026-09-07 夜读 v1 归档）

**管线**（v1 `plugins/story-world/`）：`director.abstractCanon({force})`（director.js:505）——世界书 chunks 合并 → 截 `CANON_SRC_CHAR=30000` 字 → `buildWorldCanonPrompt`（prompts.js:477）抽取 → `sanitizeCanonCandidates`（director.js:105）净化 → `mergeCanonCandidates` 落 `outline.meta.rosterMeta.canonCandidates`；独立运行守卫（3 分钟并发锁）+ AbortController + 失败软着陆（空/非 JSON → error 可重试）。generateWorld 初始化路径同用 `extractCanonCandidates`（director.js:335-339）。

**产出形状**（五件套，字段名逐字）：

```json
{
  "powerScale": [ { "level": "档位名（原文）", "note": "该档意味着什么（原文/极简）" } ],
  "rules": ["法则1", "法则2"],
  "society": "社会与制度格局一句话",
  "techOrMagic": "力量/生态体系一句话",
  "historyNotes": ["历史要点1"]
}
```

- prompt 纪律：档位名/顺序必须来自原文、不许发明重排、**档数取全**；原文措辞不润色；没有的留空；宁可少不可编；
- 净化：字符串化 + trim + 滤空；全空 → null（视为无候选）；
- **2026-08-28 用户拍板：世界设定不受任何数量/长度约束**（防编造靠"只提取不创作"纪律而非量制）——v2 延续此口径；
- 实体 canon 零件（character: identity/role/affiliation/note；faction: nature/stance/note）由 roster 管线另产（行动卡"零 token 组装器"的零件来源，2026-09-04 用户定调）——v2 大势层**不消费**实体零件，只消费五件套（范围控制）。

**书指纹缓存**（director.js:279-326、adapter.js:301-314）：键 = `bookFingerprint(fullSource)`（**FNV-1a**，书内容一变即失效）；值 = 合并前候选（`setAbstractCache/getAbstractCache`，LRU 有界、多卡共存、cacheVersion 版本戳）；"不再每聊重跑设定/名录两次 LLM 抽取"；手动「重新抽象」= force 重抽 + 刷新缓存。

**成本**：初始化/重抽/force 三时机调用；输入 ≤30000 字；输出形状固定（五件套）。
