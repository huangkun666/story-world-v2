## 1. ★★★ 病与治法

### 1.1 病：那张手写名单（逐行取证，不是推演）

面板上所有按钮共用**一个**点击委托（`web/index.js:2941`），它把按钮身上的 `data-*`
按一张**手写 13 词名单**（`:2967`）翻成引擎听得懂的参数 —— **不在名单上的词一律静默扔掉、不抛错**。

**leg105 的现场**：

- `src/render.js:1252` 画的翻页按钮带 `data-action="ch-page" data-value="next" data-layer="${layer}"`；
- `web/index.js:2571` 的处理器读的是 `payload?.layer`；
- 而 `data-layer` **当时不在名单里** ⇒ 永远 `undefined` ⇒ `String(undefined || 'event')` = `'event'`
  ⇒ **点账目层的「下一页」，动的是事件层的页码**。

处理器跑了、没抛错、判据全绿，玩家看到「页数也不会跳」。

**为什么现有判据抓不住**（本棒实测 96 个判据文件）：

- **48 个**读 `web/index.js` 的**源码文本**做正则断言 ⇒「把代码从 A 搬到 B」会红，
  而「按钮点了没反应」全绿；
- **10 个**真加载 `web/index.js`；
- **0 个**真的派发过一次点击。

最接近的一条是 `test/lookup-batch.test.js:403`（「画了按钮就必须有人接」），
但它止步于**字符串 vs 注册表**：证明"名字对得上"，不证明"点下去会怎样"。

### 1.2 治法一：照单全收（本棒**唯一**的语义改动）

`readPayload` 从手写名单改成遍历 `el.attributes`（`data-value` → `value`，逐字去前缀）。

★**用 `attributes` 而不是 `dataset`**：`dataset` 会把 `data-foo-bar` 驼峰化成 `fooBar`，
与本模块"逐字属性名去前缀"的口径对不上。

**安全性取证**（写进细案 §4.1，本棒复述）：

- 全仓 **0 处**枚举或展开 payload（`Object.keys/entries/stringify`、`...payload` 全无命中）；
- 处理器**一律点名要某一个键**、要不到走默认值；
- **机械清点对账**：处理器读 **12 个键**，其中 **10 个来自属性**
  （`chain entity force layer name param snap tick value vol`）⇒ 照单全收一个都不会少；
- 另两个 `el` / `worldName` **不来自任何属性**（`data-el` / `data-world-name` 全仓零处出现）
  ⇒ **本棒不改变它们的任何行为**（`worldName` 实测恒 `undefined`）。

**净收益**：那份名单是一份**没人校对的复制品** —— 它多列了 `source` / `filter` / `key`
三个**没有任何处理器读**的键、又**漏了 `layer`**（直到 leg105 才补上）。
照单全收之后它整个消失，**多列与漏列同时成为不可能**。

**顺带修好一处**：旧写法对**缺失**的属性交出的是 `null`（`getAttribute` 的返回值），
新写法**缺属性就没有那个键**（`undefined`）—— 与红线「空着就是空着」同向。
★这一条是 TDD 时被自己的判据咬出来的（我原本只预期"新键要带上"）。

                       · route(el)      纯函数：元素 → { action, payload } | null
                       · handleClick(e) 薄壳：挂 click 委托

web/index.js           bindActions() 里那 29 行点击委托 → 一句装配

**三支的处理顺序照搬原实现，一个字不改**：注入开关早退 → `.sw2-goto` 早退 → 走动作总线。
leg89 那段"为什么开关要在这里直接收"的定案说明**随代码一起搬走**（留在原处就是第二份真相）。

## 4. ★★ 本棒踩的坑（下一任照做，能省一整轮）

> ★★★**本节最值钱的一条**：本棒三次被自己的**判据/桩**咬红，而**每一次都不是代码错**——
> 是**尺子错**。这正是本仓第四次栽在同一个形状上（leg55/57 台账守门两次、leg106 两次）。

1. ★★★**搬家会把"文件位置"与"执行顺序"分开**。`test/tag-extract.test.js` 的 leg89⑱ 量的是
   "注入开关那段在**文件里**的位置晚于点击入口"—— 搬家**之前**那段内联在回调里，
   所以"文件位置 == 执行顺序"；搬家**之后** `route()` 在文件上半、装配在末尾
   ⇒ 这条判据量到的成了**排版，不是行为**（红得毫无意义）。
   **定稿**：改指新家，并**改成量 `route()` 内部**的位置（先收 `data-inject-switch`、再判 `data-action`），
   再补一条"`route()` 必须真的挂上那个唯一点击入口"防"留个没人调的函数"骗过去。**口径一个字没放宽。**
   ★**留档**：搬族之后判据要**改指新家 + 重新想清楚"锁的是哪一层"**，不许删、也不许照抄。
2. ★★**手写 DOM 桩必须逐个对账模块真正用到的每一口**（本棒**连栽两次**）：
   第一版缺 `addEventListener`（模块把委托挂在 `win` 上）⇒ 整条链跑不起来；
   第二版 `closest()` 只支持两种选择器、缺 `[data-inject-switch]` ⇒ 注入开关那条**静默走空**；
   第三版缺 `attributes`（照单全收要遍历它）⇒ `readPayload` 会交出空对象。
   ⇒ **桩不是"够用就行"，是要照着模块的调用点逐个核**。
3. ★★**判据写宽了会误报，而误报会让人去改守卫**。我自己的"搬家完成"判据第一版写成
   `includes("getAttribute('data-source')")` ⇒ 它把**链浮层那一处**（`web/index.js:2670`，
   细案 §2 明确列为"本笔不做"）**和我自己写的注释**一起算了进去，当场误报红。
   **定稿**：只咬**主委托那条 13 键全量拼装**，并**如实登记**链浮层仍在原地（不是漏搬）。
4. ★★**"判据测了个空气"要用真数据验**：我第一版用 `golden-world.min.json` 当夹具，
   而它的 `chronicle` 是 **0 条** ⇒ 渲染不出分页器 ⇒ 那条判据**恒真**（空锁）。
   ⇒ 凡是"从真产物取某个控件"的判据，**先跑一遍看那个控件真的在不在**。
5. ★**守门红了先看是不是它该红**：改完搬家，`STATE.md` §1 的行数读数（3099）与实测（3079）不符
   ⇒ 文档守门当场 FAIL 1 条。**那不是故障，是守门在干活**。
   ⇒ 不许"顺手改掉它"—— 按 leg106 纪律，改那一处要**单独做、留痕**（本棒放在 Task 4）。
6. ★**两笔分开落地是保命的设计**：Task 1（搬家）与 Task 3（照单全收那一刀）是**两次独立提交**
   ⇒ 第二刀万一出事，可以**只退它、保留搬家**。★本棒实测两刀都安全，但这份保险值得照抄。
