## 1. 病：编年的往事有**两条**变短的路，一条记账、一条不记账

| 路 | 谁干的 | 会不会说出来 |
|---|---|---|
| ① 包预算不够 → 裁往事 | `trimPack`（`pack.js`） | ★**会**：包里写 `trimmed`（`纪事` = 整栏没装下 · `纪事.留N条` = 只装下最近 N 条） |
| ② 编年太长 → **轮转进卷** | `rotateChronicle`（`storage.js:74`） | ★**不会**：编年**直接少一半**，而 `trimPack` 那一刻量到的是"缩水后的编年"，它**全装得下** ⇒ `trimmed` 依然是 `undefined` |

⇒ **一句话：上游先悄悄剪短了，于是下游的诚实检查报告说一切正常。**
★这一条尤其扎心，因为本仓在"裁了就要说出来"上花过**整整一棒**（`leg113`：`pack.js` 那段注释连
"`trimmed` 这个键自己占 130 字符、第一版按占位量导致越界 80 字符"都留了档）——**而轮转把这一整套诚实机制整个绕过去了**。

**三个名词，当场说人话**：

- **轮转 / 入卷**：热账（存在聊天文件里的那本账）里的编年太长时，把**最旧的一段**剪下来、整段搬进浏览器本地一个叫"卷"的地方，好让热账不变胖。
- **检索层**：专门负责"从账上把往事取回来"的那一层（`src/ledger-recall.js`）。
- **纪事**：每一轮递给**世界模型**的那份输入（"包"）里，装"世界已经发生过什么"的那一栏。

## 4. ★本笔踩的坑（**这三条最值钱**）
