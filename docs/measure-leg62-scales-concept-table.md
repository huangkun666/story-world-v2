## 1. 硬事实（本棒实测，都指得出出处）

1. **`实力` 不是编的**（三本真账逐字校验）：大荒 **508/508** · 三国 **131/132** · 实教 0/1 的值能在本书原文里逐字找到。
   ⇒ 它的病不是"编造"，是**它是个杂物槽**：大荒装 `T7 合体境`（刻度）、三国装 `左将军，益州牧`（官职）、
   实教装 `智力谋略A+|领导操控A|学业A|身体E-|团队C+`（**五项属性压成一格**）。
2. **用户截图的病在两本账上**（`实教数据库版v2.0`）：
   ① `2016年7月…2017年4月` **9 条日期被抽象成 `kind=character` 的角色**（实体 `e_bk_63..71`，`location=未明`，无任何属性）；
   ② `powerScale` 5 档 = **2 个概念混在一起**（`S~E级`=评级尺 / `A班~D班`=班级分配制度）；
   ③ `dims` 14 条 = **5 基础属性 + 5 合成分/派生 + 2 公式 + 2 重复**（`体育` 与 `体育能力`、`团队` 与 `团队合作`）。
3. **`axis` 机械分不出来**：
   - 实教 5 档 ⇒ 纯形态聚类 **1 族**（`S~E级/A班/B班/C班/D班` 全混）；
   - 三国 27 档 ⇒ 8 族，但 `T0级_天下无双` / `T0级_绝世奇才` / `T0级_王佐之才` 是**三个不同轴、同一个记号前缀**；
   - 大荒 103 档 ⇒ 21 族，且 `T1..T16` 被 **8 张不同的表**共用（境界/势力战力/资质/功法/法器/法术/叙事尺度/职阶）。
   ⇒ **轴名只能由模型标注**（读原文的那一遍才知道该合并成哪个概念）。
4. **★概念能按"原文题名"机械切出来**（三国的铁证）：`T0级_天下无双`→【演义战力体系】、`T0级_绝世奇才`→【演义智谋内政体系】、
   `T0级_王佐之才`→另一个体系、`里闾称善…`→【声誉】。**但轴名不能取题名**——见 §3 试算（会切出 28 张表全噪声）。
5. **`实力` 反查判据的实测面**（交接 §3.2.4 那条）：大荒 **21 族里 19 族被引用**（境界轴峰值 390 次、总覆盖 508/543=94%）；
   实教 **1/106**、三国 **132/132 条一条尺都匹配不上**。
   ⇒ 它答的是"**这把尺有没有人用**"，**不是**"这把尺是什么"；适合当覆盖率读数，不适合当分类。
   ★副产品（可真机复现）：三国的 132/132 零匹配 = leg61 卡 3「39% 覆盖率但 95 条是官职」的**独立第二证据**。
6. **大荒的真规模是 51 张概念表 / 311 档**（真机调用得出，见 §4）。`powerScale` 那 103 条是**把这 51 张糊成了一条数组**。
7. **`dims` 里混着换算表**：大荒 `战力基准`(`T1=100 ~ T9=1e9`) · `命/灵/神识基准` 共 **4 条**；
   实教 `S点数`(`CP班级点数+PP个人点数`) 1 条。**形态判据可认**（range 含 `=` 或系数）。
8. **实教的 `S~E级` 全书 0 命中**：`S~E` 在**所有世界书里 0 处**，只出现在账本自身（7 处）。
   即现有实教账里那 5 条属性（`学力/智力/判断力/体育/团队`）**不是书里的**——是模型自带知识。**另立一项，不混进本棒。**

## 2. 设计（用户已拍 · 四条口径）

| # | 口径 | 用户原话 |
|---|---|---|
| 1 | **形状 = 概念表**：一概念一表；标签只在**表头**，不在每条档位上 | 「粒度不要太细了，换成概念表怎么样」 |
| 2 | `用途` = **自由文字** + 一道纯函数闸（同一用途名下不许混形态不同的档位） | 「三个枚举得完吗？」→ 实测不够（见 §3.4） |
| 3 | **小阶当子表**（不另立一张表） | 「当子表」 |
| 4 | **轴名由模型照抄原文表头/题名** | 「模型在抽取时标注 axis」 |

### 2.1 形状

```js
// frozen.canon 的新可选键（旧账没有它就是没有 ⇒ 零扰动）
刻度: [
  { 名: '人族境界', 用途: '力量体系全典 / 战力准则',
    档位: [{ 档: '感气境', 注: '眉心生光/阴煞聚体。…' }],
    子表: [{ 名: '小阶段与数值浮动铁律', 档位: [{ 档: '初期' }] }] },
  { 名: '两界十一阶·功法与灵器体系', 用途: '功法与灵器品阶', 档位: [...] },
  { 名: 'S~E级', 用途: '分级（决定班级分配）', 维度: [{ 名: '学力', 范围: 'S~E级' }] },
]
```

**为什么不复用 `axis` 这个词**：`abstract.js` 里已有一个 `tierAxisOf`/`tierKeyOf` 的 `axis`
（leg61 的**档位去重键**，语义完全不同）。新结构用 `名`/`用途`/`档位`/`子表`/`维度`，与它不撞。

### 3.2 交接 §3.2 四条提案的试算判定

| 提案 | 判定 | 依据 |
|---|---|---|
| 1. `powerScale` 每条带 `axis` | ❌ **改为概念表** | 机械聚类分不开（实教 1 族 / 三国同前缀三轴）⇒ 但标签放条目级 = 309 个字段（细） |
| 2. `dims` 每条带 `kind` | ❌ **改为概念表内的维度组** | 机械 `kind` 判据召回极低：实教判对 6/14，大荒 **5/65**，三国 **0/9** |
| 3. 值不进这张表 | ✅ **成立** | 实教跨表同名 0 处，但 14 个 dim 里 8 个是合成分/公式 ⇒ 值确实没进表，**合成分与公式挤进来了** |
| 4. 用 `实力` 反查哪把尺在用 | ⚠️ **改名为"覆盖率读数"** | 它答"有没有人用"不答"是什么"；三国 132/132 零匹配是真 bug 的第二证据 |

### 3.3 概念表试算（臂 A：轴名取"原文题名"）

| 书 | 机械切出 | 质量 |
|---|---|---|
| 实教 | 3 张 | ❌ `A班/C班/D班` 被【001-入学式】抓走、`B班` 被【考试-生肖游轮】抓走（**全是噪声**） |
| 大荒 | **28 张** | ❌ 过度切分：`昆仑道宫/菩提禅院/镇魔剑宗` 各成一张（它们是**势力条目里提到**档位，不是定义） |
| 三国 | 3 张 | ⚠ 18 档挤进一张**混了 4 种形态**的表（缺题名时轴名丢失） |

✅ **形态一致性闸有效**：它把"混了 4 种形态"当场标出（这是 `用途` 自由文字那条配套的纯函数闸）。
❌ **轴名不能取题名** ⇒ 必须模型标注（与 §1.3 结论一致）。

### 3.4 「三个枚举够不够」——**不够**（反面数据）

大荒 103 档逐条摆开后，真实出现的尺：

| 尺 | 用途 | 落得进三类吗 |
|---|---|---|
| 境界表 `T1感气境…T16道祖境` | 量"多强" | ✅ 评级 |
| 势力战力 `T2炼气…T9渡劫` | 量"多强" | ✅ 评级 |
| 功法/灵器品阶 `黄阶→道祖阶` | 量"多强" | ✅ 评级 |
| **宗门职阶 `杂役/外门/内门/真传/核心/长老/太上/老祖`** | 注是 `T4+贡献≥2000+长老荐` → **入阶条件** | ❌ 制度，不是评级 |
| **天赋/血脉 `黄阶…圣阶`** | "潜能/血脉奇迹" → **潜力** | ❌ 既非强弱也非制度 |
| **小阶 `初期/中期/后期/巅峰`** | 对"境界"的细分（系数 x1.0~x1.8） | ❌ 是一把尺的细分 ⇒ **当子表** |
| **叙事尺度 `T1-T4 低武`/`T4-T6 [意]`/`T7-T9 神话`** | 描述"世界什么画风" | ❌ 完全落不进 |
| 数值基准 `T1=100 ~ T9=1e9` | 换算（★现在错装在 `dims` 里） | ✅ 换算 |

⇒ 要覆盖得开到 **5–6 个**，且"叙事尺度"这类是**方言性的**（换本书可能换成别的东西）。
**开得越多越容易过拟合**（leg61 为此栽过三次）⇒ 故取**自由文字 + 纯函数闸**。

## 4. 真机试算（两次调用 · 真模型 · 零写入账本）

装置：`leg62-live-concept-table.js`（用法：`node leg62-live-concept-table.js <书名>.json`）

### 4.1 实教（9,463 字符 · 27.6s · 输出 1,120 字符）✅ **成功**

| 模型交回 | 机械闸 |
|---|---|
| 《班级制度》用途=**"按入学综合成绩和学校面试评估分班"** · `A班/B班/C班/D班` | 轴名✓在原文 · 档位出处**全中** |
| 《年级》`一年级/二年级/高年级` | ✓在原文 · 全中 |
| 《五代学员(Gen1~Gen5)》`第四代/第五代` | ✓在原文 · 全中 |
| 维度 4 条：`班级点数(CP)/私人点数(PP)/保护点数/班级人数` | — |

★**它把 `A班~D班` 单独分了一张表、用途标成"分班"** —— 正是用户截图那个混排的根治。
★ 它**没交 `S~E级`**（书里没有，见 §1.8）—— 同样的提示词下模型**不编**。

### 4.2 大荒（268,764 字符 · 99.2s）⚠ **质量对、但输出撞死**

- 模型交回 **51 张表 · 311 档 · 用途逐张都写得对**（`力量体系全典/战力准则`、`宗门职务与阶级`、
  `货币与交易规则/购买力`、`任务分级`、`NPC心智枷锁`、`叙事检定(d20)`…）；
- 《人族境界》档名干净成 `感气境/炼体境/…`，**并主动把"小阶段"放进 `子表`**（正是用户拍的第 3 条）；
- ❌ **但 JSON 在 16,384 输出预算处截断**（21,777 字符，第 1398 行）⇒ **大荒这种体量一遍抽不完**。

⇒ 结论：**概念表方向对、模型做得到，但"粗粒度"不是免费的**——表一多，输出量比现在大数倍。
