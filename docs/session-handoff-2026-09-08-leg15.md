3. **真跑判定方法（答用户）**：一层=世界能推进 ⇒ 八组形状合法（缺组=校验拒=世界不动）；二层=主动提议痕迹（编年「入局/覆灭/复归/淡出」行 / warnings「入局限额·席位已满·覆灭复核拒绝」/ silentDropped 计数 / dialogueBook）；三层=原始 step 不进 SSOT，导出 JSON 只能看落账痕迹。你的导出=模板生效+零主动提议（合理：无素材）；
4. **【讨论·未拍板】对话依据册广播缺口**：依据册记账/校验已通，但 `buildEvolutionPack` 不喂依据册给模型——模型看不到「白小娥反复被点名」信号 → dialogueFact 通道低激活（玩家念叨的名字世界无反应=活档断头链重演风险）。方案：pack 附 dialogueBook 摘要（count≥2+近 20 轮+≤8 名，预算纪律），prompts 铁律 7 补一句，测试断言；
5. **【讨论·未拍板】新实体数值分配缺口**：现落账 attrs={} → 分量 0 → gate 阈下=**入局即哑巴**（存在、可被打、永不主动）。方案三层：①newEntities 增可选 attrs（模型从书/对话断言提炼）+ 引擎 [0,1] 薄钳制（attrs 是账本事实不是分量，与 stateChanges 同款信任模型；K32 玩家解析先例）；②缺省兜底 ENTITY_ATTR_DEFAULT（character 0.15/faction 0.25 提案，随数字组报批）——入局不哑巴、分量从低靠活跃/点名/事件渐长；③书名录 seed 同默认（从书摘数值留未决点 1 深化）；
6. **【讨论·未拍板】NPC 台词行动与模拟器（OOC 质询）**：用户指出「台词演了+账上另安排=OOC 分裂」。用户方案「提取台词角色名→本轮黑名单」经推演=死结（黑名单冻结主动作+台词行动不入账=每次露脸就静止=行为断层；断根=只提名字不提动作）。正解=ANCHOR §4.7② 原文三件套：**提取升级**（NPC 断言=名字+动词+对象）→ **登记**（落账当轮行动事实，模拟器不另写矛盾戏，OOC 消）→ **重排**（相关盘算记受阻/推进，行为逻辑接住，断层消）。归属=未决点 1 深化的正式形态（新机制，两段式：细案→拍板→施工）；
7. **真跑顺带实证**：你的世界编年 ch_0..ch_4 全无 kind（K39 前旧账）——「过滤没起效果」现场根源，A-16③ 语义不变。
