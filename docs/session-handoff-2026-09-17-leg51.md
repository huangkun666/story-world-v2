## 2. ★ 用户那两句的取证结论

### 2.1 「推进、撤销不应该放参数页」——**推进该走，撤销该留**
- **推进**：`data-action="advance-world"` 在**设置页也有一枚**（`src/render.js:1399`）⇒ 参数页这一枚是
  **重复入口**。leg40b 把它挪过来的理由是"这一页就是你对世界的输入"，但**"推进一轮"不是输入，是动作**
  （它不写任何档位）⇒ 用户这条成立。
  ★**处置**：参数页那张卡（`src/render.js:404-407`）整段撤掉；**设置页那枚保留**（不丢入口）。
- **撤销**：`src/undo-stack.js` 的作用域**只覆盖这一页的编辑**（档位/开关/上限）⇒ 挪到设置页会出现
  "在设置页撤销参数改动"的错位。**留**，但**它现在排在倒数第二张卡**——该贴着被撤销的那些控件。
  ★注意：`undoCard`（`src/render.js:414-418`）与 `advanceCard`（`:404-407`）是**两张独立的卡**，别一起删。

### 2.2 「民生和时局没人生产和消费」——**机制层成立，但不是"完全没人管"**
| 谁 | 干什么 | 在哪 |
|---|---|---|
| **书**（生产） | 从世界书抽档位词，**书里明述才落账**（不写占位值） | `src/abstract.js:357-363` |
| **模型**（消费） | 随大势块进包，**模型看得见** | `src/pack.js:482` `env: dyn.env ?? {}` |
| 引擎 | **一条判据都不读**（门控/裁定/退休/波及全换结构判据了） | 全仓 grep 无读点 |
| 面板 | 信息带 + 参数页画出来 | `src/render.js:450` / `:114` 起 |

⇒ 准确说法：**这四个键是"给模型看的氛围标签"，不是引擎机制**——面板自己那句「不参与任何判断」**是真的**。
⇒ ★**真账实测：`民生度`/`天时`/`张力推手` 三个键在账上根本不存在**（`dynamic.env` 只有 `动乱度` + 三个开关）
⇒ 那三格永远是「未定」，信息带那三格永远是「未定 无据」。

★**加重的一笔（新发现）**：开关参数（`recordEnabled` / `memoryEnabled` / `autoAdvance`）**住在同一个 env 块里**，
而这一块**整包进模型**（`pack.js:482`）⇒ **模型看得到 `autoAdvance:"0"` 这种引擎开关**（面板用黑名单把它们挡在玩家视线外了）。
★其中 `recordEnabled` 的开关**早被撤了**（leg40b：它一个字节都不写），但**旧账里那个键还在**，
且**仍随 `env` 进包**。⇒ 这是"旧键没清 + 引擎键名进模型"两件事，**要动它就先报批**（改了就是改"模型看到的东西"）。

## 3. ★ 观棋页 · 「浪尖」取证（用户：「大势有浪尖的文字」）

**成立，而且比"还有文字"更具体：同一屏里出现两遍。**

| 出现处 | 代码 | 画了什么（真账副本） |
|---|---|---|
| ① 大势行末尾 | `src/render.js:467` `浪尖：${tides.slice(0,2)}` | 浪尖：趁乱试探大虞法旨的底线（第60轮）、查探北山死煞源头并荡平邪祟（第59轮） |
| ② 独立一栏「浪尖 · 刚收尾的大动作」 | `src/render.js:475` `tides.map(...)` | 同上两条 **+ 第三条**（趁大虞与剑宗对峙，窃取死煞本源（第58轮）） |

- 信息带（`infoband`）可见字符只有 **280**，「浪尖」出现 **2 次**；两处加起来约占**信息带的四分之一**。
- 数据源：`dynamic.derivedFrom`（真账 **20 条**，如 `浪尖:a_22_1@26`），由 `pushTidePeak`（`src/setting.js:76-87`）
  在**顶层盘算终结/取消**时推入，上限 `TIDE_CAP=20`。
- 标签由 `tideLabel`（`src/render.js:219-224`）解析：`盘算目标（第${tick+1}轮）`。
- ★**第二处来源是引擎词**：`derivedFrom` 在 `BLACKLIST` 里（`:172`），而 `render.js:1347` 在**设定页**印着
  「**浪尖（派生源）**」——那是引擎词**漏进玩家视线**（`BLACKLIST` 只在测试里扫渲染产物，设定页这一处没被咬住，**待查**）。
- ★**次要**：`tideLabel` 的 `（第${tick+1}轮）` 与面板自己的轮次读数**可能不一致**
  （真账 `meta.tick=59`，浪尖项写 `@59` ⇒ 印「第60轮」）——**先核口径再改**，别当 bug 直接改。

★**待改（按 R2 的口径）**：同一事实不说两遍 ⇒ 两处**只留一处**（建议留独立那一栏，它信息更全；
