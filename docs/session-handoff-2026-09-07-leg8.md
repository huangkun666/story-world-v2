## 3. 关键决策与实测发现（全部有台账行可查：L65-L75）

1. **报批 15 项定案（L65）**：GC ×3 / 影响系数 ×2 / 初始 attrs ×4 / 掩码 ε / 败露阈值 / 事件产率 / 涟漪窗 / 热窗 / 里程碑粒度——引擎行为零变化（数字早已生效，报批补形式与口径）。
2. **大势层 T1-T6 全案 + force 重抽语义显式化（L66）**：玩家可随时强制重抽（绕过指纹、刷新缓存），入口随双流 UI。
3. **K24 schema（L67）**：`context.setting{frozen, dynamic}` 全可选 + `context.tension` 兼容保留——旧世界零扰动、黄金三锁不破（全量回归证）。
4. **K25 读写面（L68）**：保留键空间拒面（设定池对模型六类实体引用字段全拒，红线 1 同机制）+ `patchDynamic` 写通道（引擎独占）；"事件可改联动"规则推迟 K27（写通道先立，联动规则随键表）。
5. **K26 指纹缓存（L69）**：v1 算法原样搬（FNV-1a 官方向量锁）+ LRU 上限 5 + 版本戳 + 深拷贝。
6. **K27 熵泵（L70）**：**实测发现①**——锯齿表相位 1 起推，dir=+1 的键够不到危险带（首跑只发 2 键）→ down 周期修正（动乱/张力 down=6、峰值恰 0.80）；**实测发现②**——闭环熵泵事件满热窗 20 后按既有归档机制进里程碑（链条不断），测试断言按实测修正；首轮四键 t15 齐发（相位同步）、二发 t45×3 + t51 天时；**已知边界**——熵泵事件不点名实体（静默方响应需事件点名，如要扩展=队列项）。
7. **K28 玩家注入（L71）**：命中即用、不覆盖手填、缺省回退报批定案初始值；旁观世界零扰动（P-E 不破）；幂等。
8. **K29 强度算法 + 曲线（L72/L73）**：强度 = 近 10t 事件频次 ÷4 × 两强对峙度比值 × 惯性 0.9 混合（全参数提案态）；pack 大势块（有 setting 取演化层强度、无则回退数字；冻结层不入包=体积纪律）；**浪尖派生器**（顶层终结/取消 → derivedFrom 浪尖项，A-5 两来源收口）。**100t 曲线**：强度域 [0,1] 多变且冷档衰减、熵泵种子 ≥8、熵泵挂因 ≥2（"因事而生·熵泵"编年）、输入峰 ≤4000t、零警告、确定性逐字节、终态 ≈21.7KB（编年无裁剪=已知队列项，双流 UI 阶段裁剪/冷档；事件池有归档闸即有界）。
9. **验收（L74）**：A-1..A-8 逐条核对（有记录证据）；A-2/A-7 的抽取面（prompt/净化）与初始化接线归 ST 阶段（T6 范围明示，不瞒账）；检验三问通过。
