## 4. 本棒踩的坑（三个，都留档；其中一个是"同一个坑第二次"）

1. ★★**反引号（同一个坑，一天踩两次）**：`build-kb.mjs` 用**模板字符串**拼 HTML，而页面里那段 JS
   我自己写了个**嵌套模板** ⇒ 提前闭合外层模板、构建期语法错。**这正是 `leg123` §5 记过的那个坑。**

2. **EISDIR**：有几张卡的 `src` 是**目录**（`test/`、`docs/handoffs/`）⇒ 对着目录读文件当场炸。⇒ 先 `stat` 再读。
3. **PowerShell 的两个坑**（不是产品问题，但很费时间）：
   · `.NET` 静态方法（`[System.IO.File]::ReadAllBytes`）**不吃 `cd`** ⇒ 相对路径解析到别处，
     我的一次"证红"其实**没改到文件**（差点据此得出错误的结论）；
   · 内联 `node -e "…"` 里的引号会被 PowerShell 吃掉 ⇒ **写临时文件跑**。
   ⇒ 含中文的文件一律**用 Node 走字节**，这条铁律今天又被验证一次。
