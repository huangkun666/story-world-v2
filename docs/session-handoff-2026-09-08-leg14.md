## 3. 关键决策与实测发现（全部有台账行可查：L106-L115）

1. **细案贴代码写（L106）**：开工前实读数据面（settle 14+2 编年写行点逐一核对、links.up 单向=下游靠扫引用方、里程碑 links 为段级聚合、卷 fromTick/toTick 可区间映射、eventRef 缺口盘点）——验收判据全部落在真形状上，施工零猜谜；
2. **回归锁拦下设计错（L111 修正）**：细案原案「闭环/涟漪/熵泵行补 eventRef」被 settle.test 执行债回归锁当场否决——eventRef 在 streams 注入面有选择语义（`stage.chronicle.filter(c=>c.eventRef)`=注入候选面；闭环行不带 eventRef=不进注入，2026-09-07 拍板语义「闭环是历史状态，不是新动向」）。补写=注入面行为变化，违反引擎行为零变化。**铁律 9+测试先行的第一价值**；
3. **kind 章=契约唯一扩展，可选字段零破坏（L111）**：旧行/旧世界无章合法（schema 枚举锁断言）；旧账不 retro-kind（账不可篡改）→ 渲染层「无 kind 旧账恒显示+计数提示」（A-16③）；漏章回归锁双保险（settle 侧全行扫描 + backdrop 100t 全行扫）；
4. **暗处行 fixture 教训（L111）**：concealed 盘算侧行测试须预热 weights 种子——t1 门控跑在真分量重算前，空 weights 会误判静默滤除（K7 夹具教训复用）；
5. **测试预期三处自错（L112-L113）**：①`up` 不含 root 本身 ②已归档 root 用例须先把目标事件移出热池 ③被隐藏行的标题恰在可见行引文内（「沿『边关扣货』而来」）→ 子串断言改唯一子串。三处均为"预期写错、机制正确"；
6. **演示图迭代法（L107-L109）**：用户眼检=验收。方向倒挂（root 在上、来路向下长、▼与"上承"相反）=布局语义矛盾→沙漏（根居中/▲向更早/▼向未来）；"长条卡片观感不明显"→圆珠类型徽串轴（30px 圆徽单字=事/谋/纪/源/旧/卷，竖轴+横接点+珠间方向语，根=46px 金圈大珠）；用户「这个不错可以开工了」=v3 定稿；
7. **里程碑穿透的诚实边界（L112 设计落定）**：归档丢 source（只留 title/ids）→ 纪内逐事件上下沿不可枚举；余尾收敛珠只带纪 span **不造假 N**；agenda 产果只列热池（归档产果不可枚举）；跨卷=阅卷按钮动作，不自动载入旧卷全文；
8. **视图态纪律保持 A-2（L113-L114）**：筛选集与世界引用=纯视图态（不落 SSOT/不落盘/重绘保留/关面板重置）；renderAll view 入参缺省=全选，输出仍逐字节确定（A-2 锁未破）；
9. **珠链渲染=纯函数（L113）**：chain.js 零创作零玩家词面（id 交渲染转名/措辞）；renderChainViewHtml 全产物过 A-3 双扫（热链+跨纪链，details 管理区剥除后零禁词零代号）——玩家视线零 `ev_`/`a_` 代号，惯例如一。
