## 4. ★ 本棒最该带走的三条教训

### ① 构建号踩了同一颗雷（第二次）
细案初稿把构建号钉成 `leg49-entities-three-cols`（含 `entity`），与既有**共享禁词锁**
（K33/A-3「玩家可见文本零引擎术语」）对撞——而构建号恰恰**印在玩家看得见的表头上**。
实现者当时的处置是"**把构建号从扫描里抠掉**"（＝假绿），被评审揪出 ⇒ **用户拍板改名**、抠洞撤除、扫描恢复全量。
⇒ ★**leg31 当年遇到过一模一样的冲突，也是靠改名过的**。这条雷踩了两次 ⇒ **给构建号起名先过禁词扫一遍**，别等评审。

### ② 一条"永远为真"的断言（假绿的典型形状）
分组用例原来写 `assert.ok(html.includes('<summary'))` —— 而**工具条那个「？」提示本身就含 `<summary>`**，
所以 `grp:'none'`（压根没分组）时它也过 ⇒ 这条断言**对分组毫无信号**。
⇒ 改成锁真实结构（`<details class="sw2-ents-grp-block" open><summary>`）并加反向对照。
★与 ① 同源：**假绿比红灯坏得多**——红灯会让你去看，假绿让你以为已经看过了。

### ③ 「无 RED」是一种合法的 TDD 证据
Task 4 的接线被 Task 3 前置完成（既有审计「画了 `data-action` 就必须有人接」逼的），
所以那四条断言**一写就全绿**。实现者**如实报告"无 RED，因为接线已被前置完成"**，
并做两组**反向实验**证明断言真咬得住（注册侧改名 → 红在既有差异检查；断言侧写错一位 → 红在新断言本身）。
⇒ **宁可说"这里没有 RED"，也不要造一个假绿或假红。**

## 5. 本棒走过的路（17 笔，如实记）

6 个任务，每个都走"实现 → 独立评审 → 有 Critical/Important 就派修正 → **复审**"：
Task 1（数据层纯函数）· Task 2（三列行，**1 轮修正**）· Task 3（工具条，**接线被前置**）·
Task 4（接线核对，**零代码改动**）· Task 5（样式+分组，**2 轮修正**）· Task 6（文档，两笔）。

- ★ **Task 2 的第一轮评审抓到"页脚承诺了一个已被撤掉的「重查」钮"**（假承诺）——是**我口径的锅**：
  我写"只在待查行出现"，实现做成"未定案就出现"，而页脚还留着旧承诺。
- ★ **Task 3 的判据数与我计划不符（743 vs 742）**：**我计划 Step 1 的代码块本来就是 4 条用例**，
  标题写"3 条"是我的笔误 ⇒ **以代码块为准**。
- ★ **Task 5 的第三轮复审抓到"计划文件里还钉着旧构建号三处"**（含一个"照抄会红"的代码块）
  ⇒ **改动落在代码里，也要扫一遍"描述它的文件"**（计划/交接/任务书/scratch）。

## 6. ★ 控制方（我）自己踩的坑：两次 grep 相减得出的"本笔新增了禁词"是假的

我曾用 `git show d21451c:...render.js > 文件` 再让 Node 读，得出"`派生源` 本笔前 0 处、本笔后 2 处 ⇒ 本笔引入了禁词"。
**这个结论完全是假的**：PowerShell 5.1 的 `>` 重定向把文件写成了 **UTF-16LE**，Node 按 UTF-8 读 ⇒ **整个文件的中文全变乱码** ⇒
所有中文匹配都静默返回 0。
用 `git log -S '浪尖（派生源）'` 追源才查清：那字符串来自 **`c8d7a0d`（第十一棒）**，本分支**没有一行**碰过它。
⇒ ★两条纪律：**（a）跨工具传中文文本一律用 Node 的 `writeFileSync(...,'utf8')`，别用 PowerShell 的 `>`；
（b）"某字符串是本笔引入的"要用 `git log -S` 追源，不能靠两次 grep 的计数相减。**
（另：「未载」的真代码 3 处全在**观棋页**，是 leg25 f 定的"未载 ≠ 在别处"交互口径，不在本笔改的实体页。）

   建议压成「**没查到**」与「**书里没写**」两套——**跨八页，属下一刀**。
3. **★ 拼音排序限制（如实报，本笔选"接受"）**：ICU 78.3 **无拼音排序数据**
   （`Intl.Collator('zh-u-co-pinyin').resolvedOptions().collation === 'default'`）⇒
   `localeCompare(name,'zh')` 走的是**部首/笔画序**。真账实测末尾是「祝无双 · 转轮鬼圣 · 转轮鬼使 · 转轮王 · 追风 · 坐忘大罗」

   三条出路：A 接受默认序（**本笔选的**：零依赖 + 确定性；"按名号"只是第三排序档，真入口是搜索）·
   B 引拼音表（破坏"零依赖"，且表外生僻字仍退化）· C 受控词表手写键（同上）。
4. **分组只切"本页 60 行"、不切全册**（措辞已改成「本页 N 位」消歧义；把分组与分页耦合超出本笔范围）。
5. **§2 那套只读复现装置仍在临时目录**（`F:\deepseek\tmp\sw2-ui-*.mjs` 等）——leg48 §6.4 与本细案 §10 已建议两次搬进 `demo/`。
