# Story World v2 项目介绍

> Agent 知识处理、状态推演与可追溯交互

Story World v2 将来源资料转成实体、关系、规则与事件，并在多轮交互中维护运行状态、任务计划和历史记录。项目已开源，社区已有数百人使用，当前提供 SillyTavern 宿主集成。

它面向持续交互中的几类问题：前文信息离开上下文后难以回查，同名实体和关系容易混淆，历史事件与当前状态缺少明确区分，模型输出的变化难以验证和恢复。

## 从资料到状态

用户选择实际参与处理的资料后，插件分块请求模型抽取结构化信息，核对数据形状、引用与来源，再建立运行状态。原文只读；缺少证据的字段保持空缺。

每轮更新汇集当前状态、任务计划和相关历史，生成模型输入；模型提出结构化变化，程序执行校验与状态写入。生成内容、确定性检查和正式保存分开，全部提议不可用时不增加轮次。

## 已公开的知识检索

公开 main 支持名称、关键词及可选向量召回。统一检索接口保留事件标识、轮次、时间原文和来源；候选去重后按相关性与时间规则选择，再在预算内送入模型。

向量由用户显式配置和开启，历史增量建立索引；异步结果必须与当前聊天、轮次和完整查询匹配。恢复历史快照时隔离后来产生的记录，向量结果尚未准备好时保留当前名称与关键词检索路径。

## 状态追踪与恢复

可以查看实体资料、任务进展、事件流与因果链，并用快照恢复插件状态。整聊天导出用于保留聊天与插件数据；快照本身不回退聊天正文。

公开 main 还包含抽取块大小设置、中止抽取与任务诊断，帮助区分配置、网络、模型输出及来源校验等问题。实际已发送请求的服务端执行和计费由服务商决定。

## 本地研发进展

研发版进一步引入浏览器本地正式记忆账、Orama 全文/向量混合检索与 Graphology 图关联扩展，按任务固定版本查询、逐查询保存检查点，并把当前可见状态与历史证据分开提供。

这些模块尚未进入公开 main。研发版的图谱性能、内存及部分交互仍待用户实测，本页不承诺公开安装包包含未发布能力。
