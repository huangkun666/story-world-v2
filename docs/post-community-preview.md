# 【预览版】观棋窗口 v2 —— 一个装进酒馆的"活世界引擎"

> 它不决定接下来发生什么，只负责让**已经发生的事不自相矛盾**。

![观棋页全貌（当封面）](此处贴图①)

`观棋窗口 · Story World v2` 是跑在 SillyTavern 里的一个**活世界引擎**扩展。你每推进一步 RP，世界就演化一步：各方势力与角色按自己的处境和盘算行动——结盟、背叛、谋划、冲突——事件从他们的行动里长出来，带着原因和后果。

而你要做的是**继续演戏**。它不抢戏。

---

## 一、为什么做这个：长 RP 最疼的不是文笔

跑过几十轮的人大概都踩过同一批坑：

- 第 5 轮说过"某城已破"，第 40 轮那座城又完好地出现了；
- 上一章结盟的两个人，这一章若无其事地互不认得；
- 你明明办成了一件大事，世界却当它没发生过。

这不是模型笨。**是"世界现在什么样"这件事根本没有一个地方在记**——它只活在上下文窗口里，而窗口是会被挤掉的。世界书管的是设定（**应该**是什么样），不管进程（**已经**变成了什么样）。

所以这个插件做的是一件很窄的事：**给这个世界开一本账，然后每轮把账推进一步**。

> 账是唯一真源：面板上你看到的每一个数字都从账上**现读**，**没有一处是写死的**。

---

## 二、它和"让 AI 记住剧情"有什么不一样

一句话：**引擎是账房和史官，不是作者。**

它记账、守连续性、守身份、管在办事项的生死、算能见度；它**不裁胜负、不算战力、不给谁打分、不发明事实**。写场景、写台词、提议"接下来发生什么"，仍然是模型的事。

**这里没有"主角"。** 只有一枚由你控制的棋子，它的分量**由客观状态算出**：底层小民时世界的浪潮绕它而过，手握重权时它的一步能改棋局走向。你用两个口子与它相处——**RP 对话是你落子的手，观棋窗口是你观棋的眼**。

---

## 三、几个我觉得值得单独说的点

### 1. 面板上的数字不是编的，是从账上现算的

"现算"听起来像句空话，所以它在这个项目里是**一条不许违反的纪律**：凡是印在玩家眼前的数，都从真源现读。**写死的字面量迟早变成谎话，所以这个项目里一个都不许有。**

### 2. 每件事都有来路（因果链）

点开事件上的「**？**」，能看到它是**怎么来的**、又**牵动了谁**——上游是哪一方的哪一步，下游又改变了谁。

**没来路的事不会入账。** 所以这个世界不会突然冒出无因的转折，也不会把上一条线凭空冻住。

![因果链珠链视图](此处贴图②)

### 3. 它明确拒绝做什么

这一条我放在最显眼的地方，因为它比"能做什么"更能说明这是个什么东西：

- **不裁胜负、不打分**——没有"主角战力值"这种东西。书里怎么写的（`T9渡劫巅峰` 这类原话）就照抄显示，**不换算成数字**，因为拿精确的外壳装模糊的内容，会让"编的"看起来像"算的"；
- **不用词表猜书里的语义**——"这是势力还是角色"如果靠关键词表判断，换一本书就废，这种过拟合写法在本项目里是明令禁止的；
- **不发明事实**——抽不出来、算不出来、账上查不到的东西一律留空或标「未查」，**绝不用占位值凑数**；
- **不替你做决定**——引擎从不写"你"的行动，你的行动只从你的对话里提取。

### 4. 装上就有东西看，不挑书

不挑角色卡、不挑世界书：任意编排、任意语言、有没有关键词都行。按「✨ 开始新世界」，它自己去读你的卡和书，抽出这个世界的设定与名号，建起第一份账。

（**抽取效果依书而异**：有的书把设定写成条目，抽得干净；有的书把一切写进叙事，抽得就少。抽不到就空着——它不会拿猜测值把面板填满。）

## 四、装上之后长什么样（八页）

![八页页签条](此处贴图③)

| 页签 | 里面是什么 |
|---|---|
| **观棋** | 世界的正面：当前时局、在办的大事、此刻各方在哪、一条持续更新的动态流 |
| **编年** | 按轮次的史卷，五道筛（谋划 / 大事 / 牵动 / 暗处 / 时局）+ 因果链珠链视图 |
| **大事纪·旧卷** | 里程碑与已入卷的旧账，可点开阅卷 |
| **角色与势力** | 在册实体：影响力、四维、状态徽；按势力/状态/范围筛选与分页 |
| **设定** | 从书里抽出来的设定全文 + **每条的原文出处**；刻度与法则按类分段，**并如实标明哪些每轮真的进了模型眼前** |
| **参数** | 世界参数（玩家定档、引擎照抄）+ 世界尺度 7 个旋钮 + 开关；带**撤销** |
| **快照** | 每步留档、保留 15 步、一键回退；**只回世界账，不动你的对话** |
| **设置** | 世界设定来源、模型通道、旧卷与存储、导入导出、开始新世界 / 推进一轮 |

## 五、安装

**前提：你的机器上要装了 Git。** ST 的安装按钮背后就是 `git clone`，**ST 自己不会替你下载 Git**（ST 自己的安装页也写着这条）。没装的话先装 [git-scm.com](https://git-scm.com/downloads)，装完重启一次 ST。

### 方式一：ST 内建安装（推荐）

在 ST 里打开 **扩展 → 安装扩展（Install extension）**，把这个地址粘进去：

```
https://github.com/huangkun666/story-world-v2
```

（分支/标签那一栏**留空**即可。）装完 **硬刷新页面 Ctrl+Shift+R**。

### 方式二：手动克隆

```bash
cd <你的SillyTavern>/public/scripts/extensions/third-party
git clone https://github.com/huangkun666/story-world-v2.git story-world-v2
```

同样要 **硬刷新（Ctrl+Shift+R）**。

> **一句版本说明**：**方式一（内建安装）拉的是主分支的最新代码**，所以它总是最新的；Releases 页与 Code → Download ZIP 是**某一时刻的快照**，可能比主分支略旧一版。用哪种都能跑，只是想让你知道两者不一定同一天。

> **一个坑先说明**：插件**目录名必须是 `story-world-v2`**。上面两种方式都天然满足（内建安装的目录名由 ST 从仓库地址推导，正好是这个）；**只有从 GitHub 的 Code → Download ZIP 解压**出来的目录通常带 `-main` 后缀，那样面板会退化成一个小回退窗（能打开，但没有页签、没有内容）——请把文件夹改名成 `story-world-v2`。

装完记得看面板右下角的 **`构建 <版本号>`** 那行——**硬刷新之后它变了，才说明新版本真的载入了**（浏览器缓存是老朋友）。

**第一次用**：点输入栏左边的**魔杖图标** → 菜单里选「**观棋窗口**」→ 进「**设置**」页填模型通道 → 按「**✨ 开始新世界**」→ 最后进「**参数**」页把「**插件总闸 · 自动推进**」打开。总闸**默认是关的**：装上一个插件就让它自动跑，不礼貌。

## 六、★ 最重要的一句：装上之后，你的 RP 表现**不会变**

这一条我单独拎出来说，因为它最容易被误解成"插件没生效"：

**三个注入开关默认全是关的，插件默认不看也不动你的对话。** 你不开它，它就安安静静在幕后记账，只在观棋窗口里给你看。

为什么不默认开？因为**让"世界状态"每轮往对话里灌，剧情会越来越围着账本转**——叙事被账本殖民。这是设计选择，不是没做完。

而**即使你把三个开关全打开**，聊天模型拿到的也只是"名号对照 + 世界动向"这一点点，**不是账的全貌**；而且"世界动向"那段读的是**上一轮结算出来的**，**永远晚一轮**。

## 七、预览版 · 已知限制（请读完再装）

这是**预览版**——结构化的接口还会动，下面这些边界现在就存在。

**① 它没有取代世界书的权威性，两边可能对不上。**
聊天模型仍然照常读你的世界书（那是 ST 在组装提示词时塞进去的），而插件又**从同一本书里**抽出设定、建起第二套账——**两套真相并行，没有任何一处对账**。
插件**从不写你的世界书**（只读），所以分歧不是"插件把书改坏了"，而是两边各自独立地演；书改了也**不会自动重抽**（书指纹变了才会重新识别设定）。

**② 要长上下文模型。**
每轮输入是"世界账 + 名册 + 设定锚 + 上一轮的事"，几十 k 字符量级（单轮包预算 30k token），大书更甚。小上下文模型会降质。

**③ 每轮有成本、有耗时。**
一轮是一次**真实的主调用**（超时与输出上限在「设置」页由你填，出厂 120 秒 / 16384 token）；抽取那一步更慢，大书可能要跑几分钟。

**④ 记忆引擎只做了一半。**
打开「写进记忆插件」后，世界状态与大事会**逐字原话**投进「柚月の记忆」（不经过任何模型）；**没装那个插件就静默跳过**，面板不会告诉你它没投上。

**⑤ 世界书检索注入依赖别人的向量库。**
这一项要装「柚月の记忆」并启用向量记忆才有；没装 / 没开 / 维度不匹配时**静默跳过**，只损失资料补充，不影响正确性。

**⑥ 快照只回世界账、不回对话。**
回退一步之后，面板回到第 N 轮而对话还在第 N+5 轮——**没有统一的撤销**。

**⑦ 位置是自由文本。**
不建地名册、不做字面合并，账上没有真地点时如实写「未明」；**地理位置一致性不做保证**。

**⑧ 只在 SillyTavern 1.15.0 上验过。**

## 八、给想深入的人：零依赖、无构建、1078 条判据

`git clone` 下来**直接就能跑，不需要 `npm install`**——所以它不可能因为依赖漂移而坏掉。在插件目录里执行：

```bash
node --test                # 全量测试（本版：1078 / 1078，约 3 秒）
node demo/smoke-demo.js    # 合成冒烟：50 轮曲线 + 断言（不打模型、零 token）
```

引擎（`src/`）与浏览器侧（`web/`）里**没有一条裸模块 import**，也没有 `node_modules` 与构建步骤；「面板也要用的口径」一律从生产函数 import，而不是在渲染层再推一遍——**同一件事两处实现是这个项目最贵的 bug 类型**。
