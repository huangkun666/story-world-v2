## 0. 人话版：这会怎么样

现在的世界有个毛病：**齐步走**——每个势力每回合都在动，不管它值不值得动。这个细案给世界装上"分量"：引擎从每个实体的硬实力、职权、人脉、情报算出它这轮**值不值得动**。分量低的，这轮静默——不出主动作、不走盘算、不惹事，编年和注入里也没有它的动静；但它**被点名时可以应答**（谁打它、谁波及它、谁提到它，它就有机会回应）。长期静止的，分量随时间衰减——站桩的权力会萎缩，**玩家棋子同尺**：你十轮不发一言，你的分量照跌。分量上了真值以后，薄裁定按分量大小裁冲突（高分量压制低分量），感知掩码按"分量×情报×位置"决定你在 RP 注入里能看见多远的棋局。这一切都由引擎纯函数算，确定性、可回归——模型既不看见分量数字，也不参与计算（今后也不写低于阈值的实体）。世界第一次出现"谁这轮不值得动"。

## 3. 设计

### 3.1 分量公式与缓存（纯函数 `computeWeight`）

- **入参**：`attrs { hardPower, office, network, intel }` + 实体层（kind）+ 当前环境（张力量）。
- **出参**：`weight ∈ [0,1]` + 因果传播半径（影响范围）。
- **公式（提案，先冒烟曲线后复校）**：
  - 基础分 = Σ wᵢ·attrᵢ。层系数（提案）：人物 `(0.35, 0.25, 0.25, 0.15)`；势力 `(0.45, 0.35, 0.10, 0.10)`——势力更吃硬实力与职权；
  - 层级基线（提案）：势力层 ×1.5（宏大层天然分量大，对齐宏大层 ≤5 在飞上限语义）；
  - 环境修正（提案）：`envFactor = 1 + 0.2×(tension − 0.5)`（静态张力常量期；大势层真值后换）；
  - `weight = clamp(基础分 × 层级基线 × envFactor, 0, 1)`；
  - 传播半径（提案）：`radius = 1 + 3×weight`；影响范围 = 事件可波及目标数上限 `ceil(2×weight)`（位置距离未定义前，用波及目标数作传播范围的代理度量）。
- **缓存**：每 tick 结算末**全量重算**（实体数小，不做增量失效），写入 `ssot.weights`——观棋窗口（用户）、门控（引擎）、注入掩码（引擎）共用，**主调用输入不再含它**（§3.7 拍板点）。
- **客观性边界（本棒定性，dev-process 红线④落地）**：分量的"客观" = 确定性计算 + 有界输入。属性增量由模型提议、引擎边界钳制；引擎不参与的是"提议"，不是"上游数据"。

### 3.2 主动作权门控（纯函数 `gateWorldStep`）

- **静默判定（提案）**：`weight < TH` → 静默方。人物层 `TH=0.25`，势力层 `TH=0.50`。防全静默：**每 tick 至少 top-1 权重实体永不静默**（权重最高者恒活跃，世界永远有人在动）。
- **滤除规则**：静默方的 `actions` / `agendaAdvances` / `plot` 源新事件 → 在**校验之后、裁定之前**滤除（drop 集记 simLog 静默审计）；不记编年、不进注入——**双面无痕**。
- **触发例外（确定性："被点名可应答"，对齐 §4.1 拆环"伺机而动"语义）**：本轮输入（未决事件.ripples ∪ 其他实体 actions.target ∪ 玩家落子事实 object）含该静默方 id → 本轮解除静默（可应答）；应答不获得永续活跃——**下一轮重新判定**。静默方始终是合法客体：被打击/被波及照常落账（静默 = 不主动，不是消失）。
- **不改变**：满步强制结算（max_steps 到点照结，与分量无关）；拆环规则（低分量方先让，分量相等按阶段浅者先让）。

### 3.3 静止衰减（长跑细案 §2.3 并入）

- 引擎按实体记 `lastActiveTick`（有主动作落账或有触发例外应答的 tick = active）。
- **衰减因子（沿用长跑提案，用户已过目）**：`activityFactor = max(0, 1 − rate × (idle − grace))`；人物层 `grace=8 tick, rate=2%/tick`；势力层 `grace=20 tick, rate=1%/tick`。**玩家棋子同尺**。
- 应用点：分量重算时 `weight' = 公式分 × activityFactor`。**衰减作用于分量缓存，不改属性**——与属性保鲜（增量 Mutation + 熵泵）动量分离，各管一段。再次 active 后因子立即回 1。
- 验收衔接：V3。

### 3.4 感知半径与可见性掩码（换真值）

- **掩码公式（提案）**：`m(事件, 观察者) = clamp(weight_事件源 ÷ weight_观察者 × intelFactor × posFactor, 0, 1)`；
  - 情报因子 `intelFactor = 0.5 + 0.5×intel_观察者`（情报为 0 则见闻减半，满则近全见）；
  - 位置因子 `posFactor = 1.0（同位置）/ 0.5（异位置）`（位置集为符号，二元判定为当前能力上限，位置图入队列）；
  - **阈值 `m < 0.3` → 注入侧省略该事实**（行迹纪要式，预算友好）；`≥ 0.3` → 引入。
- **玩家棋子无特殊路径**：与任何实体同公式（分量低 → 对远事睁眼瞎，同尺）。
- **适用范围**：掩码只约束 **RP 注入侧**；观棋窗口全局可见（上帝视角是已拍板的用户权利，ANCHOR §3⑥）。
- 实施点：`src/streams.js` 掩码常量占位换真值（三要素：分量 × 位置 × 情报）。

### 3.5 薄裁定器分量化

- 现状：常量 A vs B，边界钳制幅度与双方无关。入位后：**硬结果幅度按动作方与目标方分量比裁**——
  - 高分量动作方 → 提议 delta 全量生效；低分量动作方 → `delta × (w_动作方 ÷ w_目标方)`（**幅度单调，V5**）；
  - 边界钳制（[0,1]）与警告语义不变。
- **只按量，不按冲突类型**——不新增分支，130 条旧债不穿新衣（ANCHOR 未决点 3 之魂）。

### 3.6 属性增量 ↔ 因果一致性烟雾报警（对偶于行动↔盘算报警）

- 世界步 `stateChanges` 增加**可选字段 `cause`**（事件 id / 盘算 id，schema + prompt 模板变更，**P4 拍板点**）。
- 报警两条（只报警、不拦截——与现有烟雾报警对齐）：
  1. **无 cause 的 stateChanges** → 警告（"写叙事不写状态"的坏账前置信号；硬拦截留给增量 Mutation 校验，长跑 §2.3 已定）；
  2. **方向与裁定相悖**（败方属性上升）→ 警告。
- 意义：给"客观分量"的输入侧装上方向可信度探针——钳制只卡范围，这条卡**方向**（本棒此前识别的链上最弱一环）。

### 3.7 演化上下文变更（拍板点 P3：模型不看分量）

- **现状**：`pack.js` 把 `weights` 喂给主调用（常量时代遗留）——与 ANCHOR §3③"模型看不到它、不参与它"冲突。
- **提案**：从演化上下文移除 weights；prompt 铁律 5 语义保留（分量与盘算决定谁值得动——概念可见，数字不可见）。隐藏后模型必然继续全员提议（它不知道谁静默）——**接受的代价**：主调用为全员付费（成本不变），换取红线干净；门控在引擎侧兜底。
- **未决**（入队列）：远期注入侧加"近况提示"（谁在动，而非谁该静）——防模型对空转世界的茫然，代价是推理泄漏，时机随大势层再议。

1. **P1 公式形态与系数**（§3.1：层系数/基线/envFactor/半径）：线性加权形态 + 初始系数，先冒烟曲线后复校（铁律 2/8）；

4. **P4 `cause` 字段**（§3.6：世界步 schema + prompt 模板变更，烟雾报警对偶所需）；
5. **P5 衰减沿用长跑提案值**（8 tick/−2%、20 tick/−1%，玩家同尺）；
6. **P6 感知掩码系数**（§3.4：m<0.3 省略、情报/位置因子）；
7. **P7 薄裁定分量化幅度**（§3.5：分量比折减、不堆规则）。
