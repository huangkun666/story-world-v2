# 观棋阅读布局

用户于 2026-10-02 确认本方案，依据三张实机截图：地点标题被关系文字挤成竖排、正文可视区域不足、展开故事线的边界不清楚。

## 已确认的设计

- 保留地点、故事线、事件的既有分组、归属、排序和近期窗口。蓝灰配色保留。
- 地点卡头分为地名、数量、跨地点关系三行。关系逐项排放并允许换行，地名不与关系争夺宽度。
- 世界现状默认收起详情，摘要显示原有世情读数。盘算栏变窄且可收起；专注阅读同时收起辅助区，再次点击恢复进入前的状态。桌面两栏独立滚动，窄屏仍整页滚动。
- 故事线保留原有默认展开规则。每条线有清楚的边框、间距和展开箭头；展开内容使用不同底色与缩进。事件按轮次、标题、说明排放，长标题及长说明正常换行。
- 提供字面关键词搜索、地点定位和只看未结故事。搜索包含地名、标题、角色及展开正文，多个词同时匹配，不生成新事实；未结使用已有线状态。清空检索恢复原来的展开状态。
- 同一聊天和世界刷新后保留检索、辅助栏状态、展开状态与滚动位置；切换聊天或世界重置。中文输入法组合期间不筛选、不替换输入节点。
- 重复的账目来源说明只保留页面的一份，所有故事与事件事实保留。

## 实现边界

`src/panorama.js` 只调整 HTML 结构和添加阅读标识；`web/page-compose.js` 组合摘要、工具行和既有两栏；新建 `web/panorama-reader.js` 管阅览交互。入口只在两个刷新点同步阅览状态，先恢复展开与筛选，再使用现有滚动恢复模块。

不改变账本、引擎、模型调用、提示词、参数或记忆窗口。无新增依赖。当前权威读数只写在 `STATE.md` §1。
