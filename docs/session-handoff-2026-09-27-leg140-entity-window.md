## 4. ★★★ 本笔最值钱的：**"元素建出来了"不等于"人看得见"**

### 4.1 症状与根因

**症状（用户原话）**：「**点击不了，没有窗口弹出我刷新了**」——点了**完全没反应**，而且**控制台一个字都不报**。

**根因（一行）**：`web/entity-window.js` 的 `open()` 里

```js
mask.className = 'sw2-window-mask sw2-ew-mask';   // ← 漏了 sw2-open
```

而 `web/style.css` 写死：

```css
.sw2-window-mask{ … display:none; … }
.sw2-window-mask.sw2-open{display:flex;}          /* 只有带这个类才显示 */
```

⇒ 窗口**真被创建了、真挂进了 `document.body`、六格内容真渲染了**——**但它是 `display:none` 的**。
**看不见，也不报错。** 与"点了没反应"逐字吻合。

### 4.2 ★★为什么 19 条判据一条都没咬住（本笔最该带走的一条）

| 漏在哪 | 实情 |
|---|---|
| 判据 ⑫ | 只断言了 `className` 含 `sw2-window-mask` 与 `sw2-ew-mask` —— **从没断言"打开态"那个类** |
| `isOpen()` | 查的是"**元素在不在 DOM 里**"——在，所以它一直说"开着" |
| 假 DOM | **没有 CSS** ⇒ 样式表说什么，判据一个字都不知道 |

⇒ **纪律（写进 `test/entity-window.test.js` 的 ⑳ 头注，别再犯）**：
**凡"可见性由样式表决定"的窗口/浮层，判据必须同时咬住两头**——
「那个类在不在」**＋**「样式表里那个类的含义是什么」（⑳ 就是照这个写的：先断言
`.sw2-window-mask{display:none}` 与 `.sw2-window-mask.sw2-open{display:flex}` 两条前置，再断言产物带 `sw2-open`）。

### 4.3 ★★★ 第二值钱的：**展示页偏偏是对的**

我在**展示页**（`docs/spec-entity-window-mockup.html`）的 JS 里写了 `mask.classList.add('sw2-open')`——
**所以展示页跑起来完全正常**，而生产那一份漏了。
⇒ **样板跑通了 ≠ 生产接线跑通了**——这正是**上一次交接里"最值钱的那一条"**（判据写对了 ≠ 生产接线对了），
**本笔当场又踩了一遍**。★下次凡"先出展示页再接线"，**接完线要把两份逐条对一遍差异**。

## 5. 做法与判据（含三处口径的来路）

### 5.1 窗口形态（用户当场改的）

**弹在页面上层**，而且**不另造窗口系统**：壳**复用**面板那套 `.sw2-window-mask` ＋ `.sw2-window`（leg101/102 定稿），
只补三样：① `z-index` 抬到 **51000**（与链浮层 `.sw2-cv-mask` 同一把尺）；② 窗口体自己滚
（`.sw2-window` 是 flex 列，子元素不写 `flex:1 + overflow:auto` 会被裁——leg101 治过的病）；
③ **尺寸**：`.sw2-ew-window{width:820px;max-width:100%;height:auto;max-height:86%}`。
★**为什么是覆盖而不是改基础规则**：`.sw2-window` 那条 `width:100% + height:calc(100vh - 40px)` 是**面板那扇窗**要的
（leg102 用户当时说「占满整个屏幕吧」）——**本窗口不该继承它，也不该去动它**。

**挂在 `document.body` 上**（不在面板窗口里）⇒ 面板开着关着都能看；**关闭三条路一处收口**（✕ / 点暗处 / Esc），
且 **Esc 走捕获阶段 + `stopPropagation`**（不拦的话按一次 Esc 会把面板一起关掉——与 leg93c 链浮层同一个坑）。
★**浮层里的按钮够不到面板的动作总线**（总线挂在 `#story_world2_window` 上）⇒ ✕ 必须**自己挂**（同链浮层那条留档）。

### 5.2 六格全部**现推**、零新写通道

| 格 | 从哪来 |
|---|---|
| 来历与身份 | 实体自己的字符串字段（结构键不摆进来）＋ `fieldSource`（每个值的出处）＋ `parent/branches/organs`（**带"怎么来的"**） |
| 变过的格 | `meta.entityFields[id].fields`（现值/原值/因哪件事/哪一轮；有 `prior` 优先用它） |
| 事迹 | `events.filter(e => e.ripples?.[0] === id)`（★`ripples[0]` 恒是主语，`settle.js` 写明的约定） |
