## 1. 病（用户截图 + 原话）

设置页底部那张「操作」卡里两枚按钮（`render.js:2358-2363`）：

```
<div class="sw2-set-card"><h4>操作</h4><div class="sw2-actions">
  <button data-action="init-world">✨ 开始新世界</button>
  <button data-action="advance-world">▶ 推进一轮</button>
</div>
<div class="sw2-hint">每轮对话后世界自动推进（总闸开着时）；此按钮是手动补推…（共 96 字）</div></div>
```

三处病：

| # | 病 | 证据 |
|---|---|---|
| ① | **要滚过四张卡才够得着** | 设置页是 2 列 grid（`style.css:630`），「操作」在**最后**；上面依次是世界设定 / 模型通道 / 记忆通道 / 旧卷与存储。它还是**面板上最常用的两颗**（开始新世界、推进一轮）。 |

## 2. 定案：动作条住**窗口外壳**，并与**页签同一行**

★两句话都是用户当场下的：先「**不是只有在设置页显示，而是整个窗口的上方**」，
随后否掉第一版形状（自己占一整行）——「**把这两个放在右边和页签同一行要不然太丑了太突兀了**」。

★关键判断：这两颗按钮是**世界级动作**，不是"设置项"。所以它属于**外壳**（`settings.html` 那层），
不属于任何一页的渲染产物；而版面上它与**页签同一行**。

```
┌ 页头（棋 · 观棋窗口 · 世界名 · 轮次 · ✕）─────────────────┐
├ 状态条 ────────────────────────────────────────────────┤
├ ★一行导航：8 个页签 ……………………………… ✨ 开始新世界 │ ▶ 推进一轮 ┤   ← 八页都在
├ 页体（各页自己的渲染产物；动作条不在其中）────────────────┤
└ 页脚 ──────────────────────────────────────────────────┘
```

★为什么是"外面再包一层"（`.sw2-navrow`）——三个形状里只有它成立：
· **直接塞进 `.sw2-tabs`** 不行：手机档把它设成 `overflow-x:auto` 的横滑容器 ⇒ 按钮会**跟着被滚走**；
· **折行**不行：窄窗时页签折两行、按钮浮在两行中间（实测 1024）⇒ 又变成"不同一行"；
· ⇒ 包一层：页签那侧 `flex:1 1 0;min-width:0`（缩得下去、装不下自己横滑），按钮 `flex:none` 钉在右端。

### 为什么住外壳而不是"每页各画一份"

| 理由 | 依据（源码实测） |
|---|---|
| **外壳不随页重绘** | 页体是 `el.innerHTML = out[name]`（`web/index.js:1427`）**逐页替换** ⇒ 按钮住页里会被反复销毁重建。 |
| ★★**长活儿的"正在跑…"因此才可靠** | `long-task.js` 靠 `[data-action="…"]` **按属性找按钮**并置 `disabled` + 改文字；它自己写着"面板会重绘，重绘会把那个按钮节点换掉 ⇒ 灰掉是尽力而为、**不是保证**"（`long-task.js:21-23`）。**搬进外壳之后那条免责基本不成立了**——节点不再被换掉。 |
| **一份定义，不是三份** | 画三份（页头/设置页/参数页）就是本仓最忌的"同一件事两处表达"。leg52 撤参数页那枚的理由正是"重复入口"。 |
| **交互零改动** | `data-action` 委托挂在 window 容器上（`web/index.js:2963 bindActions`）⇒ **按钮放哪都通**（leg96e §149 自己写着这条）。 |

### ★版面上那两处是**真机量出来的**（`F:/deepseek/tmp/leg162-ui/` 那套装置）

| # | 量到什么 | 治法 |
|---|---|---|
| ① | 手机 390：`.sw2-tabs` 只写 `flex:1` 而 `min-width` 仍是 `auto` ⇒ 自动最小宽度＝页签内容宽 ⇒ 实测**页签 780px、按钮右边缘 1033px**（窗口只有 384）——按钮被顶到屏幕外 | 基础规则补 `min-width:0` ＋ `overflow-x:auto` ＋ `flex-wrap:nowrap` |
| ② | ★病根：手机档那条 `.sw2-tabs{flex:none}` 让页签按**内容宽**撑开（780px 就是它） | 防护**上移到 `.sw2-navrow{flex:none}`**（它才是外壳定高 flex 列的直接子元素；强度一字未降） |

实测三档（桌面 1440 / 窄桌面 1024 / 手机 390）：**同一行 ✔ · 按钮在最右 ✔ · 手机档页签自己横滑 ✔**。

### 外壳那一段长什么样（形状定稿）

```html

  <button class="sw2-btn sw2-primary" data-action="init-world">✨ 开始新世界</button>
```

★它**不是**解释文字，是**状态**；与"总闸关着时状态栏要写出后果"（`plugin-master-switch.test.js:132`）同一条口径。
