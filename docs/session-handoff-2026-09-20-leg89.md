## 3. ★ 这一棒做出来的东西长什么样（下一任要维护的）

### 3.1 标签（给聊天模型的规范，注入原文见设计文档 §2）

```
【时长】三天
【场景：忘川渡口】
【行动】薛铁衣｜迎战｜黄坤
【行动】孟婆｜探查｜灵脉
```

- `【时长】`**累加**（可多次；插件**不做算术**、只并列成一段散文）；
- `【场景：X】`以下的地点由**最近的场景继承**；
- `【行动】`三格：**谁做的｜做了什么｜针对谁**（后两格可省）。

### 3.2 提取出来落到哪（三处）

### 3.3 名号归一（用户拍板「认得出就按插件的正名来看」）

## 4. ★ 本棒踩的坑（写下来免得下一任再踩）

1. **★★提示词文件里的反引号**（`src/prompts.js`）：`MAIN_PROMPT` 是 176→300 行的模板字符串，
   写入 `` `turnFacts` `` 这种带反引号的词**当场截断模板**；Node 报的是**导入方**（`worldstep.js`），
   `node --check` 又过 ⇒ 我连查四个文件才定位。**用全角引号「」。**
2. **`buildEvolutionPack` 的 opts 里不能写"条件展开"简写**：`{...(cond ? {a} : {})}` 是合法 JS，
   但 `{cond ? {a} : {}}`（我写的那种）**不是** ⇒ 当场解析错。显式建对象、逐键按条件 add。
3. **函数放错作用域**：`injSwitch` 第一版写进了 `renderParamsHtml`（那是**另一个函数**）
   ⇒ 运行时 `ReferenceError`，**22 条渲染判据当场红**。
4. **按钮不派发 `input`/`change`**（开关那个坑的第一层，见 §14.8）。
5. **`bus` 里注册了动作 ≠ 按钮收得到**（第二层）；**重绘要穿过两道护栏**（第三层）。
6. **导出的判据函数必须在 Node 里真能跑**：`sw2ToggleInject` 导出后一调就炸
   （`setStatus` 里 `document.getElementById`）⇒ 被自己写的判据当场咬住。**`setStatus` 已加 `typeof document` 守卫。**
7. **`extract.js:55-59` 有个走不到的老坑**（`find(...)?.name` 对 `undefined` 取属性）：`?.` 护不住它。
   本笔**没修**（那个方向已被用户否掉、生产恒空），登记在 §14.6。
8. ★**我自己的坑**：`git grep` 之类的命令里带反斜杠/引号会被 PowerShell 吃掉一层
   ⇒ **判断句写成 `.mjs` 文件再跑**（本仓 leg88 §6 第 5 条同款）。
9. ★★★**最贵的一个：`| Select-Object -First N` 会掐断管道、把还在写文件的 node 进程当场掐死**。
   本棒实测代价：`node leg89-ledger-insert.mjs 2>&1 | Select-Object -First 3`
   ⇒ `writeFileSync` 写了一半 ⇒ **`docs/ledger.md` 从 282 行 / 778KB 被截成 2 行**（整本台账没了）。
   恢复：`git -C F:/deepseek/plugins checkout -- story-world-v2/docs/ledger.md`（已恢复、已复核 282 行）。
   ⇒ **纪律：凡是会写文件的装置，输出一律 `> 文件` 重定向，或只看尾行；绝不用 `-First` 掐管道。**
   ★这条与"写坏了要先看损失再恢复"一样重要——本棒是先 `git status` 看损失、再从 HEAD 恢复的。
10. ★★★**往账上写新字段，必须先登记进 `ssot.schema.js`**（本笔实测代价）：
   `meta.lastInjection` 第一次写进去 ⇒ `test/backdrop-smoke.test.js` **当场红**
   （`$.meta.lastInjection: 未知字段`）——SSOT 是**严格 schema**（`additional: false`），
   引擎不许偷偷多写字段。★这条判据在正常干活，**别绕过它**：登记字段、不要放宽 schema。
11. ★★**我一个人做错、被用户骂了三件事，形状是同一种：把"理论上说得通"当成"事实"**：
   ① 那个开关六版：我读一段源码、推一个机制、就宣布"找到原因了"（§14.8）；
   ② ③世界动向：我**假设** `meta.lastInjection` 有人写（其实全仓零处写它）⇒ 做了个**死开关**；
   ③ 名册封顶 120 / 名单外的人丢料：**没依据就拍的决定**（§14.7）。
   ⇒ **纪律**：凡是"某格有人写/这件事会发生"的判断，**先 grep 一遍谁写它**；
     凡是真机行为，**验证之前不许说"找到了"**。
