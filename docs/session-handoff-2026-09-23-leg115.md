## 1. 病：账上"没有时间"这回事

### 1.1 人话版

这个世界每推进一步，都会在账上记一笔"发生了什么"。可是**它从来不记"过了多久"**：
账上每个读数都只有"第几轮"——那是**世界自己推了多少步**，不是"故事里过了几天"。

而"过了多久"其实是有人写的：**聊天模型自己在正文里写**（`【时长】三天`）。插件把这句话抽出来，
**当轮**递给世界那一步，然后……**就没了**。账上一个字都不留。

⇒ 后果：下一轮里，聊天模型想问"那件事是多久以前发生的？"——**账上答不出来**。

### 1.2 ★实测（你真账 `大荒z` · tick 61 · 只读副本）

| 查什么 | 结果 |
|---|---|
| `meta.simLog` 的全部字段 | `tick / packTokens / ssotBytes / events / chronicle / calls / warnings / silent / lifted / silentDropped / proposals / rejected`——**零时间字段** |
| 编年行有没有时长 | **0 / 382 行**（本笔之前没人写过那一格） |
| 聊天模型那侧收到什么 | 记忆桥两张表：「世界状态」1 条 + 「世界大事」60 条；每条的"什么时候"**只有「第 60 轮」** |
| 代码怎么写的 | `pack.js:1014` 原文：「**`elapsed` 是账外的料——引擎一个字都不解析它（账按轮走，故事按时间走）**」 |

### 2.1 ★★为什么"不做算术"是这一笔的命门

本仓最硬的一条红线（`STATE.md` §2.2 第 1 条）：**不许把书里的词换算成数**——书里的说法照抄成文本，引擎不换算、不进公式。
**时间归同一条管**：把「三天」「一炷香」「半月」累加成一个"第 65 天"，就是引擎**自己造了一个账上没有的数**。

⇒ 本笔只做两件事：**①原话照抄 ②把它归到哪一轮**（轮次账上本来就有，是事实不是换算）。
读者（模型/人）拿到的是「第 47 轮 · 此后又过了：三天」，**要累加由读者自己加**。

### 2.2 ★"六种方式"不是装饰（用户就问了这一句）

用户原话：「**检索的方式也不可能只有一种吧？**」⇒ 本层把"取哪一批往事"分成六条，各有用处：

| 方式 | 取什么 | 谁会用 |
|---|---|---|
| `recent` | 最近的（账只往后加 ⇒ 尾巴就是最近的） | 世界模型那一侧当兜底 |
| `entity` | 跟某个人/势力有关的（★**照关系取**：名字 / 他名下那件事的目标名 / 他牵扯的事件） | 面板"点一个人的线" |
| `id` | 照指针（给定事件/盘算 id） | 世界模型追因果链 |
| `keyword` | 按词命中 | 聊天模型想找"死煞那摊事" |
| `tick` | 第几轮到第几轮 | 面板阅卷一段 |
| `cause` | 照因果链上溯（一层层走 `source.ref`） | "这件事怎么来的" |

### 2.3 ★三条纪律（逐条照抄 `recall.js` 的既有口径，不新造）

1. **只读、零副作用**：本层不写账、不改入参（判据 `L7` 用"检索前后逐字节相同"锁死）；
2. **失败零阻塞**：没源/取不到/抛错 ⇒ 返回空批次，**永不抛**（判据 `L8`）；
3. **如实上报**：`reason` 必须分得开「**没命中**」与「**根本没在检索**」——★这条有血证：
   `START-HERE.md:1298` 记着「返空是静默的……界面分不出"没命中"和"根本没在检索"」（判据 `L9` 锁三态）。
