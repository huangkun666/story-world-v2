## 2. ★★★ 用户那一问的实测答案（本棒的技术核心）

**用户之问**：「**正文里有【…】呢？？不能包裹在一个标签里吗？？？**」

**逐字喂真提取器实测**（装置 `F:/deepseek/tmp/leg93-brackets-in-prose.mjs`）——两处**真会出事**的：

| 正文里长这样 | 实测后果 |
|---|---|
| 一句**以 `【行动】` 开头**的叙述（解说格式/举例子/被引用） | 被当成**一条真行动**（名字 = 整句话），落 `unresolved`/`notNoted` |
| 一句**以 `【时长】` 开头**的叙述 | `elapsed` **收下一整句话**（实测「这个词表示时间流逝。」） |

★**第二条更重**：`elapsed` 是"账外的料"，**引擎一个字都不校验**（`pack.js:964`），
它**原样进世界模型的 prompt**（`prompts.js:222`）。

**根因一句话**：认不认得出标签**全看 `【` 在不在行首**——正文与标签**共用同一个语法空间**，没有边界。

★**同时实测证伪了"包裹有用"**（这条最要紧）：旧实现逐行扫全篇，
代码块与 `<tags>` 包裹**一点都不影响结果**（包裹行只是被判"其它一律不看"）。
⇒ **光让模型包裹、不改解析器 = 白包**；甲案正是把"包裹"从无意义的壳变成**真正的边界**。

**安全的那几形态**（实测都没事）：行首 `【系统提示】`/`【叮】`、行中 `祭出【九幽雷罡】`、行尾 `念了一句【敕令】`。

## 3. 甲案的形状（改的是哪些字）

| 情形 | 行为 |
|---|---|
| 有块（开围栏行**整行只有它**：三反引号 + `tags`） | **只扫块内**；块外的 `【…】` 一律当正文 |
| **没块** | ★★**退回逐行扫全篇**（`mode:'all'`）——**老账、老聊天逐字节不变** |
| 块没闭合 | 吃到正文末尾，标签**照样读出来**（`closed:false` 如实标出） |
| 围栏行不干净（后面还跟字） | **不算开块** ⇒ 退回逐行扫 |
| 块空着、真标签在块外 | **就是不认**（代价面，判据 ㉔d 锁住让维护者看得见） |

★**为什么必须留"没块就退回"**：模型漏写围栏时，"**整轮零标签**"比"少认几条"严重得多。
★**代价面（如实登记）**：标签写在块外 ⇒ 不认。这一面由注入规范那段硬要求兜
——**规范判据与提取器判据是一对，缺一不可**（㉔ 与 ⑪ 分居两处，别只改一头）。

## 7. ★★★ leg93c（同一会话追加）：事件链改走浮层

**用户令**：「**事件链条点击后不要放在编年页了，直接弹出一个小窗口，要不然我在大事纪页签点击还得回到编年页**」

**根因（源码可证 · 在接线层、不在渲染层）**：旧 `bus['open-chain']` 把渲染好的链视图
`insertAdjacentHTML('afterbegin')` 到**写死的 `#sw2_view_chronicle`**；而「链」按钮在**两处**
（编年页 + 大事纪·旧卷页，C-1 两个入口）⇒ 从大事纪点，内容却进了**另一个页签**
⇒ 玩家看到"点了没反应"，得自己切回编年页。★`renderChainViewHtml` 一直是好的——错的是**把结果塞到哪儿**。

**修法**：链视图进一个挂在 **`document.body`** 上的浮层（新常量 `CHAIN_MASK_ID`）——
不在面板窗口里 ⇒ **面板开着关着都能看**；`z-index:51000` **高于面板那 50000** ⇒ 一定浮在面板之上。
内层是**一字未改**的链视图，只给它一个壳。

| 关闭路径 | 说明 |
|---|---|
| 链自带的「收起」按钮 | `chain-close` → 同一处收口 |
| **点背景** | 点弹窗内部不关（不然想看细处一点就没了） |
| **ESC** | ★**捕获阶段 + `stopPropagation`**——面板自己有一条"ESC 关整个窗口"，不拦会把面板一起关掉 |

★★**最容易漏的一处（判据专门锁它）**：面板的动作总线 `bindActions` 挂在 **`#story_world2_window`** 上，
而浮层挂在 `document.body` ⇒ 浮层里的 `data-action` **永远走不到那条总线**：
链自带的「收起」与各处的「阅卷」（`.sw2-goto`）会**点了没反应**。
⇒ 浮层自己挂一条同形状委托；「**阅卷**」**先收浮层再切页签**（否则浮层挡住玩家正要去看的东西）。

**判据**：`test/render.test.js` 新增 leg93c 一条，锁**接线层**（照 leg55 先例）——
正面要有 `CHAIN_MASK_ID` 与 `document.body.appendChild(mask)`；
**反面**（对着用户症状）**不许再出现 `sw2_view_chronicle`、不许 `insertAdjacentHTML` 到页签容器里**。
★**咬合演练**（`F:/deepseek/tmp/leg93c-bite-drill.mjs`，**仓外复制整包再变异**）：改回"插进编年页"⇒
`fail=1` 且**红在 leg93c 自己身上**；还原后全绿；**生产文件哈希未变**。

**升位**：`PANEL_BUILD` → **`leg93c-chain-popup`** · `CSS_VERSION` → **`20260921-leg93c-chain-popup`**
（★样式真的动了 ⇒ 按纪律必须升）。★原 `CSS_VERSION` 停在 **leg89**——leg90/90b/91/92/93b 都没动样式，**那不是漏升，是没动**。

★**未做（登记）**：浮层固定 820px 居中，**没做**位置记忆与拖拽；链视图将来若长出别的动作按钮会走 `dispatchAction` 兜底。
