### 2.2 ★★三个把我拦住很久的坑（留档，别再踩）

1. **`globalThis.indexedDB = {...}` 会静默无效**（`window.indexedDB` 是不可赋值的访问器属性）
   ⇒ 必须 `Object.defineProperty`。**headless Chrome 里真 IDB 的 `open()` 永不回调**
   ⇒ 不换掉它，`loadWorld` 会**永远挂在 `volumeStore().list()`**（面板根本画不出来）。
2. **中文文件不许用 PowerShell 的 `Set-Content` 落盘**：`node build.mjs` 用 Node `writeFileSync(...,'utf8')`
   —— 我用 PowerShell 转手一次，**中文注释被吃掉了半行，整份 JS 语法崩**（本仓 leg28 那次血的教训同源）。
3. `--dump-dom` 在 `window.open()`/定时器场景下**不按 `--timeout` 等** ⇒ 让测试页用
   `document.title` 立刻可见地写结果，别指望"跑完再 dump"。

## 6. 下一棒可选（**都不是必须的**）

   （`commit` 之后、`ensureChronicleRotated` **之前**）。若世界对象是"载入链**后半段**才成型"的，

   ⇒ 已定稿：**"世界一到就补"**——`loadWorld` 里**每一处拿到可用世界的地方**都补一次
   （轮转失败那条 `rot.hot` 也补）。幂等、无变化零写、判据仍全绿、真浏览器复验照旧五步全 9。
1. **`loadWorld` 为什么会在用户机器上跑不完**——本棒已经让它**出声**了（`console.warn` + 状态条），
   但**没有修它**。它一旦失败，现在只影响"镜像晚一步"，不影响玩家改档位。若用户报"引擎好像没按我的档跑"，
   就从那一行日志往下查（IDB 卷库 / 快照链 / 取书）。
