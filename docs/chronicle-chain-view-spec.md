## 0. 人话版：这会怎么样

现在编年是一整卷流水账：一条事件的来龙去脉要自己脑内拼，想看「暗处的谋划」也没处筛。本细案两把刀把史卷变成可读可组织的东西：

1. **看因果（纵向）**：每一条事件都能打开它的「来龙去脉」——往上是它从哪来：哪盘谋划生的、沿哪件事牵来的、还是由世界处境而生，一路追到根（追进大事纪也不断：更早的段落给你留了翻旧卷的门）；往下是它惹出了什么：牵动了哪几条线、每条线又牵动了什么，一路铺到枝梢。
2. **筛史卷（横向）**：编年页顶部五把筛子——谋划/大事/牵动/暗处/时局。想看暗处就看暗处，想追一条波及线就只看牵动。旧账（本细案之前落下的行）不藏：任何筛选中都照常显示、并告诉你还有多少条旧账没分类。

全程零创作零预测：引擎只把已有的事实链展开拼句，一个字不新编（「走向预测已裁」保持），叙述润色继续延后（YAGNI）。

## 2. 范围限制（本棒不做，防漂移）

- **润色叙述**：链视图/筛名零模型调用、零创作（数据=事实拼句）；叙述润色沿用 YAGNI 延后（T3-D1 同哲学）；
- **动态流/位置速览加筛**：五筛只在编年页（twostream §3.2 原文口径）；
- **阅卷视图加筛**：旧卷原文原样展开（读卷是动作，不是过滤面）；
- **链视图全文自动跨卷**：链展开只到里程碑纪节点，旧卷内全文=阅卷按钮动作（卷是冷档，不自动载入）；
- **深链裁剪/分页**：链=数据不是文本，账内全量展开（环防保终止）；若实测超长链渲染卡顿，另行入队（触发=实机冒烟）；
- **历史行不补章**：旧行/旧卷行不 retro-kind（账不可篡改）；编年裁剪不做（既有队列项不变）；
- **导出面**：kind 随 SSOT 自然入导出包（编年行在 SSOT 内），零新工作；导入旧包无 kind 行=旧账规则（§3.1③）；
- **实体治理主线**：K37/K38 与本细案零依赖、可并行；施工序自 K39 起，不占用主线序号。

### 3.2 因果链展开器（引擎层新模块 `src/chain.js`，拍板点 C-1/C-3）

`expandChain(world, rootId)` → `{ok, chain}`（纯函数、输入不可变、确定性）：

```
chain = {
  root:  { kind:'event', id, title, position, closed?, born, children:[...] },
  up:    [ 节点 ... ],     // 上承 = 单一路径（事件源单一：ripple→事件 / plot→弧线 / state→终节点）
  down:  [ 树节点 ... ],   // 下沿 = 全分支森林，每节点 { … , children: [……] }
}
```

节点种类：`event`（标题/事发/闭环徽/出生轮）/ `agenda`（弧线卡）/ `milestone`（纪卡）/ `state-root`（「由世界处境而生」）/ `gap`（悬空：「沿旧事而来」）/ `leaf-note`（纪内余尾收敛卡）。

- **上承**：root.source.ref 逐级——ripple → 上游事件节点（递归继续）；plot → **盘算弧线节点**：agenda 卡（owner/目标/明暗徽/阶段/进度 N/maxSteps/**结局徽**（在飞 | 已了结 | 已终止[blocked 尾条以「放弃」开头]）+ memory.done 尾条 1 条 + blocked 尾条 1 条 + **委派链**（parentId 上溯至顶，各自成卡）+ **产果事件清单**（source.plot.ref===a.id，按出生轮序，逐条可继续展开）——弧线本体上溯到此为止（盘算=动作源头）；state → 终节点；ref 落空（events/milestones 均无）→ 悬空节点「沿旧事而来」（正直展示，不猜）；
- **里程碑穿透**：
  - 上承遇归档段（upId 未命中 events → milestones.ids 命中）→ **纪节点** `{id, span, counts, titles, ids}`：纪卡（N 件事 · 首尾轮）→ 沿 `m.links.up` 每个 id 递归（别的纪→继续纪节点；仍热事件→事件节点）；m.links.up 空 → 「纪之源头已不可查（旧账）」终节点（如实，不发明）；
  - 下沿遇归档段（root.id ∈ 某纪 m.links.down）→ 收敛节点「另有 N 条在旧卷（纪 m_x）」 + 阅卷按钮；
- **盘算弧线下沿**：未 closed 且 parentId===a.id 的子盘算（树形委派的继续）——按 id 序；深链不设限（ANCHOR §4.1 深链合法），环防保终止；
- **排序纪律**：事件节点按出生轮序（id 契约解析 bornTick，同轮按序号）；盘算按 id 序——确定性；
- **防御**：未知 rootId → `{ok:false, error:'无此事件'}`；空世界/无事件 → 防御态；人工环（互指）→ seen 剪断 + 「（环防：至此为止）」；所有行走 seen 有界 → 复杂度 = O(热事件 + 里程碑)。

### 3.3 渲染（渲染层 render.js，拍板点 C-1/C-2）

- **编年页筛选**：`renderChronicleHtml(world, {oldVolumes, filter})`——filter = kind 集合（null/缺省=全选）；顶部 chips 行（`sw2-ch-filter`：全部 + 五筛，玩家词，多选高亮，`data-filter`）；行选择规则：无 kind 行恒显示；带 kind 行 ∈ filter 才显示；里程碑插行（`sw2-ch-roll`）恒显示；筛选激活且存在无 kind 行 → 底部提示「另有 N 条旧账未分类，始终显示」；

### 3.4 编排接线（编排层 web/index.js，拍板点 C-3）
