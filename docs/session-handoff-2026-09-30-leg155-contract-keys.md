### ★★ `axis` 那一族的真相（本笔最该带走的一条）

**账上 463 条 `axis`，逐条看下去：全是 `""`**（有值的 **0** 条）。
根因在 `mergeSameTierEntries`：它先给每条挂上 `axis: String(x?.axis ?? '').trim()`，
而"**单条**"那一支是把这一格**原样递出去**的（`out.push(g[0])`）⇒ 空串顺着 `scalesToFlat`
落进了 `canon.powerScale`，而**下游一个读者都没有**（`axis` 是去重键，不是账字段——
`abstract.js` 与契约里那两处注释都明写"**不是一回事**"）。

★**两种病必须分开说**（这是本笔最值钱的一条判断）：
- **"漏登记"** ⇒ 补登记，**别动引擎**（引擎写得对，只是尺子不知道）；
- **"写了个空壳"** ⇒ **堵产出**，**别把空壳登记成合法**（那等于把"空着就是空着"这条纪律签字作废）。

★**同场一处如实登记**：`test/scales-concept-table.test.js:211` 原先写死了
`[{ level: 'X1', note: '唯一', axis: '' }]`——**那条判据的意图是"单条不动"**（别被合并掉），
那个空串只是**照抄了当时的产出**。本轮把期望值改成 `[{ level: 'X1', note: '唯一' }]`，**意图一字未动**，
并新增一条反证的反证（**真轴仍要留着**，修的是空串、不是把这一格删了）。
⇒ ★**"判据把 bug 冻住了"这件事本仓又栽了一次**：它写的时候是对的（照实描述），
  但它让"这个空串"变成了**有判据保护的行为**。

### ★★ `nextVolume` 那一族（只在长局里出现）

`rotateChronicle`（`src/storage.js:89`）在把编年旧段落成卷时，会在**留下的那份世界**上写
`nextVolume = 本卷号 + 1`；而那一份**就是热账**。四份真账最长那份 tick 59、**一次都没轮转过**
⇒ 逐个核它们时一次都照不到它。本笔是拿 leg153 那份 **400 轮长账**（跑完 249 卷）做向量那一族的
"引擎侧验收"时浮出来的——**判据用的是真产生者**（`planChronicleRotation` → `rotateChronicle`）。

★**同场如实登记一处不对劲**（本笔只登记、**没动流程**）：同一个数目前**有两个家**——

## 7. ★★ 两版插件：能不能同时跑？（用户问的那一件，查实后的答复）

1. ★**为什么"改分支"这条换不出社区版**：ST 的分支下拉（`src/endpoints/extensions.js` 的
   `/branches`）是拿**那个文件夹自己的 git 仓库**去 `git fetch origin` 再 `checkout`。
   而部署位是 **junction → 工作目录** = monorepo `F:\deepseek\plugins`（远端 **`story-director.git`**），
