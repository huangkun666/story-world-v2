# 解耦清单 · story-world v2（第二十三棒 · 只列减法 · 待拍板）

> 性质：**减法清单**。不提新机制、不加新层；只问一句「这条信息该住在哪」，然后把重复的、可由书现场回答的，标出来准备删/停。
> 起因（用户 2026-09-10）：「我们现在搞了这么多会不会有点太复杂了？」→「对的我们需要解耦」。
> 病根诊断：**同一份信息存了两处**——世界书里有一份（作者写的），我们的账本里又抽了一份（我们抽的）。
> 两份必然对不上（抽取有损耗），于是每处对不上都配一套补丁：标签一套、关系轮一套、属性轮一套、位置又要一套。
> 这正是 ANCHOR §2 记的旧病：旧项目 24 天 / 525 提交 / 130 条边界，死于"计划追着实弹问题跑"。

## 0. 人话版：这会怎么样

现在这台引擎像个"抄书员"——它把整本世界书抄成一张精确的表格，抄错一个字就要修一次。问题是：**聊天模型从来不抄书，它用到哪一条就现场读哪一条，读得还挺准。**这份清单要做的事只有一件：**把"抄书"这部分从引擎里拆出去**，让引擎只管它自己算出来的东西（谁分量多少、谁在谋划什么、发生了什么），书上的事（谁归谁管、谁在哪、什么来历）——**问到再查书**。

拆完之后：抽取流水线可以大幅变薄甚至停掉；引擎的账本只剩它自己产生的演化。**账和书各归各位，不再互相抄。**

## 1. 一条规则定归属

> **凡是世界书里已经有的，账本不再存；问到再查。账本只存"引擎自己算出来的"和"玩出来的"。**

- **书**：名号、类别、隶属、所在、统治者、机构、来历、种族……（作者写的，只读，不动）
- **账本**：分量、盘算、事件、编年、状态变更、实体的 identity 标记（引擎算的、玩出来的）

判据（拿不准时用）：**这条信息如果丢了，引擎的结算会不会错？**
- 会 → 归账本（必须精确，值得投入）
- 不会，只是"说不清它是谁、在哪" → 归书（现场查，查到就用，查不到就含糊过去——跟聊天一样）

## 3. 乙类：要你拍一下（拆得干净不干净，就看这两条）

**乙1 · 引擎需不需要"提前知道世界上有哪些名号"？**
- 需要（现状）：因为要建实体、算分量、分配镜头
- 不需要：实体**第一次在场上出现时**再登记（名字+类别即可，不用抽全书）——账本按需长
- 我的建议：**改成按需登记**（书里的名号表就是"名录"，不必抄进账本）

**乙2 · 位置要不要精确到"第十二重天·朝天殿"这种细粒度？**
- 掩码用的是"分量 × 位置 × 情报"——**位置只需要粗（同层/异地），不需要精确到殿**
- 我的建议：**粗位置即可**（天层/洲域一级），细粒度现场查书

## 4. 丙类：必须留（引擎自己算的、玩出来的）

| # | 东西 | 为什么必须精确 |
|---|---|---|
| 丙1 | **分量**（谁强谁弱） | 决定"谁值得动、冲突空间、你能感知多远"——引擎的骨架，必须确定性、可复现 |
| 丙2 | **盘算**（谁在谋划什么） | 世界自转的燃料，玩出来的，书里没有 |
| 丙3 | **事件与因果链 / 编年** | 玩出来的，书里没有 |
| 丙4 | **实体身份标记**（id / 名字 / 类别 / 状态） | 账本的主键；不精确就串账 |
| 丙5 | **分量公式的入参口径** | 拆掉属性轮之后，初始分量从哪来必须重新定一个口径（见下） |

**丙5 的难点（诚实登记）**：分量公式吃四维属性（硬实力/职权/人脉/情报）。**拆掉属性轮，这四维的初值从哪来？**
三条候选，待拍板：
1. **书里的档位标注**（大荒书自带 T1-T16 阶）——**书里有就用书里的**，比手拍浮点诚实（这也是"词档版 K50-K53"的本意）
2. **同类默认**（现在的兜底）——诚实但扁（所有人都一样）
3. **现场查书**（第一次登场时问一次）——最省事，但引入非确定性

## 5. 拆完的架构（三段，各归各位）

```
世界书（只读，不动）        账本（引擎所有）           现场查（用到才做）
─────────────────         ────────────────          ────────────────
名号 / 类别 / 隶属           分量 / 盘算 / 事件          "界渊长城归谁管？"
所在 / 统治者 / 机构          编年 / 状态变更             "瑶池在哪一层？"
来历 / 种族 / 阶标注          实体 identity              → 书里那几条现场读，读到就用
```

**接口只有两个**：①记账（引擎→账本）②查书（引擎/渲染→书）。**书和账本之间不再有第三条"抽取"管道。**

3. **乙2：位置粗粒度足够**（推荐）／必须精确到殿
4. **丙5：初始分量口径**——书档位（推荐）／同类默认／现场查
