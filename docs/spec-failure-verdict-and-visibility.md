### 1.1 八本书的结构供给面（`demo/audit-design-candidates.js`，零 token）

| 综漫-春物 | 19 | **0** | 2 | 2 | 31 |

- **凡是把"位置"当必要条件的机制，只是少数派能力**：三国（最结构化的一本，742 条成员行）地名条目 **0**。
- ⇒ 可见性方案**不许**建立在位置上；位置继承的"安全"必须由**结构闸**保证，不能靠"大多数书都有地名表"。

### 1.2 「败露」的输入面（合成跑 50 tick + 契约实读）

| 实读项 | 结果 | 含义 |
|---|---|---|
| `hurtWindow` 写入方 | **0**（仅剩"旧账残留滑零自删"） | 判据输入不存在 |
| 真账（563 实体）`hurtWindow` | **0 个** | 同上 |
| `agenda` 对象上的 `source` 键 | **不存在**（`source` 只在出生时用于编年措辞，**不落账**） | 想判"源事件是否了结"必须回头翻编年文本 ⇒ **词表判语义**，触否决线 |
| 父盘算终结时 `parentId` | **被 `delete`**（`settle.js:345/387`，诸子断链转独立） | "父已终结"这个状态在账上**不会和子共存** ⇒ 该判据不可达 |
| 50 tick 合成跑 | 盘算 **1** 个、满步终结 1 个、`memory.done=3`、`memory.blocked=0` | 「起手未动」样本 **0 例**；"计划完成"与"计划推进过"在实测里**同时为真** |

**结论：引擎手上没有任何"计划被打崩/被反驳"的客观输入，也没有任何"计划落空"的记录方式。** 这不是"判据没写好"，是**输入不存在**。

## 2. X1：盘算满步终局

### 2.1 四个候选

| 候选 | 内容 | 代价 | 否决线 |
|---|---|---|---|
| **A · 认账简化** | **删掉「败露」这一支与 `VERDICT_HURT_THRESHOLD`（死参数显式废弃）**；满步终局改称「**结清**」（不带褒贬），把"达成"这个引擎**无权下**的判断收回来。"未竟而终"由**模型提议取消**那条既有通道承担（K22 已实施：模型提议放弃 + 引擎裁决 + 编年 + 托孤） | 删代码；面板/编年措辞少量改动 | ✅ 全通过（只减不加，零新数字） |
| **B · 另立"伤害"记录** | 造一个不依赖四维的"损伤"记录（如"被覆灭/被夺产"事件波及）再判败露 | **要新造一连串东西**（记什么、怎么记、阈值多少） | ⚠️ 触碰「宁缺勿造」；且四维被删的理由（手拍值装精确）会原样回归 |
| **C · 结构衰减** | "计划存在太久且毫无进展"判败露 | **要新造 N**，且"时间久"≠"败露"——引擎替世界宣布它不知道的结论 | ⚠️ 触碰「占位值/手拍数字当判据」 |
| **D · 读世界书找反动势力** | 从书条目里找对立名号，对方有动作则判败露 | 要**读书正文**，且"谁跟谁对立"是语义、引擎判不了 | ❌ 违反「把某本书的文本形态当必要条件」 |

### 2.2 推荐：**候选 A**

**为什么它最挑不出毛病**——它是唯一一个**不需要引擎知道它不可能知道的事**的方案：

- 引擎是**账房 + 史官**，不是裁判。「达成」是**对世界下判断**（"这事办成了"）；而引擎能证明的只有"**步数走完了、没人拦**"。把它改叫「**结清**」不是文字游戏，是**把结论收回到引擎的职权边界内**——与红线 1「引擎不裁胜负」同源。
- "未竟而终"**已经有通道**（K22 取消：模型提议 + 理由 + 引擎裁决），不需要第二套。
- 删掉死参数而不是留着，消灭"看着有机制"的假象。
- **代价**：面板上不再出现"败露"字样（现在也不会出现——它本来就不可达）。**零功能损失**。

**要你拍的一点**：「结清」这个措辞你认不认？（备选：「结算完毕」/「期满」/保持「达成」但编年措辞改为"期满结算"。）

### 2.3 如实留档：初稿两条判据已被推翻

| 初稿判据 | 为什么不能做 |
|---|---|
| A1"源已了结而事无进展" | `agenda` **不落 `source`** ⇒ 要判它得去解析编年里的「因事而生：…由「X」生…」文本 ⇒ **词表判语义**（禁用清单第三条） |
| A2"父盘算已终结" | 父终结时 `parentId` 已被 `delete`（诸子断链转独立）⇒ **该状态在账上不与子共存**，判据不可达 |

**这两条是我在写细案时凭"契约应该有这么个字段"想出来的，复核实读当场否掉。** 登记在此，防重走。

## 3. X3：可见性掩码

### 3.1 现场

- `MASK = { posSame: 1.0, posDiff: 0.5, threshold: 0.25 }`，`isVisible = m >= threshold` ⇒ **两个取值都过闸**。
- 唯一消费面：`streams.js` 的 RP 注入（带 `eventRef` 的编年行）。
- 已定口径：观棋侧**全局可见不变**（你的权利，ANCHOR §3⑥）；本体玩家棋子必须存在，否则降级"全见"。

### 3.2 四个候选

| 候选 | 内容 | 代价 / 问题 | 否决线 |
|---|---|---|---|
| **A · 删掉掩码** | 注入侧不再做可见性过滤——观察者看得见全部世界动向，把这个**事实**写明 | 放弃"信息不对称"的设计意图 | ✅ 只减不加、零新数字 |
| **B · 让位置真能挡** | 阈值提到 `posDiff` 之上（>0.5） | ①**要报批新阈值** ②位置是**二元量**：挡=整条不见，粗得像开关 ③§1.1 已证位置输入只在 **2/5** 本书上有 ⇒ 其余书全员"同地"、掩码**恒真如故**，白改 | ⚠️ 拿少数派当通用 |
| **C · 未知位置取中立** | 只改"事件没给 position"这一种 | 只治边角，**不解决"两个取值都过阈"这个主问题** | ✅ 可作 A 的附带合并，不单独立项 |
| **D · 位置改为"换形态"** | 异地不给细节、给"远方风声" | 要新写一套**措辞模板** ⇒ 新机制 + 越界（笔归 LLM，引擎不写叙事）+ 仍依赖位置那 2/5 | ⚠️ 形态依赖 + 越界 |

### 3.3 推荐：**候选 A（删掉掩码）+ 把 C 的边角一并合并删掉**

**为什么它最挑不出毛病**：一个**改不动任何事实**的参数，留下的唯一作用就是让人以为这里有个机制。删掉后注入侧只剩一件可验证的事："玩家能看见带因果指针的世界动向"（答：全部），与观棋侧全局可见**同向**——**不制造两套真相**。

**必须说清的关系（你的两问本是两个问题）**：
- 「败露」判的是**盘算结局**（写在账上）；删掩码判的是**玩家能不能看见动向**。**互不影响。**
- concealed 盘算的编年抑制（K21）**照旧**，不随本细案改动。

**若你坚持保留不对称**，那正确答案是**回到数据**：先回答"**玩家这枚棋子在书里的位置到底有没有意义**"——§1.1 的答案是 **2/5**。为少数派的书留一个全局开关，正是你那条线要拦的东西；真有需要，应做成**该书有地名表才生效、无表即"不生效（全见）"**的加分通道（形态判据只能加分——唯一被实测证通用的骨架第④条）。

## 4. X2 / X4：位置缺失口径 + 占位值算不算"有值"

### 4.1 X2 · 位置缺失该取哪一值（拍板题，但**当前无后果**）

三选一：**同地** / **异地** / **中立**。
- 现法 = 异地（口径"不因数据缺失放宽可见性"）。
- **实测事实**：因为 X3 的掩码恒真，**这三个取值在今天的成品里没有任何可观察差别**。
- ⇒ **建议**：随 X3 候选 A 一并把这段判断**简化掉**（不再需要"缺失取哪一值"这个概念）；若你选保留掩码，这条才需要真拍。

### 4.2 X4 · `location` 的占位值（`'未明'`）算不算"有值"

现在：`ENTITY_LOOKUP_FIELDS = ['实力','位置']`，而 `位置` 这一栏查的是**中文键** `entity['位置']`，账本用的是英文键 `location` ⇒ 两条路的口径**不一致**（实测：`missingFields` 报缺"位置"的是 **563/563**，而 `location` 有占位值 **563/563`）。

| 候选 | 内容 | 后果 |
|---|---|---|
| **A · 不动** | 保持现状（位置继承已零 token 吃到 173） | 零成本；但"位置"这栏仍在查书名单里，**真去查就会烧模型** |
| **B · 占位值不算有值** | 让 `location === '未明'` 计入"缺" | 语义更正；但会让 390 个实体**真的进入模型查书队列** ⇒ **花钱**，不是代码问题 |
| **C · 摘掉"位置"这条查书腿** | 既然零 token 的结构推断已经吃到 173，剩下的 390 个是"书里没写驻地/写了但不是地名"（如 `幽都` 的「轮回破碎后亿万魂魄滞留所建」）⇒ 查也查不出 | **最诚实且省钱**：不再假装"查书能补位置" |

- **实测支撑 C**：`幽都` 的条目驻地是描述句、归一化拿不到集内地名 ⇒ 留空（宁缺勿造正确生效）。这类"书里确实没有地名"的实体，**送进模型也是白烧**。
- **要你拍**：A / B / C 选一（我推 **C**，与"空着就是空着"一致）。
