## 0. 人话版：这会怎么样

我们想把一台"程序化的世界模拟器"变成一部"**自己会转的编年史**"——不是你输入它才响应，而是：**对话作证，模型判案，引擎记账执法，焦点跟着历史的重心自己流动**。本篇是这台机器的设计蓝图的讨论纪要，以及我们还拿不准、想请人集思广益的问题清单。凡未拍板处均显式标注。

## 1. 机器现状（30 秒）

- **形态**：Node 纯源码、零依赖、无构建；每回合 = 一次主 LLM 调用输出"世界步"（八组 JSON：actions/newEvents/agendaAdvances/stateChanges/newAgendas/agendaCancels/newEntities/entityFates），引擎校验 + 结算 + 落账 + 编年 + 双流渲染（RP 注入 / 观棋窗口）。

## 2. 蓝图四根柱子（本轮收敛的核心）

1. **史书**——世界只有**一本账、一部编年史**（单史，非多线并发）。势力是棋盘，角色是棋子，都是"活在书里的人"。
2. **史官（引擎）**——只做两件事：**记录**（一切落账、永远可查 = 连续性）与**执法**（无源之物不存在、有戏才在台上、人走线不断）。
3. **证人（对话）+ 时钟**——玩家的对话是输入事实（账吃对话、对话不改账）；**时间刻度也归对话宣示**，引擎只推演时间的后果。
4. **镜头（渲染）**——视角是阅读层的：RP 注入跟人（可见性掩码），观棋窗全知眼，史书详略由"重心"决定。两双眼睛，一个世界。

## 3. 本轮攻下的七个难点（问题 → 收敛结论）

> 标【实码】= 读过代码的结论；其余为推演（讨论中未实测）。

### 3.1 耦合 / OOC 分裂 —— 事实呈堂，裁决在席

**问题**：实机观察到"NPC 台词演了、账上另安排"（OOC 分裂）。根因【实码】：世界步调用的上下文**不含场景台词**（pack 只有结构化世界状态 + 一条玩家落子事实）——不是"世界自相矛盾"，是**世界根本没听见**。

**收敛**：所有场景信息只以"带出处、零权威的**事实**"进入上下文（玩家落子 / NPC 断言 / 时间声明 / 依据册摘要）；**事实只改处置（记账、盘算记"受阻"重排），不改裁决（判决只出自引擎结算）**。黑名单方案（提取台词角色名→本轮冻结该实体）经推演为**死结**：冻结 + 台词行动不入账 = 每次露脸即静止、行为断层；且把对话抬成对账本的否决权 = 台词中心化（主角中心化的镜像，旧 v1"对话窗=最高准绳"已作废）。

### 3.2 客观性天花板 —— 与自己过去一致，而非真值

**问题**：分量公式确定性【实码】，但喂公式的属性全部由模型提议、引擎只做边界钳制。"更接近客观"如何成立？

**收敛**：两个旋钮——**调参**（公式输出贴着提案跑：系数/衰减/钳制）与**历史盘问**（每个新提案过已落账的过去的对质：无源拒、重名拒、覆灭复核已是雏形，再往前是跨通道一致性校验）。诚实边界：LLM 媒介里没有独立测量，可逼近的是"**与自己过去一致**"，不是真值。

### 3.3 身份连续性 —— 人物常驻簿

**问题**：预算剪枝、归档压缩后，"白小娥还是不是白小娥"？每轮模型从被剪的上下文重新推断人格 = retcon 温床（本项目红线原文："幻觉记忆比遗忘更糟"）。

**收敛**：**人物常驻簿**——引擎所有、模型不可自由改写：一句话画像 + 关系簿 + 承诺簿 + 积怨簿；只在封闭时刻（事件落账/闭环/断言登记）由引擎发起更新，空转轮绝不重写；与既有簿矛盾的提案过盘问、不静默覆盖。**两级实现控成本**：零调用层（引擎从已落账文本确定性拼账本画像，永远兜底）+ 低频层（每 10–20 轮批一次小调用更新 ≤8 名实体画像，可并入既有提取调用 = 零新增请求数）。

### 3.4 时钟 —— 对话宣示时间，引擎推演后果

**收敛（用户拍板方向）**：对话宣示时间增量（"三个月过去"）→ 引擎按增量推演后果（静止衰减 × 增量、熵泵按增量脉冲、在飞盘算按增量推进）。**一致性优先于自转**：有玩家的世界里，回合外不自动演化——自转会制造"时差裂隙"（玩家回到一个他没见证过的世界）；回合内引擎按自己的规则动（熵泵/衰减/盘算推进=结算的一部分）。旁观者式自转属于另一个无人对话的模式，不混用。

### 3.5 涌现验证 —— 观测台 = 找死的仪器

**问题**："在转"与"被讲"短期不可区分（两者输出相似）。怎么证明世界是活的？

**收敛**：观测台**不拿去证明活着，拿去找死**——死处比活处好测：**引用解析率**（盘算/事件/承诺都查得到吗）、**拒绝统计**（引擎对模型说"不"的次数——剧本写不出被拒，每一次拒绝都是世界重力的证据）、**矛盾考古**（扫编年找"承诺了 A 却干了 B 且中间无受阻/无事件"= 自动化 OOC 体检）。世界死了的迹象（断线、遗忘、承诺无下文）是最好测的，找到死处修活它。

### 3.6 实体生命周期与饥饿 —— 名册/舞台分工 + 分量地板离席

**问题（用户提出）**：实体该依附 agenda——整个盘算消失就该下场，不该等 20 轮没被提到才退。

**收敛 + 补丁**：
- **名册/舞台分工**：舞台 = 有在飞盘算或被引用者（"有事缠身才在台上"）；名册 = 在位简表（名字+分量+朝向），**名册不设座**，装得下全书名册；下舞台 ≠ 除名（可复归）。
- **分量地板离席**（关键新件）：分量衰减由引擎算【实码：静止衰减 character 宽限 8/每 tick −2%，faction 宽限 20/−1%】，编剧写什么都不能阻止不动的实体掉到地板(FLOOR=0.05 提案)以下；掉穿 + 无未决引用 → 强制离席，盘算走承继三通道。打崩≠灭（分量归零仍是合法客体，K7 回归）——地板以下是名册位，不是死。
- **入场 = 候补通道 + 破裂放席**：新人只有被点名/入书名录（依据册/书名录=候补排队），然后等结构破裂腾席（汇点事件/覆灭/降格/强制结算）；"席位已满"是**可见摩擦**不是静默失败。
- **待拍板**：席位政策——统一 32 席 vs **分池**（势力席/角色席分池，防势力占席挤角色）。

### 3.7 子势力折叠 —— 分支不做实体，做盘算的归属限定

**问题（用户提出）**：旧插件抽象了 100+ 势力，大量势力互为父子。若都当独立实体：席位被碎片占满、父子同框行动违背常理、**分量失真**（父势力拆成 5 个子势力各算各的，每个都矮一截）。

**收敛**：**分支 = 盘算的归属限定**（盘算加可选 branch 字段：派系张力 = 同实体、异分支的盘算之间的张力，天然是暗盘算/concealed 的舞台）；**升格/降格通道**（分裂/吞并事件落账 → 该分支盘算整体转主给新实体 = 承继协议原样搬家；三家分晋/田氏代齐是历史原型）；提取阶段净化折叠（书名录提出名单后引擎按归属并成 ~十几二十个实体 + 内部分支表）。

## 4. 叙事结构重构（本轮转轴）

- **不追求并发多视角**：多视角叙事的底座是并发（同一时间段多线并行），本引擎无此底座，强做 = 假装。改**单史多幕**（县志）：一部史书按事分卷，人是各卷的演员，卷不是为演员开的。
- **多视角 = 阅读层**：掩码（RP 注入跟人）+ 观棋（全知眼）。世界只有一本史书，视角是给读者的。
- **收束 = 账本级**：线程在里程碑里聚合，不在世界里相遇；**预设汇聚点 = 预写结局 = 提线木偶**（推演否决：无论汇聚点由模型设还是引擎设都不行——模型设 = 编剧预写剧本，引擎设 = 机械决定论）。改为**给场不给点**（共享地点/共享事件/引擎偶尔酿的汇点事件 = 相遇的可能）＋**相遇必记录**（两线当真撞上 → 引擎落一笔账本交会点，进大事纪）。
- **焦点从实体剥离**：实体退场不再"交镜头"（A 的镜头交给 B 是笨拙的接戏）；**焦点 = 账本热度重心**——由已存在数据算出（新鲜度 × 重量 × 密度；因果指针聚类成"事簇"= 一卷，热度前 N 簇进 pack）。用途四件：①预算分配（焦点卷吃细节，其余吃简表——"史官详写哪卷"的机械形态）；②镜头（观棋/动态流重心卷显眼）；③幕（重心移动 = 封卷 = 里程碑+综述，**幕不是导演指令，是重心移动的记录**）；④观测台（焦点漂移速度/封卷频率 = 世界在转的读数）。**玩家对话也是热度输入**——能拨重心，不能当焦点主人。
- **活起来 = 写得活 + 护得住**：五件体感——①它记得你（记录活过剪枝）；②它有自己的事（你到场时大事已进行到一半）；③你的选择真的改变它（因果链传出去）；④它会拒绝你（席位已满/覆灭复核拒绝=世界的重力）；⑤它会惊讶你（引擎的两种选择：压平它 = 杀死活气，让它成立 = 保护它）。**引擎造不出活气，只负责不让活气死掉；活气是模型写的，"写得好"不在任何机制的控制里。** 规则护因果、不规定剧情（旧引擎死于 130 条边界——不是规则太少，是规则裁到了剧情头上；纪律是自由的资产负债表）。

## 5. 模拟流程（实体级）

**【tick 一圈】** 对话 → 提取三证词（玩家落子 / NPC 断言 / 时间声明）→ 记账（依据册点名计数/断言登记）→ 打包（焦点卷细节 + 名册简表 + 大势块张力/环境 + 证词段）→ 主调用八组提议 → 校验（schema + 语义：无源拒/重名拒/位置/玩家拒/覆灭复核）→ 结算（分量重算、事件落链、盘算入账、入局 ≤1/轮+席位检、覆灭需刀+处置、离席判定）→ 编年落行（kind 盖章+链指针）→ 渲染（RP 注入掩码 / 观棋全知眼+重心标记）→ 热账写回、超阈值冷档压卷。

**【幕一圈】** 焦点线收束 / 编长阈值 / 汇点事件 → 封卷（里程碑+综述行）→ 重心移动 → 预算翻转 → 幕界审计（交会点、孤线=0、引用解析）。

**实体级示例**（江州小世界）：tick N 玩家催白小娥的债 → 依据册 count+1（账吃对话）；大虞盘算推进产事件"官军出城引发恐慌"落账 → 白小娥被波及（分量 −0.02×比值）但静默合法；薛铁衣暗盘算照常推进（编年落 shade 行）。tick N+12 白小娥连续无动作 → 静止衰减过宽限逐轮 −2%【实码】→ 掉穿地板且无引用 → "白小娥 淡出"（下舞台进名册）；玩家日后再点名 → 依据册计数再涨 → 模型可提议 dialogueFact 源入局 → 复归。tick N+20 薛铁衣暗盘算败露产果 → 若无"刀"（别人已落账的覆灭源事件）则进名册，有刀且线程已处置则覆灭（dead 终局）。

## 6. 生态位速记

| 生态位 | 势力 | 角色 | 分支（派系） | 名册居民 |
|---|---|---|---|---|
| 一句话 | 棋盘 | 棋子 | 棋子上的纹路 | 候场棋子 |
