## 0. 人话版：这一棒发生了什么

用户报了「世界散成一地部门」，我按上一棒的任务书走了"结构落地"。中间做了实测（真模型 43→48 条关系、原句逐字命中 100%），写了代码（照书办：书用标签声明的结构照抄），也验出了病根（27 条声明里 7 条被判成地名、3 条没进册）。

**但用户连着几轮把整套方向推翻了**，最后收敛出一个**更简单的设计**：

1. **引擎不裁胜负**——因为"能力不在战力维度上"（神通、法宝、免疫），引擎要裁就得堆规则＝旧项目那 130 条边界的老病
2. **引擎不需要任何"谁强谁弱"的数值**——不裁胜负之后，那些数一个用户都没有了
3. **数值降级为 LLM 可选的自我笔记**——不填也不影响世界跑
4. **账本不再是书的副本**——书随时可查，账本只记"算出来的 + 玩出来的"
5. **重心＝盘算**；盘算从【事件 / 父盘算 / 实体处境】来；熵泵（引擎确定性，零模型）不停制造摩擦推动重心流转

**本棒最值钱的产出是这套设计定案**（`docs/design-core-leg23.md`），以及**一次诚实的减法**：砍掉四维浮点、全量名册抽取、整条抽取流水线、引擎的裁定与分量。**落地的 5 片切法已定，一片未动。**

## 3. 设计定案（**本棒的真正交付**）

### 3.1 三者分工

| 角色 | 职责 | 绝对不做 |
|---|---|---|
| **世界书** | 原料 | 不被引擎写、不被抄成副本 |
| **引擎** | **账房 + 史官**：记账、守连续性、守身份、管盘算生命周期、算能见度 | **不裁胜负、不算战力、不排序、不发明事实** |
| **LLM** | 读者 + 提议者 + 笔：查书 / 每回合提议 / 撰写 / 拾玩家落子 | **不记账**（落账前一切只是提议） |

**承重墙**：写账只有引擎能做。

### 3.2 账本记六项（多一项都不加）

身份（名字+类别，主键，不能缺）· 位置（粗粒度，查书，缺=「未明」）· 归属（查书，**缺就空着**）· 标尺档位（**书里的原话**+依据，缺就空着）· 状态（模型提议+引擎校验）· 事件（同上）。
另有本来就属账本的：**盘算**与**编年**。

**三条硬规矩**：①**空着就是空着**（不许填默认值冒充客观——倒挂/75% 全默认的病根）②**不裁胜负，但拦矛盾**（上轮说过的这轮不能翻）③**每条变更留痕**。

### 3.3 数值的最终处置（用户拍板）

- 引擎**一个世界数值都不需要**（不裁胜负/不排序/不掩码算分）
- **熵泵自己算**（纯引擎确定性锯齿，每 3 tick 一步，零模型——`src/entropy.js` 实读确认）
- LLM 填数值 → **降级为可选自我笔记**（唯一用途是"自己前后一致"，而引擎不裁胜负后这已不重要）
- **保留一条不可选**：**环境指标必须从书里抽一次真实初值**（否则四个都 0.5 → 熵泵要摆好几步才够到危险线，前期世界太平）
- 熵泵的机械参数（步长/危险线/回缓线）**全部早已报批定案，跟世界设定无关**——换书不改代码

### 3.4 重心机制

**重心＝盘算。**来源只有三条（顺序不可反）：**事件 / 父盘算 / 实体处境**（无源之物不存在，ANCHOR §4.2）。
书只能给"势"（张力），**给不了盘算**——盘算是"下一步要干什么"。

**流转闭环**：熵泵（引擎，确定性）→ 处境事件 → 生盘算（挂因）→ 盘算驱动行动 → 状态变化 → 新事件。
**重心是"长"出来的，不是排出来的。**

### 3.5 数值的替代度量（无数字）

| 想知道 | 改看 |
|---|---|
| 盘算重不重要 | 挂了几条因、牵动几个实体 |
| 角色在不在重心上 | 出现在几个在飞盘算里 |
| 事件大不大 | 波及多少实体状态变更 |

**全是"数个数、看牵连"，没有"谁强谁弱"。**
