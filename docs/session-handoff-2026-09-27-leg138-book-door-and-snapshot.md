### 4.1 ★★★ P1：回档那条链是坏的（**已逐字复现**，而且**不报错时更坏**）

**病**：`web/snapshot-store.js:177`

```js
sw2SnapChain = { seq: p.nextSeq, anchorId: p.anchorId, anchorSeq: p.anchorSeq, anchorWorld: snapshot };
//                                                                              ^^^^^^^^ 应是 p.anchorWorld
```

`planStep` 的注释把这条不变量写得很明白（`src/snapshot.js:284-291`）：
**「delta 必须相对"锚点世界"算，不能相对"上一步世界"算」**，而且它**返回值里就有** `anchorWorld`。
接线层把返回值丢掉、塞进了**当前世界** ⇒ 从**第 3 步**起：差值是"上一步→这一步"，却仍挂着**原来的锚**
⇒ 恢复 = 锚 ＋ **错的差**。

**症状两种，都复现了**：

| 情形 | 结果 |
|---|---|
| 那份错的差**碰到了**基准里没有的路径 | **报错**：`恢复失败（快照链不自洽，世界原样不动）：路径 meta/entityFields 在基准里不存在（快照链不自洽）`——★**与用户屏幕上一字不差** |
| 那份错的差**没碰到**缺的路径 | ★★**恢复"成功"了，但少 7,141 字节**（整个 `entityFields` 块没回来），面板照样印「已落盘」⇒ **玩家退回一个从来没存在过的世界，看不出来** |

`anchorWorld = p.anchorWorld`。⇒ **判据全绿，但它量的不是生产那条接线**（本仓记过的那条病）。
