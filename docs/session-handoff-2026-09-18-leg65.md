### 1.3 ★"判断依据"的边界（本棒量出来的一课，已写进提示词口径）

第一版机械分类规则 = 「有数字 **且** 有比较符/阈值词」⇒ **实教 18 条判据 0 条**——
而实教恰恰是**机制最密**的那本（`1CP=100PP` · `及格线=班均÷2最高50分` · `期考加分10万=+1分`）。
同样漏掉大荒的 `跨1境: 必败` / `装备品阶不可超越自身境界两阶，否则反噬` / `强行越层进入=被天道法则当场碾碎`
——**一个阿拉伯数字都没有，却是货真价实的判据**。
⇒ 口径改成：**①带具体数** 的 ∪ **②带明确条件** 的，并明写"**第②类最容易漏**"。
修正后同一个机械分类器：实教 0→**6** · 三国 1→**7** · 大荒 54→**70**。

★另一面（**别把内容禁令当判据**）：第一版把 `严禁生成【顶级】与【超一流】势力` 收进了判据——
那是"不许写某种势力"（**内容禁令**），不是"拿它判这一轮谁强谁弱" ⇒ 已列为反例。

### 1.4 ★两道闸的单位教训（**本棒第一版就错在这里**）

第一版 `RULE_PACK_TOP`（条数）= 40、字符闸 = 4,000。实测当场暴露：

> 大荒 **70 条判据平均只有 50 字符** ⇒ **条数闸先于字符闸咬住** ⇒ 只进 40 条 / 1,852 字符，
> **静默丢掉约 27 条真判据**——而字符闸（4,000）明明还差得远（真需要 3,477）。

⇒ 改成：**主闸 = 总字符**（4,500，直接映射包预算）· **条数闸只当荒谬上界**（160 = 真账规模两倍）。
★这是 `刻度` 那条教训（`SCALE_TABLE_TOP_PACK` 头注）的**同族**：**用错的单位去封顶，会从结构上把预算卡死**。
★已立判据锁：拿真账规模（70 条 × 50 字符）的夹具喂进去，**一条都不许被条数闸砍掉**。

### 1.5 老账口径（用户拍板）与它的**可验证后果**

老账没有 `ruleKinds` ⇒ **一条不进包**（零迁移：不猜、不重抽、不按关键词瞎分类）。
★**直接证据**：冒烟 **8231 字节 · PASS · 警告 0**，与 leg61/62/63 **逐字节相同**

### 2.1 ★契约形状（为什么**不是**交接建议的 `{文, 类}`）

```js
rules: ['法则1（原文）', ...]                 // 仍是纯字符串数组 —— 一个字的原文都不改
ruleKinds: { '法则1（原文）': '判断依据' }     // ★leg64 新增（可选）：原文 → 类别
// 模型侧交的输入 = 按位对齐的并列数组： 判据: ['判断依据', '文风禁令', ...]
```

| 方案 | 代价 |
|---|---|
| `rules: [{文, 类}]`（交接 §3-A 的字面） | `rules` 的字符串形态被 **9 处**依赖（`dedupeRules` 同形键 · `mergeCanonChunks` 并集 · `render` 法则卡 · `pack` 进包块 + **8 个测试文件的固定夹具**）⇒ 一次真契约变更 |
| **本棒：并列一格 `ruleKinds`** | 与 leg63 的 `源` / leg62 的 `刻度` **同一种加法**；信息量完全相同 |

★**三条口径**：① 类别只认**词表四值**（`判断依据`/`文风禁令`/`变量指令`/`其他`）——契约层放行、**净化层收口**；
② 老账 ⇒ 不进包且**键不出现**；③ **分类只有一处实现** `classifyRulesByKind`，**面板与进包共用**
（leg63 那句不准确的文案就是"渲染层自己推一遍进包口径"的产物）——这条有**源码锁**。

### 2.2 ★去重之后类别要重挂到胜者身上（设计时推演出来的洞）

`dedupeRules` 合并"互为前缀的近义两版"时**留最长的**，而类别按原文串挂 ⇒
若模型给短版贴了 `判断依据`、给长版贴了别的 ⇒ 胜者**拿不到判据类别** ⇒ **那条判据静默进不了包**
（正是本棒要治的病换张脸回来）。⇒ `keyByPrefix` 兜底重挂（先精确命中，再按前缀）。
⚠ `dedupeRules` 有 **45% 长度差阈值**（有意留的）——夹具长度差超了它 ⇒ 两条都留下、判据假红（本棒踩过）。

### 2.3 两条设定通道的口径（leg62 的坑不许重演）

`RULE_CLASS_GUIDE` **一处定义**，`buildRosterPrompt`（名册遍）与 `buildSettingOnlyPrompt`（设定遍）
**都展开同一份**。★为什么必须：leg62 的病正是"概念表口径只加进名册遍那一份"⇒
「只重抽设定」抽不到任何概念表（用户实机报「重抽出来的设定很简洁」）。
本棒这一格同样有两条通道要吃它 ⇒ 判据锁着**两条提示词里都有 `判据`**。
