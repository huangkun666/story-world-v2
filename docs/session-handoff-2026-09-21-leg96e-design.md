## 1. ★★★ 点 · 线 · 面 四层（本棒的设计主菜）

```
大势   ── 书里写定的局面（一句，原文措辞；引擎只读）
  └ 此刻：N 处有事发生 · 全书 M 条线（还在往下长 x · 挂着没了结 y · 已收场 z）   ← 活数，机械算的
面     ── 一个地方（事的 position）
  └ 面头：几条线在这里交会 · 几件事发生在此 · 与别处相连：某某 → 哪几处
线     ── 一条故事（事件的连通分量）
  └ 线头：名字 · 第 A–B 轮 · N 件事 · **那枚徽（三态，一个数都不带）**
  └ 线身：主使 / 这条线也伸到了 / 与这一处别的线共享的人 / ★他一步步是怎么做的 / 代价
点     ── 一件事（时点）：第 N 轮 · 事名 · 来路 · 地点 · 牵动的人（**一个字都不说状态**）
```

**每一层从哪来（不许新造数据）**：

| 层 | 取自 | 性质 |
|---|---|---|
| 大势 | `world.context.setting.frozen.canon.situation`（书的设定层） | **前提**，不变 |
| 面 | 事件的 `position`（自由文本，**不建地名册、不做字面合并**） | 事实，每轮变 |
| 线 | 事件的连通分量（`ripple` 边 ＋ 同一主人 / 已实现于 `panorama.js`） | 事实 |
| 点 | 事件自己的格子 | 事实 |
| ★桥（原"块"） | **同一个实体出现在 ≥2 个面**（`ripples` 是实体号，牢） | 关系，不是层 |

### 1.1 ★ 面的立与不立（真账标定的判据）

1. **一个地方装 ≥2 条线**才**立起来**当一个面（A 局 3 面 · B 局 11 面）。
2. **只装 1 条线的地点**（"单线地点"）→ 作为**「这一处另有 N 件单独发生的事」**列在它所属的那个面里，**地名照印**。
3. **从不经过任何面的线**（A 局 12 条 · B 局 1 条）→ 进 **「各处散落」**，**照印它的事发地**。
4. ★**归属按线算一次**（一条线只有一个落脚的面）：按"地点"推会把**同一条线的两个单线地点推两遍**（本棒当场踩到：`大虞龙气外泄` 重复）。

### 1.2 ★★ 桥（面↔面）：账上现成的，一根不用编

| 局 | 面 | 桥（横跨 ≥2 面的实体） | 面↔面对 | 面图 |
|---|---|---|---|---|
| A（60 轮） | 3 | **6 个**（`大虞` 横跨 3 面） | 3/3（100%） | 连成 **1 块** |
| B（11 轮） | 11 | **17 个**（`渡虚帝` 横跨 4 面） | 8/55（15%） | 连成 **6 块**（含 3 座**孤岛**） |

★桥的例子（这就是"面之间相互组织"的答案）：
`渡虚帝` → `长城 · 界海 · 鬼门关 · 界渊长城` ｜ `东胜沧洲 ↔ 东海` 共享 **6 人** ｜ `大虞 ↔ 大虞皇陵` 共享 4 人。
★**孤岛也有信息量**（`北俱荒洲`/`东海迷雾群岛`/`忘忧凡川`）：它明说"这块现在跟别处没关系"。
★**杂质要剔**：`ripples` 里**混着地名当人名**（`界渊长城`、`大虞` 被当成"人"）⇒ 桥的名单要**只留角色/势力**（判据：名字本身在 `context.positions` 里、或驻地等于自己名字、且 `kind !== 'character'` ⇒ 视作地点，不当桥）。

## 2. 用户两个追问的答复（都验过真账，不是推理）

### 2.1 「面之间能够相互组织吗」——**能**，靠 §1.2 那两种桥

面当节点、**共享的人**当边 ⇒ 账上直接连成"块"。**面头上印一行** `与别处相连：渡虚帝 → 界海 · 鬼门关 · 界渊长城`，点得进去即可。

### 2.2 「能让大势直接统领面吗」——**不能**（两条硬原因）

1. ★**大势是一句话，句子收不了条目**：A 局 **31 字**、B 局 **72 字**，**各自只切成 1 句**（内部是**顿号并列**＝属性罗列，不是几个局面）。
   要它当一层就得**先做语义切分**——正撞用户定的红线「**引入机械就一定要避免让代码去理解语义**」。
2. **大势是"书的原始设定"，面是"账上算出来的"** ⇒ **前提不能收纳事实**（否则就是「拿一句话冒充一个结构」，与「还开着」「这个 7」同一族）。

★**大势与面的真关系 ＝ 对读**（B 局实证）：大势句写着「**高原准圣无终借天道碎片寄生系统宿主蚕食大荒气运**」，
而 `渡虚帝` 横跨的 `长城/界海/鬼门关/界渊长城` **正是这句话的兑现** ⇒ **大势给"何故"，面给"何处"**。
★A 局则相反：大势句（`复苏历：黄金大世…`）**完全没提**那场 `大盘谷` 大会战 ⇒ **它是世界里自己长出来的**。
⇒ 这一条**本身有信息量**：「**照着演**」与「**长出来的**」之差，读者看得见。

### 2.3 顺带查清的一件事：`浪尖` 不能当中介层

`浪尖`（`setting.dynamic.derivedFrom`，顶层谋划落幕时推一条）真账读数：**A 局 20 条（全部对应的谋划都已收场）· B 局 0 条**。
⇒ 它是**历史层**（讲办完的事），不是导航层；**新世界里整层是空的**（B 局 0 条）⇒ **拿它当组织层，11 轮的世界里就是个空架子**。

## 4. ★ 观棋／说书并页：本棒查到的全部事实（下一任动工前先读这节）

**用户令**：「**观棋和说书其实是一个东西吧，不如就合并成一页也简洁些**」。

### 4.1 两个页签现在各装什么

| | 说书（`panorama`） | 观棋（`board`） |
|---|---|---|
| 渲染入口 | `src/panorama.js` 的 `renderPanoramaHtml(world)` | `src/render.js` 的 `renderBoardHtml(world, opts)` |
| 形态 | **字符串**（自渲染） | ★**五块对象**：`{ digest, infoband, agendaStrip, feed, side }` |
| 内容 | 大势（本棒新设计）→ 面 → 线 → 点 | 时局句（digest）· 信息带（infoband）· 盘算总览（agendaStrip）· **动态流（feed）** · 位置速览（side = 地图） |
| 交互 | 无（纯只读） | 动态流/裁定栏等（`data-action`） |

### 4.2 ★★ 动工必须知道的四条约束（踩了会红）

1. ★★★**`panorama.js` 是「零 import 的真叶子」**：`test/module-layout.test.js` 锁着**模块数 = 46** 与"**它不 import 任何东西**"（那条注释逐字写着 `render.js → panorama.js` 是**唯一一条边**）。
   ⇒ **两条路**：(a) 把并页的组合做在**接线层**（`web/index.js` 那个 `for (const name of SECTIONS)` 循环里把两块拼起来）——**推荐，不动模块图**；
   (b) 让 `panorama.js` 去 import 别的模块 ⇒ **必须同步改 `module-layout.test.js` 的模块数与依赖边**（改之前先想清楚是不是真需要）。
2. ★★**`board` 是五块对象，直填 `innerHTML` 会渲染成 `[object Object]`**：接线层 `web/index.js:432` 用 `BOARD_BLOCK_ORDER.map((k) => out.board[k]).join('')` 拼。**并页时那一段拼装逻辑要么沿用、要么一并搬走**。
3. ★★**页签清单在这三处**：`web/index.js:145` 的 `SECTIONS = ['board', 'chronicle', 'panorama', ...]`（**删掉 `panorama` 要同时处理 `renderAll` 的 `panorama:` 键与 `#sw2_view_panorama` 那个容器**）；
   `src/render.js:2309` 的 `panorama: renderPanoramaHtml(world)`；以及**各页签标题的中文标签**（观棋窗口那颗按钮在 `web/index.js:326-327`）。
4. ★**按钮走 window 级 `data-action` 委托**（`web/index.js:2932`）：所以**观棋那几块挪进哪一页，交互都不会断**——但★**设置页的「推进一轮」**是另一条路（leg66 那笔把"要推请按观棋窗口的推进一轮"统一过口径），**并页后要复查那句提示还指不指得到**。

### 4.3 并页的建议口径（本棒的设计意见，供下一任裁量）

- **主层就用本棒的四层**（§1）；**观棋那五块降为"附层"**：
  · `digest`（时局句）**与"大势"是同一件事的两种说法** ⇒ ★**只留一个**（大势句是原文措辞，digest 是拼装句 ⇒ 留大势，digest 那句兜底话并入"此刻"那一行）；
  · `feed`（动态流）**留着**——它是"最近发生了什么"的流水，四层里没有对应物；
  · `infoband`（信息带）**留着**（参数档位/张力，四层里也没有）；
  · `side`（**地图**，按实体驻地聚合）**留着**——★注意它与"面"是**两把尺子**：地图按"**人驻在哪**"，面按"**事发生在哪**"；**用户已裁"地图先不改"**，所以**别顺手改它**，并页时**只搬位置不动口径**；
  · `agendaStrip`（盘算总览）**留着**（它是"在办的事"，线那一层讲的是"已经发生的事"）。
- ★**判据要跟着搬**：`test/panorama.test.js` 那一族（说书①～⑨）咬的是 `renderPanoramaHtml` 的输出；并页若改了它的调用方式，**先确认那一族还咬得住**。
