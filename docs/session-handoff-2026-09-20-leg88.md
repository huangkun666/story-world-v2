## 6. ★ 本棒踩的坑（写下来免得下一任再踩一遍）

   而 `objectId || object`、`extractCtx: {}` 这种带竖线的代码**必须转义成 `\|`**。

   **改用脚本插入 + 落盘前先算格数**（装置在 `F:/deepseek/tmp/leg87-ledger-*.mjs` / `leg88-*.mjs`）。
2. **幂等保护不能只按子串判**：leg87 那一行的文案里就写着"见 leg88" ⇒ `includes('leg88')` **误报"已插入"**。
   ⇒ 要认**行首的棒次**（`/^\|\s*20\d\d-\d\d-\d\d\s*\|[^|]*(第八十八棒|leg88：)/`）。
3. **`git checkout <commit> -- 多个文件` 里只要有一个 pathspec 不匹配，整条命令不生效**（一个文件都没改）。
   ⇒ 分批 checkout，并用 `git diff <base> -- <file>` **逐件回读自证**（本棒靠这个才发现第一次"以为撤了其实没撤"）。
4. **`git status --short` 的暂存列**：`M ` = 已暂存、` M` = 仅工作区。当时差点把"src 四件已还原"看成"还有修改"。
