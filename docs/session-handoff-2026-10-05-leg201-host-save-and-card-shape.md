# 宿主保存层、卡形状读法与"环境自检"交接

接手先读 `STATE.md`，当前测试数、构建号、样式版本、冒烟与入口行数见其 §1；"还剩哪些活"见 §0.5 指向的 `docs/work-current.md`。

本棒由**社区三条实机报告**驱动，用户逐句令：①「推送吧」②（看了调试页截图之后）「太多了，就放在复制报告里就行了，别展示出来」③「交接」。**三条报告分属三个完全不同的层**——把它们当成"同一个 bug 反复出现"会一直追错方向：

| 谁 | 报什么 | 是哪一层 | 结论 |
|---|---|---|---|
| 社区甲 | `localStorage` 配额超了 | **浏览器环境**不给存储 | 环境，非本插件 |
| 社区乙 | TauriTavern 上"装上插件就弹无法保存聊天" | **第三方宿主换了保存层** | ★**我们的设计错误**，本棒修掉 |
| 社区丙（三次） | 「设定源不可用：角色卡四件套全空」 | **宿主卡形状 × 我们的读法** | ★**我们的真缺陷**，本棒修掉 |

## 一、宿主保存层（TauriTavern）

**实机形状**（社区乙逐条给的原话）：装上插件就开始弹「无法保存聊天」，停用即恢复；空聊天（没有世界）不弹，**开始新世界生成后就弹**，回到有世界的卡继续弹。

**取证链（不是推演）**：TT 的 dev bundle 里有两条硬读数——① **后端日志一条保存错误都没有**（唯一那条 WARN 是扩展安装撞车）；② 聊天文件只有 **46 KB**。⇒ 既不是"数据太大"，也不是 Rust 侧保存失败，失败在 TT **前端**的 `runChatSave()`（TT 自己的口径：「integrity 弹窗与强制完整保存恢复都留在同一次队列任务中，**其他失败提示并抛出**」）。

**机理（三样叠加）**：本插件**只改 `chat_metadata`**，本该走 TT 那条轻路 `saveMetadata()`（TT 文档：「只保存 header 的 `chat_metadata`…**不遍历或传输消息**」），却在走 `saveChat()`（整份聊天的 commit session ＋ 分帧 IPC，Android 用小帧 base64）；再加一道按**官方 ST 的 fetch 往返**校准的"10ms 内返回＝被静默跳过"闸——在 TT 的 IPC 路径上**每次都判失败** ⇒ 每次落账跑满三次重试环。**我们整套落盘防护是照"官方 ST 会静默失败"写的，TT 恰好不静默 ⇒ 防护本身成了故障源。**

**改法**：认宿主（`window.__TAURITAVERN__`）⇒ 改走 `saveMetadata()`；关掉那道闸；TT 上不重试（`账本被别的副本覆盖` 那一支照旧重试）。**官方 ST 一个字不动**（那条路是实机验证过的）。

## 二、卡形状读法（「角色卡四件套全空」）

**这条被社区报了三次**（leg154 修过一次）。用户这次的补充是决定性的：**"换一张卡也一样"**——说明**卡片不是变量**。

**真缺陷**：`src/abstract-input.js` 读卡写的是 `character[field] ?? character.data?.[field] ?? ''`。**`??` 只在 `null`/`undefined` 时往下一层找**——宿主在顶层给一个**空串**（`description: ""`）而正文躺在 `data.description` 里时，`""` **会赢** ⇒ `data` 层那份**永远读不到** ⇒ 取料为空 ⇒ 报「四件套全空」，而玩家的卡明明是满的。**空串是宿主给的，不是卡给的**——这正是"换多少张卡都一样"的形状。

**同批抓到的第二处**：`src/init-source.js` 那句"卡空不空"的判定**只看顶层**，与取料那处**两把尺子**（连四件套名单都各写了一份）。

**改法**：新增 `characterFieldText()`（**顶层与 `data` 层都看，取第一个非空字符串**），两处收口同一个取法；报错**自带取证**（顶层几字 · `data` 层几字 · `shallow` 是什么 · 顶层键数）。

## 三、环境自检（取证通道）

同一条报错报三次，**每轮都卡在同一件事**：拿不到"环境到底是什么形状"这一格读数——**手机端没有控制台**，插件里那些 `console.warn(...诊断...)` 一句都取不出来，玩家能给的只有一张状态条截图。

**改法**：新增叶子模块 `web/env-evidence.js`（零 import、纯函数、Node 可测），一次取证完：**宿主 · 浏览器 · 在不在角色聊天 · 卡形状 · 世界书三个来源 · 世界账**。挂在 `web/panel-tools.js` 的摘要里 ⇒ **走已有的「复制报告」**一键取证。

**位置是选过的，别搬**：① **零新按钮、零新动作**（`web/index.js` 有 `<3100` 行硬锁，加一行就红）；② 没放回参数页——那一页的自检卡是用户亲口撤掉的（「不要在参数界面出现」）；③ **只进报告、不上屏**——用户看了第一版截图后当场裁「**太多了，就放在复制报告里就行了，别展示出来**」⇒ `debug-console.js` 的 `REPORT_ONLY_KEYS`（`modules` ＋ `环境自检`）。★报告走的是**整份 summary**（`diagnostics.report`），不经过那层过滤 ⇒ 「复制报告 / 下载报告」一个字不少。

## 遗留

1. **「总闸点不动」未定性**（社区丙同一条报告里的第二个症状）。要问清两件事：**整页都点不动还是只有总闸**、**是不是手机**。已知一条老病就在这一族：重绘会把正在展开的 `<select>` 节点销毁 ⇒ 选择器刚弹出就关 ⇒ **手感就是"点不动"**（leg27 为它改过一次重绘策略）。
2. **错误话术改造**（用户尚未拍板）：量出来的比例是 **45 处会朝玩家喊"出事了" vs 38 处正常态**（`console.warn/error` 另有 58 处）。建议把"环境没准备好"那一类从**故障口吻**（「不可用／请检查」）改成**下一步动作**（「先选一张角色卡、进入聊天，再打开观棋窗口」），并**分级**——不是删报错。
3. **`AGENTS.md` 那条交接规矩现在自相矛盾**：它写着"新交接统一写进 `F:/deepseek/plugins/story-world-v2/docs/`"，可真身在 C 盘、F 盘落后 30 棒。本棒照 leg173 的既有做法办：**正本写进真身 `docs/`，另存一份到 F 盘 docs**。**要不要把规矩改成"正本进真身、F 盘只留指针"，归用户拍板。**
4. **台账未补**：`LEDGER.md` / `docs/ledger.md` 没有 leg201 行（文档守门对它只黄不红，故未拦发布）。

## 别重走（本棒踩过的坑，逐条留档）

1. ★**两个版本的文件混用会把宿主搞挂**。TT 装的是**发布版 `leg200b`**，F 盘工作树停在 **`leg169b`**；只拷 `web/index.js` ＋ `web/hot-ledger.js` 两个文件 ⇒ `probeEmbedChannelCapacity` 在 leg172 已撤、那份 `src/embed-client.js` 没有它 ⇒ 扩展加载失败 `does not provide an export named`。**改宿主那份之前先核 blob 哈希**（`git rev-parse HEAD:<path>` vs `git hash-object <path>`），相同才敢整份替换。
2. ★**PowerShell 的 `>` 是 UTF-16**。`git diff > patch` 写出来的补丁，`git apply` 报 `No valid patches in input`。用 **`git diff --output=<file>`**（或 `Out-File -Encoding utf8` 也不行——带 BOM）。
3. ★**git 根在上一级**：`…/332e/plugins` 才是仓库根 ⇒ `git -C <插件目录> add story-world-v2/…` 路径会翻倍（报 `could not open directory`）。用**相对于当前目录**的路径。
4. ★**`git apply` 会静默退出 0**：路径对不上时它不报错、什么也不做。**打完补丁必须核 blob 哈希**，别信退出码。
5. **行数硬锁**：`web/index.js` `<3100`（现 3099，余量 1 行）。落点要选在**没有锁**的模块上（本棒选 `web/panel-tools.js` 的 `summary()`）。
6. **新文件必须 `git add`**：`test/browser-load-graph.test.js` ② 咬"图上每个文件都必须**被 git 收了**"——未跟踪文件会让它红。
7. **升号之后 `docs/index.json` 不会自己更新**：`build-kb.mjs` 不生它，要跑 **`node scripts/audit-docs.mjs`（不带 `--check`）**才会写。
8. **改了 `STATE.md` 或 `scripts/*` ⇒ 知识索引要重生**（R10 咬指纹，`node scripts/build-kb.mjs`）。
9. **发布脚本第⑥步会撞网络抖动**：`fetch failed / ECONNRESET` **不代表推送失败**——推送在第⑤步已经成了；用 `node scripts/verify-release.mjs` 补核（本棒实测 20/20 ✔）。
10. **别用 PowerShell 的 `Get-Content … .Count` 数 `web/index.js` 的行**：它在这个文件上会少报一千行（`STATE.md` §1 那一格早就写着这条，本棒又踩了一次）。用 `node -e "…split('\n').length"`。
