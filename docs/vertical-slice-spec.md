## 0. 人话版：这会怎么样

这一棒不建世界，只打通最小闭环：你推一步 RP → 引擎把对话提取成一条落子事实 → 主调用生成世界步 → 引擎按序结算 → 双流各出一条。验收只看一件事：**观棋侧出现第一条动态流条目**，可读、带因果、你看得见。全程不碰分量公式（常量占位）、不碰大势层（静态张力）、不碰 UI 面板（console 输出）。真 schema 强制从第一天就上，单测和黄金样本从第一天就建——还 D-C3 旧债，不给下一棒留新债。

## 1. 目标与验收判据

**目标**（交接 §6 原文）：最小活棋盘跑通一次完整 tick——一个世界、一两个实体、一条盘算：原料组装 → 一次主调用（真 schema）→ 引擎最小结算（校验/因果挂链/落账/编年）→ 双流各出一条。

**主验收判据**：观棋侧出现第一条动态流条目——可读、带因果、用户看得见。

**次级判据**（长跑防线细案接缝）：演化上下文序列化后恒 ≤ 预算（4k 提案值）、台账四字段记账可用、合成冒烟骨架跑通 20-50 tick。

## 2. 范围限制（防超纲，交接 §6 原文 + 补充）

1. 分量引擎先用常量占位（公式后续）；
2. 先不做设定大势层（用一个静态张力常量）；
3. 不做 UI 面板，先 console/log + 简单输出；
4. 真 schema 强制解析从第一天就做（还 D-C3 债）；
5. 单测与至少一条 golden 从切片开始建；
6. （补充，长跑防线细案 §3 切片内项）不实现里程碑归档/静止衰减/熵泵——只立演化上下文裁剪、台账记账、冒烟骨架。

## 3. 切片前必答（未决点前四项的最小形态）

### 3.1 落子提取契约（未决点 1）
- **最小契约**（提案）：`{ verb, object, location, attempt, note? }`——`attempt` 承载 §4.7 的"对话只写尝试"语义（真值/假值），结果归模拟器；
- **动词口径**：切片先用枚举词表 + 自由文本 fallback，实测看分布再定（词表的好处是可校验，坏处是漏提取；分布数据说话）；
- **条件/多意图**：切片期每条对话只取**一条事实**，超出部分引擎规则丢弃并**记台账**（诚实未提取，不假装理解）；契约质量先过实测再定稿；
- **样本来源**：活档（交接 §7）取 10-20 条真实对话段落——**一律先 cp 副本再解析**；
- **闸门**：样本黄金测试通过才进 S4；不过就回头改契约，不硬上。

### 3.2 事件位置合法性（未决点 2）
引擎校验：事件 `positions ⊆ 世界状态位置集 ∪ {玩家当前位置}`——不过 = 拒绝并记坏账条目。切片版就这一条：**防止主角中心化以新形态回来**。

### 3.3 薄裁定器最小形态（未决点 3）
只裁两种硬结果：**分量对比**（常量占位版 = A 常量 vs B 常量）与 **exposure 暴露判定**；不按冲突类型堆规则——130 条旧债不穿新衣。过程与台词全部留给模型。

### 3.4 张力 schema（未决点 4）
**暂缓**。切片用静态张力常量（如 `tension=0.5`）；schema 待读旧 `abstractCanon` 产出格式后定（接未决点 4 的既定路径）。

## 5. 测试与黄金样本纪律

- **单测**：结算管线纯函数各一（校验/裁定/挂链/编年）；
- **golden**：至少一条完整 golden 世界，**含一条"值得读的世界条目"样板**——"棋好看"质量锚从切片开始落地（ANCHOR §6）；
- **数据来源**：活档——一律先 cp 副本再解析；
- 改码三件事连着做：测试 → 部署 → 台账（铁律 4）；
- 机制新增先细案后实施（铁律 1/两段式）。

## 6. 本棒不做（写在此处防漂移）

U1 分量公式真实值 · U2 设定大势层/张力 schema · U3 UI 面板 · U4 里程碑归档/静止衰减/熵泵（只立骨架）· U5 快照分叉 · U6 世界步异步化（先同步跑通，再议体验层）。
