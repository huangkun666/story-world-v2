## 1. ★ 修一：桥那一行**先问"这个东西是不是本面自己"**（判据⑱）

`src/panorama.js` 的 `bridgesHtml` 里那条 `selfRef` **只判"去处"**，而且判得**比现场窄一格**：

```js
// 旧法（leg97）：要求"名字 = 驻地 = 本面"三样同时成立才算自指
if (e.name === name && String(name) === String(e.location) && f.place === name) return true;
//                              ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ 真账里这些人的驻地大半是「未明」⇒ 一次都不成立
```

⇒ `大虞`（驻地「未明」）被印在**自己那张卡**上。**定稿分两处判**（判"谁"和判"去哪儿"是两件事）：

```js
.filter((b) => b.name && b.to.length && b.name !== f.place);   // ② 桥自己就是本面 ⇒ 整行不印
```

★**两个反向都留档**（过宽过严都是错——这是全仓改得最多的一处，现在**六版错法**全在注释里）：
· 只咬"两边逐字相同"⇒ 真机当场漏出两行：`大虞 → 大虞皇陵` 与 `界渊长城 → 长城`（**左右并不相同**，旧尺子一条都咬不住）；

★**为什么不用 `e.location === f.place` 判**：真账里这些人的驻地大半是「未明」，那条尺子在真账上一次都不成立。
