## 0. 人话版：这会怎么样

世界书只负责说清两件事：**谁比谁强**、**哪里是质变**。至于"这个差距在棋局里该有多重"，交给一台能看见后果的调参机器——一个页签、几个旋钮（主旋钮只有一个：**档间倍率**）、一张实时曲线预览、一份体检报告（这组参数会不会把世界调成一潭死水、或调成几个神仙打架）。机器还会自己试算：你给约束（"顶端别并列、中段要有戏"），它搜出建议值让你挑。**你调的是世界的标定，不是某一步的结果**——红线不破。

## 1. 问题定性

- **形状不能硬编码**：武侠书近线性、修仙书等比、有的书有阶跃（飞升）、有的书干脆给数值域——一份书一种形状。
- **形状不能让模型给**：模型手拍数字正是当前病根（导出 (5)：大虞 0.8/0.9 手拍 → 分量满分，天庭落默认 → 0.375，倒挂）。
- **形状也不该由开发拍一个数了事**：那是开发替玩家定世界手感。
- 结论：**"书提供什么"与"棋局怎么响应"必须分层**，可调性只放在第二层。

## 2. 设计

### 2.1 核心一刀：两层分离

| 层 | 谁提供 | 内容 |
|---|---|---|
| **L1 书 → 序**（契约/引擎，确定性） | 世界书 | **序位**（谁高谁低）+ **阶跃点**（质变边界：飞升/超脱/不入轮回/自建宇宙这类原文标记）+ **数值域**（书给了数就直引归一） |
| **L2 序 → 效力**（可调） | 玩家（默认＝提案值） | **形状**（linear / geometric / segments）与**陡度**、**值域下限**（默认＝类别默认） |

- **属性存的是 L2 之后的"效力值"**（词档三角的"引擎定值"落在这里）；档徽仍是派生词，数字仍可逆查档徽。
- **分量公式（P1-P7 已拍板）不动**：形状在"派生成效力"那一步生效（`tableToValue`），**不落 `computeWeight`**——已拍板公式与黄金逐字节锁零扰动。
- **numeric 维不过形状**：书自带量纲的数（武力 90/100）按书内域归一后直进——书已经给了度量，再套形状＝二次失真。**形状只作用于 ladder 维**：书只给了序，度量必须由引擎补，而"补成什么样"正是可调的那部分。
- **值域下限＝类别默认**（character 0.15 / faction 0.25）：保证"**有据者不低于无据者**"——消解等比映射带来的新倒挂（书内 T1 < 引擎兜底默认）。

### 2.2 参数面（三层，别混）

| 层 | 参数 | 归属/生命周期 |
|---|---|---|
| **世界尺度** | 形状（linear/geometric/segments）、档间倍率 r、值域下限、维度表 min/max、阶跃点 | **随书**（存 setting 的标定小节；**不进指纹键**——调参不得触发重抽） |
| **引擎节奏** | GC 上限、事件产率、镜头预算、抽取预算、批上限、掩码 ε、默认 attrs | 全局（提案态数字第一次有了台面） |
| **观测门限** | 顶端并列线、地板占比线、可动区间线、驻留/摸鱼阈值 | 全局（体检读数用） |

每项带四件：**默认值**（＝黄金锁/提案态原值）· **合理区间** · **一句人话说明** · **恢复默认**。

### 2.3 体检回路（机器之所以是机器）

三级，逐级变贵；**全部零 LLM**：

1. **静态体检**（毫秒级）：当前世界全册实体 + 候选参数 → 纯函数重算效力/分量 → 四项读数：
   - **地板占比**：分量 ≤ 类别默认的实体比
   - **顶端并列**：分量 ≥ max−0.01 的实体数
   - **可动区间占比**：分量落在 [0.25, 0.9] 的实体比
   - **镜头覆盖**：30k 预算内入镜实体数（复用 `lensList` 同口径）
2. **合成冒烟**（复用 `src/smoke.js`，50 tick）：世界还转不转、警告/坏账是否异常。
3. **观测台**（复用 `src/observatory.js`）：拒签率/坏账/驻留——"这组参数下到底谁在动"。

读数给**红黄绿**，且**只提示不拦截**（留痕进 simLog，与档位跃迁监控同一哲学）。

### 2.4 自标定（一键）

玩家给约束（例："顶端并列 ≤3% 且 可动区间 ≥25%"）→ 机器在形状参数空间里搜索（形状单调，二分/扫描皆可）→ 输出**建议值 + 曲线预览（档位→效力折线）+ 各读数对照表**。纯静态、确定性、可复现——**这台机器自己会试算，而不只是给你一堆输入框**。

### 2.5 推定辅助（能从书推就推，推不出就直说）

- **阶跃点**：确定性扫描档位 note 的质变词（飞升/超脱/不入轮回/自建宇宙…）→ 候选分段点 + 原文句留痕（逐字出处，零编造）。
- **量级锚**：确定性正则抽档位 note 里的"数字+单位"（寿/里/丈/斤/倍…）→ 同单位成组、相邻档比值取中位 → 建议 r + **置信度**；样本不足即直报"**推不出——建议手调**"（不猜）。
- LLM 版锚点抽取：**登记不做**（触发＝实机发现正则覆盖不足且玩家要自动）。

## 3. 验收判据（可测）

- **A-1 零扰动**：参数缺省（形状=linear、值域下限=类别默认）下，黄金锁与全部既有测试**逐字节不变**。
- **A-2 调参不重抽**：改形状/r 后，指纹、canon、抽取缓存均不变（只重算派生效力与分量）。
- **A-3 读数可测**：同一世界两组参数产出不同的四项读数；静态体检结果确定性可复现（同输入逐字节）。
- **A-4 自标定**：给定约束，机器给出的建议值满足约束；无解时明确报"无解 + 最接近的一组"。
- **A-5 推定留痕**：阶跃点/量级锚每条推定都带原文句；推不出时报"推不出"且不阻塞手调。
- **A-6 体检不拦截**：红灯只提示 + 留痕，世界照常推进。

## 4. 范围限制（本棒不做）

自动推定的 LLM 版；参数档导入导出/分享；按维度分别设形状（v1 全维共用一个形状）；分量公式改造（形状不落分量层）；每 tick 实时自动标定；世界书之间的参数迁移；页签的权限/多用户面。

## 5. 拍板点

1. **形状落哪层**：L2 派生效力（**推荐**——黄金锁与已拍板公式零扰动）/ 落分量层（要动 P1-P7，需另案）。
2. **numeric 维不过形状**（推荐）确认。
3. **值域下限＝类别默认**（推荐）确认——消解"有据 T1 < 无据默认"的新倒挂。
4. **红灯只提示不拦截**（推荐）确认。
5. **主旋钮词汇**：档间倍率 r（等比语言：'每档强 1.2 倍'）/ 陡度幂 p / 两者都露（同一实现的两种说法）。
6. **页签分层与命名**：世界尺度 / 引擎节奏 / 观测门限（推荐）确认。
