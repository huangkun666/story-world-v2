### 2.2 ★★★ 用户抓出的那个真冲突（本笔的设计依据，别丢）

账上逐字可证——同一轮模型写了**两套时间**：

**给 MVU（另一个扩展）的**：`"19025年08月15日 23:00 → 复苏历19…"` ＋ `"19025年十月初。"`
**给我们的标签块**：`【此刻】复苏历19025年 十月初` ＋ `【时长】三月后`

⇒ **"三月后"的基准分不出来**：
- **(a) 从上一轮（八月十五）往后三个月 ⇒ 到了十月初** ← 对
- **(b) 从此刻（十月初）再往后三个月 ⇒ 明年正月** ← 我第一版默认的读法

**根因**：规范说 `【时长】＝从这里起又过了多久`，而**模型手上没有"上一轮是什么时候"**
⇒ 那个基准**在模型那一侧根本表达不出来**。

**治法（照用户令②）**：包里新增**「时间」一栏**，**两格分开摆**（★合成就把歧义原样带回来）：

```json
"时间": { "此刻": "复苏历19025年 十月十七", "此后又过了": "三月后" }
```

提示词第 9 条同时教了两句：**"现在 ＝ 此刻 ＋ 此后又过了"** ＋ ★
**「别把"此后又过了"当成"从此刻再往后"——那是把时间读反了（会读成明年）」**。

| # | 坑 | 现象 | 定稿 |
