# Story World v2 v1.1.0 版本介绍

> 本页说明历史 v1.1.0 的能力；当前 main 与本地研发进展请看 [README](../README.md)和 [STATE.md](../STATE.md)。文件名保留，避免历史链接失效。

## 长文介绍

Story World v2 是一个提供 SillyTavern 集成的 Agent 状态推演与知识检索项目。它从宿主资料中抽取实体、关系和规则，维护任务计划、事件及历史状态，为持续多轮交互提供可回查的状态依据。

### 结构化知识与任务计划

资料经模型抽取后接受结构与来源检查。程序维护已确认实体、进行中的计划和事件，模型负责提出下一轮变化，程序负责校验和正式写入。

任务不是一次性正文：其阶段、进展和结束记录保存在状态账本中，用户可以回查。程序不将未知字段补成事实，也不把自由文本属性换算成未经定义的分数。

### 检索与上下文

近期历史与更早记录采用不同处理范围。名称、关键词与可选向量通道提供历史候选，输入打包控制上下文预算。模型获得的是被选中的证据，不等于读取全部资料和完整历史。

向量服务需单独配置，Embedding 与主生成的请求、成本分别计算。具体接口及参数以该版本代码和界面为准。

### 因果链与数据恢复

事件保留来源与关联关系，界面可查看前因和后续影响。快照保存插件状态，整聊天导出保留聊天与插件数据；恢复插件快照不会撤销宿主聊天。

用户控制的实体受保护，程序不直接替用户补写行为。模型的间接描述仍可能出错，需要结合原始记录排查，不能据此承诺完全消除幻觉。

### 使用条件

需要配置插件自己的模型通道，主动开启自动运行后才会自动推进；也可以保持关闭并手动更新。初始化资料抽取会请求模型，耗时与费用由资料规模、模型和服务共同决定。

v1.1.0 不包含此后新增的全部抽取控制，也不包含本地研发版的 IndexedDB 正式记忆账、逐任务 Graph RAG 与新图谱。不要把 main 或研发记录的能力追溯为该历史版本已具备。

## 简短介绍

Story World v2 将非结构化资料转为实体、关系与规则，通过任务计划、状态更新、名称/关键词及可选向量检索，支持可追溯的持续交互。v1.1.0 提供宿主集成、因果链、快照和完整导出；安装当前版本请核对 main 与 Release 的区别。
