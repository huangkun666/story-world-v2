# 抢先测试常见问题

## 为什么还是 1.1.2？

这是独立测试分支，manifest 版本保持 1.1.2，没有发布新的正式稳定版本。确认安装的是 `codex/preview-2026-10-23`，不要只看版本号。安装方式见 [README](../README.md)。

## 安装后面板不正常或没有变化？

确认只有一份插件，目录名为 `story-world-v2`，根目录直接包含 `settings.html` 与 `manifest.json`。等待任务结束并保存后硬刷新页面。若仍失败，记录浏览器、ST 版本和错误文字；不要反复重装或清除网站数据，以免丢失未导出的本地世界。

## 能直接用酒馆主模型吗？

需要在插件自己的模型通道配置 API 地址、密钥与模型。可以使用兼容的本地或远端接口，但不保证所有网关和模型都适配。使用服务商模型可能计费。

## 为什么抽象停在字段确认？

这是正常流程：前置先读取字段、设定与地点，用户确认字段后才继续 A/B。点“确认字段并继续”；关闭窗口后从继续入口重开。没有明确位置可以留空，无须编造位置。

## JSON 格式失败、截断、429 或超时怎么办？

先查看具体阶段与调试记录。确认密钥、额度、限流、模型容量及输出设置后，再手动“继续抽象”。不要把不完整 JSON 当作成功结果。格式检查不能保证模型抽象内容正确，受控测试通过也不保证真实模型永不截断。

“继续抽象”保留成功部分；“开始新世界”建立新的抽象任务。未知请求的重试可能再次计费，请阅读界面确认。停止任务不保证服务商立即停止处理。

## ZIP 能用更新按钮吗？

ZIP 没有 Git 元数据，不能 Git 更新。请重新下载正确测试分支，替换前备份并等任务保存完成。Git 安装应确认跟踪测试分支，再使用更新功能；自动更新声明没有在本预览中变更。

## 切换分支、换浏览器后世界还在吗？

世界数据在浏览器 IndexedDB，按 origin 隔离，不在插件代码 ZIP 中。同一 origin 换代码通常仍会访问原库；换浏览器、设备或访问地址不保证可见。先完整导出，再到目标环境导入。不要双装，也不要用“清除网站数据”作为普通排错步骤。

## 快照能把聊天一起撤回吗？

不能。快照恢复建立世界分支，酒馆聊天保持当前进度。恢复前先保存完整备份，留意聊天和世界的时间是否一致。

## 测试通过代表能放心长期使用吗？

目前是抢先测试。已有离线回归与 Chrome/Edge 受控流程证据；模型回应由测试控制，没有消耗真实模型额度。真实模型质量、真实宿主全部组合、手机真机、Firefox/WebKit 和长期内存表现仍有验证缺口。大文本处理可能占用较多内存，请保留备份。

## 如何反馈

在 [GitHub Issues](https://github.com/huangkun666/story-world-v2/issues) 或向你提供此预览的社区提交：

```text
安装：codex/preview-2026-10-23；Git / ZIP；是否更新后硬刷新：
环境：ST 版本、系统、浏览器与版本、桌面或手机：
操作：从哪一页开始，依次点了什么：
预期：
实际：完整错误文字、失败阶段、发生时间：
复现：每次 / 偶发；新聊天或已有世界：
模型：模型名称与接口类型（不要填密钥）：
附件：已检查隐私的截图或必要日志：
```

请勿公开 API 密钥、带鉴权的 URL、完整私人聊天、世界书、世界备份或未经检查的调试报告。报告可能包含请求正文与模型回执；先检查和删去敏感内容，仅提供定位问题所需部分。正文很长时可先提供错误信息与操作，需更多资料时再单独确认范围。
