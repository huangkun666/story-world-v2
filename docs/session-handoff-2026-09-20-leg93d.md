## 2. leg93b：标签包进一个块里（用户裁示「就甲吧」）

**用户那一问**：「**正文里有【…】呢？？不能包裹在一个标签里吗？？？**」

**逐字喂真提取器实测**（装置 `leg93-brackets-in-prose.mjs`）——两处**真会出事**的：

| 正文里长这样 | 实测后果 |
|---|---|
| 一句**以 `【行动】` 开头**的叙述（解说格式/举例子/被引用） | 被当成**一条真行动**（名字 = 整句话），落 `unresolved` / `notNoted` |
| 一句**以 `【时长】` 开头**的叙述 | `elapsed` **收下一整句话**（实测「这个词表示时间流逝。」） |

★**第二条更重**：`elapsed` 是"账外的料"，**引擎一个字都不校验**（`pack.js:964`），
它**原样进世界模型的 prompt**（`prompts.js:222`）。

**根因一句话**：认不认得出标签**全看 `【` 在不在行首**——正文与标签**共用同一个语法空间**，没有边界。

★**同时实测证伪了"包裹有用"**（这条最要紧）：旧实现逐行扫全篇，代码块与 `<tags>` 包裹
**一点都不影响结果**（包裹行只是被判"其它一律不看"）⇒ **光让模型包裹、不改解析器 = 白包**。
甲案正是把"包裹"从无意义的壳变成**真正的边界**（`src/tag-extract.js` 的 `shellRange()`）。

| 情形 | 行为 |
|---|---|
| 有块（开围栏行**整行只有它**：三反引号 + `tags`） | **只扫块内**；块外的 `【…】` 一律当正文 |
| **没块** | ★★**退回逐行扫全篇**（`mode:'all'`）——**老账、老聊天逐字节不变** |
| 块没闭合 | 吃到正文末尾，标签**照样读出来**（`closed:false` 如实标出） |
| 围栏行不干净（后面还跟字） | **不算开块** ⇒ 退回逐行扫 |
| 块空着、真标签在块外 | **就是不认**（代价面，判据 ㉔d 锁住） |

★**代价面如实登记**：标签写在块外 ⇒ 不认。这一面由注入规范那段硬要求兜
——**规范判据与提取器判据是一对，缺一不可**（㉔ 与 ⑪ 分居两处，别只改一头）。

## 3. leg93c：事件链改走浮层（用户令「点击后直接弹出一个小窗口」）

**用户原话**：「**事件链条点击后不要放在编年页了，直接弹出一个小窗口，
要不然我在大事纪页签点击还得回到编年页**」

**根因（源码可证 · 在接线层、不在渲染层）**：旧 `bus['open-chain']` 把渲染好的链视图
`insertAdjacentHTML('afterbegin')` 到**写死的 `#sw2_view_chronicle`**；而「链」按钮在**两处**
（编年页 + 大事纪·旧卷页，C-1 两个入口）⇒ 从大事纪点，内容却进了**另一个页签**。
★`renderChainViewHtml` 一直是好的——**错的是"把结果塞到哪儿"**。

**修法**：链视图进一个挂在 **`document.body`** 上的浮层（常量 `CHAIN_MASK_ID`）——
不在面板窗口里 ⇒ **面板开着关着都能看**；`z-index:51000` **高于面板那 50000**。

| 关闭路径 | 说明 |
|---|---|
| 链自带的「收起」按钮 | `chain-close` → 同一处收口 `closeChainPopup()` |
| **点背景** | 点弹窗内部不关（不然想看细处一点就没了） |
| **ESC** | ★**捕获阶段 + `stopPropagation`**——面板自己有一条"ESC 关整个窗口"，不拦会把面板一起关掉 |

★★**最容易漏的一处（判据专门锁它）**：面板的动作总线 `bindActions` 挂在 **`#story_world2_window`** 上，
而浮层挂在 `document.body` ⇒ 浮层里的 `data-action` **永远走不到那条总线**：
链自带的「收起」与各处的「阅卷」（`.sw2-goto`）会**点了没反应**。
⇒ 浮层自己挂一条同形状委托；「**阅卷**」**先收浮层再切页签**。

## 4. leg93d：超时那句人话（交接 §5.1 登记两棒的那条）

**病**（用户控制台那行）：`[story-world-v2] signal is aborted without reason`
—— 状态条上印的是「⚠ 演算失败：传输失败: signal is aborted without reason（世界原样未动，可重试）」，
**看得出失败、看不出为什么**。

**真因（实测三臂对照 · 装置 `leg93-abort-shape.mjs`）**：
我们确实 `abort(new Error('…超时…'))` 把 reason 传进去了，但
**真浏览器里 fetch 不把 reason 交回来**——它抛的是**它自己的**
`DOMException('signal is aborted without reason', 'AbortError')`。
甲臂（假 fetch 直传 `signal.reason`）能拿到人话；乙/丙臂（**照真 fetch 形状**）拿到的一律是那句英文。

★**为什么既有判据一直绿**：那条判据的假 fetch 写的是 `reject(opts.signal.reason 或 new Error('aborted'))`
—— **它把 reason 直接传了出来**，于是 `/超时/` 过得去。**空绿的第三个实例**（见 §0.2）。

**修法**：
- `src/transport-http.js`：catch 里**由我们自己组人话**（超时是我们发的信号，我们知道多少毫秒）——
  `模型超时（Nms）——这一轮没等到模型回话，已中止；可在参数页把「单轮超时」调大`；
  原异常挂 `cause`；**`sw2Timeout` 标志一个不丢**；措辞走人话（**这句会印在状态条上**）。
- `src/abstract.js` 的 `isTransientCallError`：超时的**权威判据是标志位**——新文案里**没有 `abort` 字样**了，
  若还指望 message 里那个正则，超时会被误判成"可重试的瞬时错"（重演 leg61 那次
  "超时后重试一次 = **又等满一个超时**"）。那条正则在注释里**降级为兜底**。

## 6. 本棒踩的坑（写下来免得下一任再踩）

1. ★★★**"问问题"≠"授权改码"**（§0.1）。
2. ★★★**台账插行的口诀是错的**：交接 §4 写「列数 = 裸竖线数 − 1」——**只对 4 列表成立**。
   本表是 **5 列**（`| 日期 | 步骤 | 变更 | 测试 | 部署形态 |` ⇒ **6 个裸竖线**）。
   我照那条口诀**连算错两次**，两次都被自己的守卫拦下（**守卫是对的，算式是错的**）。
