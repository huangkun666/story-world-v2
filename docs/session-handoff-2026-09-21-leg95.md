## 0. ★★★ 接手先看这一条：**"账目合上了" ≠ "真的讲完了"**

用户这一问把整个案子问穿了。**本棒的全部改动都从这一句长出来**：

> 「**链头没法完结但是为什么每个事件都写个还开着，这些事件都是已经完成了呀，这不是误导人吗？**」

**病根是"层次串了"**：面板那行判词印的是引擎的 `closed`，而 `closed` 的意思是——

> **这件事还要不要继续参与引擎的连锁**（账目口径：下游有没有人接着、谋划关没关、够不够老）

它**不是**「这件事发生了没有」。**一件事是时点，落账那天就发生了**；"还在不在往下长"是**一条线**的性质。旧代码把线层的账目状态印在点上，于是**一条链上每一环都印「还开着」**——用户看到的就是这个。

★**用户随后自己把分工定了**（这两句是本棒的总纲，下一任照做）：

| 角色 | 管什么 | 依据 | 不许干什么 |
|---|---|---|---|
| **引擎（机械）** | **"这单结没结清"**——账目 | 结构、可复算（谁的下游空了、谋划关没关） | ★**不许判"这故事讲完没有"**（那是语义，机械无从知道） |
| **模型（LLM）** | **"这故事还要不要往下讲"**——语义 | 它读得懂情节 | ★**不许替引擎记账**（收场由引擎落账，模型只提议） |

**⇒ 两条纪律（下一任照做）**：①**凡是"我已经看懂了"的东西，都要问一句"用户拿到的是不是同一份"**（leg94 §0 那条，本棒是它的第二次兑现）；②**一条判据用错层次，会长出一整族怪现象**——「还开着」这一个词底下压着三道门、两种源、一个永久死锁。

## 2. 引擎与契约（本棒主菜）

### 2.1 ★★★ 死锁的根：`headClosed` 问错了问题

```js
// 旧（headClosed）：沿链上溯 —— plot 看"那个谋划结算了没"、state"恒算了结"，
//   而 seed **既不是 plot 也不是 state** ⇒ 走到最后 return false ⇒ 链头永远"没结清"
// ⇒ 种子底下长出来的每一环**结构上永远闭不了**（这就是用户看到的"一直还开着"）
//
// 新（chainSettled）：沿链上溯，**遇到播种源（seed）或处境源（state）就当链条在这里走到头**——
//   它们**生来是一个起点，没有"了结"这一说**（书的原始设定／当时的局面，不是谁在办的事）；
//   链条中间若压着一个**还没收场的谋划**，那这条链就还在被人办着 ⇒ 不算收场。
```

★**这不是"漏了一个分支"，是判据用错了层次**：旧判据问的是「**根那件事办完了没有**」（语义），该问的是「**这一段还在不在往下长**」（结构）。

**措辞分化**（同一批收场，两种说法不许混成一句）：

| 链条源头 | 编年怎么写 | 为什么 |
|---|---|---|
| plot（谋划） | 「涟漪平息（**链源已了结**）」 | 谋划真的结算/取消了 |
| **seed / state** | 「涟漪平息（**这一段没人接着长了**）」 | ★种子是书的原始设定，**它没有被"了结"过**——旧那句话对它是不诚实的 |

### 2.2 ★★ 闭环第四型：模型判"这一段讲完了"

```
世界步新增一个可选组（与 entityUpdates 同一条口径：缺席 = 本轮不提议，不是形状错误）：
  "eventClosures": [{ "event": "ev_48_2", "why": "这一战已经打出结果（对手重伤退走），战场上的事由后面那几件接管了" }]
```

| 谁 | 干什么 |
|---|---|
| **模型** | 判「这一段过去了」——只递判断 + 一句理由，**不碰记账** |
| **引擎** | **只做机械审计**：①号在册 ②还没收场 ③同批不重复 ④每轮 ≤ `EVENT_CLOSE_CAP`=8 ⇒ 落账 `closed`+`closedAt`+**`closedBy:'model'`**+`closedWhy`，编年写「事件「X」这一段收场了：<模型给的理由>」 |

★**它治死锁的机理**（本棒最值钱的一处）：**模型点名链头（种子）收场 ⇒ 底下那串当场过 `chainSettled` ⇒ 引擎的老规则自己一层层扫干净**。
真账实测：**B 局模型只点 9 件 ⇒ 连带解开 21 件**。**模型只出判断，清扫交引擎。**

★**审计所在的那一层（当场踩出来的形状，别搞反）**：①号不在册、②已收场 这两条由**契约层**（`check-step` + 判据表）在**整步入口**就拒掉 ⇒ **到不了**引擎那一段。引擎里那两句警告是**防御**（只在有人绕过校验直调阶段函数时才响）。★本棒第一版按"引擎给警告、照样落账"写判据 ⇒ 当场红。
