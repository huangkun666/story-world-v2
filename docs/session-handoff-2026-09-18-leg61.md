2. **把明细塞进账本**：`frozen.compile` 第一版铺进整个探测结果 ⇒ `titleRoster` 189 条明细 = **账本的 11.4%**，且契约没登记 ⇒ 违约。**教训**：账本只留标量计数，明细留诊断面。
3. **空绿**：设定页那两栏**只加了渲染代码、没加判据** ⇒ 那条分支一次都没被跑到（补"真渲染一次"的判据后才当场抓出我把 markdown 星号写进了 HTML）。
4. **过拟合（用户当场抓）**：我提"给引擎加**年份 + 剧本方向**两个参数"——那是**这本书的字段名**。反过拟合实测：`（YYYY年）` 块头三国 127 个、其他 5 本 **0** ⇒ 任何以它为判据的机制都是方言机制。**教训**：提任何判据前先答"换一本书会怎样"，并给出实测。
