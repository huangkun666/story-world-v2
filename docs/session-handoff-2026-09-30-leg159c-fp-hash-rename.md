## 0. 一句话

`src/fingerprint.js` → **`src/fp-hash.js`**。原因是 EasyPrivacy（uBlock Origin / uBO Lite / AdGuard 共用的
公共过滤列表）**第 982 行**有一条 `/fingerprint.js^$domain=~github.com`——它是拿来封 FingerprintJS
那个指纹库的，而本插件当时恰好有一个**同名文件**，于是浏览器抓它时被当场掐断，**整个入口模块加载失败**。

判据 **1466 / 1466 · fail 0** · 冒烟 **8351 字节逐字节未变** · `web/index.js` **3098 / 3100（±0）** ·
**四个号一个都不升**（契约/引擎/渲染一个字没动、页面可见面零变化）。

## 8. ★★★ 同一天的第二笔：**默认那一屏补上入口**（用户实机报「没看到效果」）

> 这一节是**同一天接着发生的**：改名那一笔装到用户本机之后，他回来说
> 「**我的构建号是这样但是没看到你说的效果**」——他指的是**观棋页那两处新东西**（leg159b 的）。
> ★根因**不在安装、不在缓存、也不在过滤器**：**是 leg159b 自己的设计错了一处**。

### 8.1 病：**功能在，入口不在**

leg159b 那行「看哪一段」的渲染条件是：

```js
const r = stats.range;
if (!r) return '';        // ← 没选时间段 ⇒ 这一行一个字都不印
```

而**默认那一屏的 `range` 恒为 `null`** ⇒ **默认那一屏上根本没有那一行、也没有那枚「整本账」按钮**
⇒ 玩家**永远没有机会点进「整本账」**。我量的是"函数能读回归档"（判据 ㉓ 绿的），
**没量"玩家能不能走到那个函数"**——这正是本仓那条老纪律说的：**一格填对了，还要问"玩家进不进得去"**。

★**还有第二处、更隐蔽**：那一版把"账上一共多少"挂在 `pool`（＝**这一屏读的那一批**）上：

| | `eventsAll` | `eventsArchived` |
|---|---|---|
| 第一版（挂在 `pool` 上） | 默认档 = **33**（＝热层） | **0** |
| 现读（挂在**全账** `whole` 上） | **579** | **546** |

⇒ 默认那一屏不但没有入口，**连"还有 546 件可看"这句话都不成立**（它报的是"账上共 33 件"）。

### 8.2 治法（两处）

1. **四个数一律按全账算**：`eventsAll` / `eventsArchived` / `eventsFrom` / `eventsTo` 改读 `whole`（热层 ＋ 归档），
   与"这一屏读哪些"（`pool`）分开。★`events`（这一屏看得见几件）**不动**。
2. **默认那一屏也印那一行**——但**分两档**，为的是既不破坏旧基准、又不给假承诺：
   - **账上真有归档**（`eventsArchived > 0`）⇒ **照旧不印**（与 leg159b **逐字节相同**，判据 ㉓ 那条基准保住）；
   - **还没有归档**（短局／新局）⇒ **印一行说明**：如实报"这本账共 N 件事、都还在热层里、
     **还没有哪一段被搬进大事纪**，所以现在按「整本账」看到的与这一屏相同；再往后走，搬进大事纪的旧事会回到这一页"。
     ★按钮照给（它就是入口），但**旁边把"现在按下去会看到什么"说明白**——不许给一个按下去没反应的按钮。
