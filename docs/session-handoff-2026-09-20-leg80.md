### 2.2 ★★★本族真正的承重墙：**三态语义**（判据⑥真跑一遍钉住它）

```

```

★**实测代价**（`web/index.js` 里那段留档注释就是这段历史）：用户真账 **563 实体**，
`location` 真值 **0** / 占位值「未明」**563**——面板整列「未载」。

⇒ 本棒把这条**写成可执行判据**（判据⑥）：真喂 ctx 跑三种世界（有书 / 书里没这个人 / 一本都没挂载），
逐态断言 `ok` 与 `entries`。**这一条是本族最值钱的一条**——它守的不是"代码在哪"，是"两种空不许被当成一种"。

## 3. ★★本族特有的形态：**一口零参 + 其余收形参**（两种形状**故意并存**）

```
collectWorldInfoEntries(ctx, character)   ← ctx 当形参收（纯函数，谁调谁给）
pickCharacter(ctx)                        ← 同上
worldBookCached(ctx)                      ← 私有，也收形参
bookEntriesForInherit()                   ← ★零参！内部走**注入进来的** getCtx()
```

★为什么零参那一口**不许改成收形参**（本棒第一版改错了，**测试当场红**，是证据把它改回来的）：
`test/location-inherit-wiring.test.js` 装好 fake ST ctx 之后**按零参**调它
（`await mod.bookEntriesForInherit()`）——**外部契约就是零参**。
⇒ 本棒的验收口径是"纯结构搬迁、外部契约一个字不动" ⇒ **改测试去迁就实现是倒过来了**。
⇒ 定稿：它内部走 `getCtx()`，而 `getCtx` 由接线层**注入**（`setCtxSource(getCtx)`，在模块顶层同步区）。

★★★**注入的是函数，不是值**——`window.SillyTavern.getContext()` **每一轮都可能换**（换聊天/换卡），
注入一个值就等于把上下文**冻在建模块那一刻**（leg73 的 TDZ 铁律、leg79 的"视图对象不许抓死"，
**这是同一条纪律的第三次**）。判据③咬这一条（`setCtxSource` 只许收函数）。

★**为什么其余的口一律收形参**：`locateNameLine`/`locateNameSnippet`/`bookEntryText` 是**纯字符串函数**，
本该在 Node 里被直接真测（`test/lookup-batch.test.js` 一直在测它们）⇒ 本模块**不许碰 `window`**（判据②咬），
`node --test` 才能直接 `import` 它。

## 4. ★★★本棒踩的三个坑（都已修，都写进判据/装置）

### 坑①（最贵）：**抠段的锚点会命中"结构同形但语义无关"的别处** ⇒ 变异等价、判据假绿
咬合演练第⑥段的变异，我第一版手写的锚点是 `` `}).filter((x) => x.text),\n    };\n}` ``——
它在**另一个**结构同形的函数里也命中（`bookEntriesForInherit` 里 `const hit = … .filter(...)` 后面那个 `});`）
⇒ 变异"打上了"、**但落在别处、对行为等价** ⇒ 判据全绿**是对的**（leg74 §4.2 的第二问）。
★修法：**要改什么就先说清楚**，再从**目标函数的函数体里按内容现取**唯一锚点
（`anchorInFunction(file, fnName, needle, extra)`）——装置里已封装。

### 坑②：**手写锚点连错两次**（第一次落别处、第二次取了开头那个早退）
第二次我改成"取函数体里第一个唯一的三行段"，取到的是 **`if (!name) return { ok: true, … }`**（空名号那条早退）
⇒ 变异打在"空名号"的路上，与"书里没有"**毫无关系** ⇒ 又是等价。
★教训：**"唯一"不等于"对口"**——锚点必须由"我要动的那一行"定义，不能由"哪一段碰巧唯一"定义。

### 坑③：**另起进程的探针"要能看见那条纪律"才有意义**
判据⑦第一版只断言"初始态返回空数组"⇒ 变异"模块级抓死一份 ctx"**咬不住**
（抓死的那份 ctx 只要没书，空数组照样成立）。
★定稿把"初始态"钉成**三格**：`before=0`（没有上下文）→ `after=1`（**注入后换得动**）→ `back=0`（换回后清得掉）。
★★"**换得动**"才是"没有被抓死"的**可观察证据**——这是本棒咬合演练逼出来的一格。
★顺带钉下**真契约**：`setCtxSource` 只换"以后去哪取 ctx"，**不动已缓存的那本书**
⇒ 换聊天/换卡时必须照旧调 `resetBookCache()`（生产侧那处就是这么写的：`loadWorld` 里）。

★另外两处小坑（都留档）：`--input-type=module -e` 的探针里 **`console.log` 会被 `execSync` 默认缓冲吞掉**
（改成把探针写成文件再跑，或让判据自己断言）；**探针路径不许拼 `process.cwd()`**
（反斜杠在 `-e` 字符串里被吃一层 ⇒ `F:deepseekplugins…` 当场 `ERR_MODULE_NOT_FOUND`，用 `import.meta.url` 算）。
