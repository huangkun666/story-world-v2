## 3. ★★ 我试的修法，以及它为什么**不成立**（本棒最值钱的产物）

### 修法（泛用化，不写任何本书专名）
新增 `pickCanonSource(src, budget)`：在窗口内**优先装"体系条目"**、余量按书序，
**总量恒 = `CANON_SRC_CHAR`**（保住 `abstract-chunk.test.js` 那条"五件套段 = 头 3 万字符"）。
判据是**形态**（作者标注体系的方式），不是题材词：
- 标题含结构词（体系/系统/规则/设定/总纲/机制/谱系/世界观）
- 正文首段是「字段：值」清单
- 出现数值区间（`0-100` / `95-99`）
- 短标签行密集（`核心属性:` `范围:` `属性联动机制:`）

### 出数结果：**它没解决问题**

```
启用 264 块上跑：
  标题含体系词        0 条   ← ★（启用集里一条都没有）
  含等级锚（T0/SS级…） 2 条
  脚本条目           220 条
挑出来的 top：人物档案（邹氏/杜氏/祝融夫人…）+ 用户信息 + 经济指导 + 变量更新规则
真正的战力体系：**不在集合里** ⇒ 再怎么挑也挑不到
```

### 三条不成立的原因（**上一任要照这个避开**）
1. **根因不在取样，在"条目被禁用"**：`演义战力体系` `disable=true` ⇒ 输入里就没有它。
2. **形态判据分不开「分类定义」与「分类的实例」**：人物档案的 `基本信息: / 姓名: / …`
   与体系条目的 `核心属性: / 范围: / …` **是同一个形状**（都是"字段:值"清单）。
   本棒试了两信号（题名体系词 ∧ 等级锚）与三信号（+ 定标字段）——**要么 0 命中、要么命中档案**。
3. **泛用化的样本只有一本书**：我用"规则/机制/等级/区间"这套结构词去认体系，
   在三国上**只捞到 声誉/经济指导/变量更新**（它们确实是体系——但不是**战力**体系）。
   ⇒ 单本就调参 = **过拟合**，正是用户叮嘱要避免的。
