## 2. ★★ 三条口径（判据钉着，别再自己发明）

### 2.1 落脚处：**每条线恰好一处**（核算平的根据）

```
线 的 落脚处 ＝ 面（它到达的那些面里、**它的事最多**的那个）
              ＞ 它自己的主要地点（从没到达任何面时）
              ＞ 无 ⇒ 进「各处散落」
```
★**三个分类互斥且穷尽** ⇒ 自证闸才有意义（`线 N = 面内 + 单线地点 + 散落`）。
★设计交接 §1.1 第 4 条那句"归属按线算一次"说的就是这件事（leg96 当场踩到 `大虞龙气外泄` 被推两遍）。

### 2.2 面 ＝ **到达 ≥2 条线**的地方；单线地点**不立**，挂在它那条线的落脚面里

- 面上的线**分两种**：**落脚在此**（它的落脚处就是这里）与**路过**（发生在别处、只是在这里也落了事）。
  面头那句「N 条线在这里交会」数的是**两种之和**（照设计交接 §1 的原话）；另有 N 处单线地点另计。
- **单线地点**（只被一条线到达的地方）：作为「**这一处另有 N 处单线地点**」列在它落脚的那个面里，
  **地名照印**（设计交接 §1.1 第 2 条）——★印的是**它起头那件事**（只印一个线名，读者会读成谜语）。

### 2.3 ★★「几件事发生在此」＝**真的发生在这个地方的**事（不是"落脚线在此的事之和"）

这是本棒修的**第一处真病**，也是 leg96 §0 那条纪律的**第五次露面**（"喂给它的那个数，量的是不是这件事"）：
第一版写成"落脚线在此的事之和" ⇒ 真账的 `南荒部洲·十万大山` 面报 **1 件**（真相是 2 件）——
因为**路过**这条线在那一处也落了 1 件，而它不算"落脚线"。
⇒ 判据⑮咬住它（夹具里特意造了一条**路过**的线，`只数落脚线 < 按地方数` 两个数**必须不等**）。

1. ★`panorama.js` 仍是**零 import 的真叶子** ⇒ 组合做在**接线层**（`mergedMainHtml`），模块图未动 ✅
