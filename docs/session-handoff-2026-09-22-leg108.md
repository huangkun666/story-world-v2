★这与 leg107 §3 修掉的 `publishedBuild` 写死是**同一个形状**：**读数缺一条"现读真值"的腿**。

`err.stdout` 取（别把它读成"跑不起来"）。
★**先证红再转绿**：补完先跑一遍，它当场咬住 `实测 1110 · STATE/README 1096`；把读数改对之后转 PASS。

### 1.5 ★★ 快照页标出"盘上现在这份"（B6）

**先查实（先量再动）**：快照库**根本不知道**"盘上现在这份是哪一份"——`snapshotList()` 只回清单 + 一行摘要；
`restoreSnapshot` 里那个 `keepId` 只是**临时**用来防窗口把该份剪掉，**不落任何记录**。

★★**而且本棒证伪了一个看起来能用的偷懒办法**："列表最新那份就是盘上那份"是**假的**——
恢复快照时会**先给当前状态拍一份"恢复前自保"**（`restoreSnapshot` 第二行），于是恢复完成之后
**最新那份是恢复前的旧状态**，而盘上装的是**被恢复的那一份** ⇒ 拿"最新"当"当前"，会把玩家指到**正好相反**的一行。

**治法（用户拍板"记在快照库自己身上"）**：新增 `markCurrentSnapshot(id)`——标记**只住在那份快照自己的记录里**
（**不动世界账、不动契约**），只写**真变了**的那几条；只在**两个确知的时刻**打标：①刚拍成一份之后
②恢复某一份之后（标在**被恢复的那一份**上）。渲染侧一行：那一行印「**← 盘上现在这份**」。

### 1.6 ★★★ 一处判据打架（本棒最该带走的一课）

本棒改了玩家可见文案 ⇒ 按 §1 那条"玩家可见文本变了就升 `PANEL_BUILD`"**本该升位**；
而另一条**承重判据**（`test/render.test.js`）要求「**CSS 号的 leg 号只许落后构建号一笔**」，
CSS 号停在 `leg104` ⇒ 升到 `leg108` **差 4 笔、当场红**。而"**没动样式就不升 CSS 号**"同样是明文规矩。

**为什么会撞**：leg106 / leg107 两棒**没有玩家可见变化** ⇒ 构建号没动；⇒ 两条规矩**第一次真撞上**。

**处置（照本仓纪律，一步没跳）**：**先证红**（把 `PANEL_BUILD` 改成 `leg108-honest-status` 跑一遍，
红的正是那一条）→ **当场回退** → **停下报因**（登记 `STATE.md` §3-E）→ **用户拍板「改判据」** →
换成"**直咬那个病本身**"：给 `web/style.css` 钉**内容指纹**（按 **LF 归一**算，照 leg106 那条留档：
换行随检出机而变，不该把"结账机怎么结账"算进判据）⇒ ①指纹变了就必须同批升 `CSS_VERSION`
②没变就不许变 ③**构建号只需不落后于 CSS 号**（"挨得近"那半条撤掉）。
★**反向自证当场做过**：把指纹故意改错 ⇒ 1110 里 1 条红、报文正确打印实测指纹；改回真值 ⇒ 全绿。
