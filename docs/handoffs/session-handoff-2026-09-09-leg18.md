4. **取数形状宽容+失败诊断**：worldInfo 兼容 数组/{entries} 两形态；群聊 character 回退首位成员卡；失败现场整包上控制台（`[story-world-v2] 初始化设定源失败诊断`）；reason 细分（无卡/四件套全空/世界信息空/全禁用）。

## 3. 关键决策与结论索引

1. **换源/worldBook 整体废除**（用户令）：初始化只有自动两条路（世界信息/卡内置书 + 卡四件套）；"源"概念从 UI 与存储中消失——v1 无此概念，K38 三按钮中它是最失败的一扇门。台账 L131。
2. **世界书全量+分块抽取**（v1 范本）：五件套头 3 万单发 / 书名录分块 6 万+拆半自适应（ROSTER_CHUNK_DEPTH=4）；出处校验、禁用标记尊重、内嵌书双路径 `character_book || data.character_book`。L125。
3. **抽取预算独立 16384**（实证）：思考型模型推理+输出共享预算；主调用 4096 提案不变。L128，报批 #12。
4. **接线雷教训**：`transport(p)` 返回裸字符串（transport-http 契约），凡对结果取 `.text` 的调用点都是雷——diagExtract 已双形；**后续新增任何 transport 调用点先查 worldstep.js L12 写法**。L129。
5. **合成演练≠实机**：K38 三按钮"演练全绿但从未真跑"是全部雷的温床——真跑在前、机制在后。L129 复盘。
6. **生成层缺口确认**（未拍板）：v2 初始化=源文本归档（只提取不创作），v1 初始化=生成稿（现状/谋划/事件）——"抽象出来不像样子/开局不活"的体验根因；方案：五件套之后追加一次生成调用（局势一句/谋划 ≤3/事件 ≤3/开篇编年 1-2 行，引擎校验落账），数字提案态。等拍板。
7. **焦点公式修订讨论**（挂起）：提及进热度被用户否决方向（主观信号进客观公式+廉价操纵+镜头读了输入层的账）——焦点细案时锁"镜头只用结算层数据"；A 提及出局（推荐）/ B 提及降权+加权（提及者分量+行动佐证）。
8. **复归拉杆讨论**（挂起，真跑读数后）：休眠名册+LLM 建议权；合并 R2（复归与门控点名例外统一）与 R5（依据册随退清账 vs F 条"想回来的人必然回来"）。
