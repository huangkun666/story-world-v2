## 3. 关键决策与实测发现（全部有台账行可查：L96-L106）

1. **部署纪律（L96）**：ST 老式三件套扩展的部署位=代码自身定死（`renderExtensionTemplateAsync('third-party/story-world-v2',…)`）→ junction 单源部署，比拷贝省同步债；后续改 web/ 免部署、刷新即载；
2. **首开死结（L98）**：凡功能藏在「渲染产物」里而渲染依赖有世界，必须给无世界空壳——同理适用于后续所有「操作按钮在设置页」的设计；EMPTY_WORLD 契约=形状空世界非裸 `{}`（K34 防御锁的口径）；
3. **接线层 DOM 边界无 Node 锁（L98/L105）**：A-2 锁的是 renderAll 输出形状，**锁不到 innerHTML/异步值传递**——本轮 [object Object] 与 Promise 两炸都是实机才现形；对策：接线层语义（DOM 组装/异步 save）进测试（async-tick 注入面可测），DOM 组装留实机冒烟（部署形态验证不可省）；
4. **模型行为类问题一律走模板（L103）**：ripples 误填事件 id——修在 prompt（铁律 8 + 字段说明 + 版本号 v2-ripples-1），引擎 check-step 拒绝行为一字未动；模板语义缺口=两扇门没对上（示例展示 X、说明没定义 X）；
5. **编年文本是持久化玩家视图（L106）**：引擎措辞=玩家视线（编年行进注入、进导出、进旧卷）；代号零可见是 A-3 的引擎侧补位；历史行不篡改（账的不可变性），只改新落账；
6. **异步契约必须显式（L105）**：注入面函数（save）的同步/异步在契约注释与测试里都要锁——K36 测试全同步注入，浏览器侧 async 实现直接违约且测试全绿；
7. **诊断通道先于修复（L102）**：错误消息带现场（原始输出预览）→ 用户贴回 → 定案修——本轮两次大修（非法 JSON→其实转向语义错、空转→其实渲染冻结）都靠「现场先回来」。
