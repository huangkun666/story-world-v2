### 2.2 A1：`membersOf` 分量序 → 名号序（`abaa829`）

`src/pack.js` `membersOf` 的排序键由 `world.weights` 改**名号序**（同名按 id 兜底）。为什么必须改：leg24 片2 之后势力成员四维普遍为空 → 同取中立 floor → 分量全等 → **排序退化为底层数组顺序**，面板「麾下」名单每次重算都可能换位。测试用**反向构造**守卫（若偷偷按分量排则必红）。

**注意**：名号序是 **Unicode 码点序不是拼音序**（`弟子乙` 前于 `弟子甲`）——已写进测试注释，别当 bug。

### 2.3 A1b：张力行不再用「烈度」包装（`34f0f25`）

`setting.js` 的 `rival` 腿（"两强对峙度"）**实测恒为满值**（均值 0.9913，t10–t80 恒 1.0；根因：`w2` 就是"去掉一个 `w1` 之后的并列者"，有并列就恒 1）。故面板那个 `%` 实际只反映**事件密度**，而「烈度」这个词在暗示"引擎判断了天下张力"。

**处置**：`recentEventCount()` 提为共用口径；面板张力行改 **`近10轮事件 N 件`**；设置页保留原值 + 补说明。**公式与数字一律未动**（改已报批数字须先出曲线再报批）。
