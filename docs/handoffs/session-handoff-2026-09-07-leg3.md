## 0. 人话版：这会怎么样

这一棒把"这个项目怎么开发"写成了手册，然后按手册给世界装上了"谁这轮值得动"：分量低的角色不再每回合齐步走——他静默（不出主动作、窗口里也没有他的动静），但**被点名时可以应答**（谁打他、谁波及他、谁传唤他）；站桩的权力会随时间萎缩（你十轮不发一言，分量照跌）；弱者的提案会被引擎按分量比打折；静默者不能偷偷给自己变强。测试从 74 涨到 109，全部绿。过程中照出并确认了一个重要缺口：**玩家棋子在世界的账本里还没有位置**（没有属性、没有分量）——已经写成"玩家档案"细案，等你拍四个小数点级的决定就能动工。收尾做了一个 `node demo/status.js`——一条命令看阶段、健康度、每个模块的测试覆盖和队列。

## 3. 关键决策与实测发现（全部有台账行可查）

1. **分量引擎组件全部落地**（K1 公式/掩码/半径 → K2 门控 → K3 衰减 → K5 折减/报警 → K6 冒烟泛化），数值全部**提案态**待报批（GC 数字曲线在手，正式报批排 K 序联动）。
2. **门控语义实证**：静默不消失（合法客体）、被点名可应答、下一轮重新判定、top-1 永不静默、阈值严格小于（0.25/0.50）。
3. **点名窗口发现（K6 曲线证）**：事件不闭环 → 被点名者持续可应答（e_lo 应答后自身 plot 事件波及点名自己 → 窗口开到盘算满步结算）。这是 `events.closed` 关闭路径执行债的**可见症状**，触发理由加重。
4. **衰减 × 常驻事件交互**：e_mid 衰减入静默后被 ev_p 每 tick 点名持续应答——同一症状的另一面。
5. **静默自我增强漏洞 → 已堵**：actor 缺省 + 静默 → 增量归零 + 警告（stateChanges 通道的隐性自我回血）。
6. **P3 执行**：演化上下文移除 weights——"模型不看分量"从 ANCHOR 条文变代码事实；分量只在观棋侧（用户）与引擎内流动。
7. **锚点更新事记**：golden 权重锚点 1.0 → 0.705（重算在 stateChanges 落账**之后**）；本棒三处测试预期自身错误（await import、层差数学、锚点算术、K6 窗口/计数）全部"机制对、预期错"，已修正并记。
8. **玩家棋子在 SSOT 无位置**（无 attrs 无分量，夹具实证）→ 玩家档案细案（入实体池 + 两条写权限规则 + 影响/兑现/衰减通道）。
9. **K5 减项如实登记**：方向相悖报警（需胜负裁定语义，薄裁定器只按量不产胜负——ANCHOR 未决点 3 之魂）；K4 挂起（观察者=玩家）。
10. **快照机制就绪、真跑未做**：capture-demo 可落 `snapshots/*.jsonl` 并转制为模型输出快照 fixture（锁言行，零成本）。
11. **status.js 零增量维护原则**（本棒定的工具哲学）：语义状态永远在文档（拍板/验收/挂起），脚本只聚合活事实——状态不会因忘改脚本而撒谎。
