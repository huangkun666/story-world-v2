## 3. 关键决策与实测发现（全部有台账行可查：L40-L49）

1. **评审裁决（L40）**：外部 AI 三条建议——除零守卫/边界连续性两案无事实基础（源码已守卫、min(1,ratio) 天然连续）；掩码加权和公式破坏锁定断言且让低分量观察者近事全瞎；但"观察者方向"问题成立：实施 m=src/obs 与细案句意（P-5"low weight→远事不可见"）相悖，且 obs→0 有"0.001 全见/恰 0 全瞎"断崖。
2. **掩码方向拍板 + 修边（L42）**：保留比值（相对显著性=实施即语义）；MASK.obsFloor=0.05 存在感门（clamp 后乘 min(1,obs/ε)，obs→0 连续趋 0，obs≥ε 原公式）；既有锁定断言零改动；ε 提案态随报批支线。
3. **K14 出生裁判（L41）**：gate 滤静默方 newAgendas（A-2 双面无痕）；spawnAgendas GC 三档上限（A-3）/落账 a_<tick>_<n>/编年挂因三型/父 promises 写（A-5 前半）；环检测自动拆（A-4）——**防御性实现**（发现：parentId 不可变 + K13 校验 ⟹ 同 tick 互指在契约层即拒，环现实不可达；防御不删）；子达成→父 done 兑现（A-5 后半）；提议并落账=活跃（与 gate 对称）；**K13 补差两处**（禁写玩家三通道完整：newAgendas.entity===playerId 拒绝；pack 在飞盘算含 parentId）。
4. **K15 三态终结（L43）**：判序=**变形优先托孤**（有在飞子→断链转独立+编年；子不悬挂死父）→败露（近 2 tick 负 δ ≥0.05 提案，编年"功败垂成"）→达成；实体 hurtWindow 惰性写（全 0 删字段，锚点零扰动）；兑现仅达成态；模型无直接终结通道不变式保持；**两笔执行债全清（promises/blocked 写入 + 满步败露/变形分支）**。
5. **K16 树冒烟（L44）**：smoke 统计扩展（maxPerTickBirths/peakTopLevel/rejectedTotal）；assertSmoke 切片断言能力化（新生应为 0→每 tick ≤2/顶层 ≤5）；K16 曲线如上；体积界 80KB（事件池无界=因果链阶段债，注释声明）。
6. **K17 + 真跑回填（L45/L46）**：capture 零改（record.step 全量含 newAgendas，契约随 schema 入档）；A-8 后半物证：newAgendas 真模型首现 ×12、live 8→0、红线 1 实战拦截 ×2、玩家被拍崩（影响通道+硬边界钳制再现）、坏账前置 1 条（K5 报警生效）、bystander 限流。
