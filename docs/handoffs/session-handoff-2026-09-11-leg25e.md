## 2. 四个真 bug（按发现顺序，全部已修 + 有回归锁）

### 2.1 `entries is not defined`（我写的）
点「开始新世界」直接报 `⚠ 初始化失败：entries is not defined`。
**根因**：我给 `autoComposeSource` 加"顺手带出真书条目"时写成 `res.worldInfoEntries = entries;`，而该作用域的真名是解构出来的 **`worldInfoEntries`**。
**为什么 473 条测试当时没抓到**：`autoComposeSource` **从没被测过**（要真 ST ctx，且未导出）——正是本棒反复踩的"接线断了而测试全绿"。
**修**：改名 + **导出 `autoComposeSource`** + 新增 `test/init-source-wiring.test.js`（注入 fake ST ctx + 卡内置书 + 最小 DOM 桩，真跑它）。**变异证红**：改回 `entries` → 当场红，报错与实机一字不差。

### 2.2 短名取不到长名正文（我写的，影响最大）
模型抽的名号常是**短名**，书条目名是**复合名**：canon `万妖盟` ↔ 书条目 `混乱之地·万妖盟`、`幽都` ↔ `鬼族幽都`、`大虞` ↔ `人族皇朝`。
我上一节加的"归一尺"只用在**验伪/推导**上，**没用在 `contentFor` 取正文**上 ⇒ `万妖盟` 取不到正文（打印实测 `contentLen=0`）⇒ 该组织**花名册根本建不起来** ⇒ **这 12 个组织的成员一个都挂不上**。
**修**：`contentFor` 走 `bookNameAlias`（精确优先 → 双向子串取最长）；`resolveCanonName` **并列时优先 kind=faction**（`人族皇朝` 的候选里有泛称 `人族`）。
**效果**：归属 **109 → 162**、档位 72→125、规模 48→65、有麾下的势力 16→26 个。

### 2.3 同一本书被读两遍（老洞，用户实报"怎么变成 50 万字了"）
```
旧：usedChars=499526  entryCount=424  truncated=true   ← 顶到 50 万防御上限，书尾被切
新：usedChars=301538  entryCount=228  truncated=false  ← 正好一份
```
**两个叠加的洞**：
1. `collectWorldInfoEntries` 把"卡内置 `character_book`（235 条）"与"ST 挂载世界书经 `loadWorldInfo`（235 条）"**直接 push 到一起**——旧注释只写"候选**世界名**去重"，**名去了重、条目没去重**；
2. `init-source.js` 的 `normalizeEntry` 取主键写成 `String(e.key ?? (Array.isArray(e.keys) ? e.keys[0] : undefined) ?? …)`，而 **ST 形状里 `e.key` 就是数组**（`["九宸玄陆","世界总纲",…]`）⇒ 变成一长串逗号连接 ⇒ 两路的行**不可能相同** ⇒ **去重交集实测 = 0**。
**修**：新增导出 `normalizeEntryKey(e)`（数组取首元素，两条路**同口径**）+ 收条目时按"主键+正文"指纹逐条去重。回归锁 `test/init-source-dedup.test.js`（4 条真函数测）。

### 2.4 「补全全册实力/位置」实际是空转（复验时发现）
`missingFields` 第一条判据是 `typeof entity[f] === 'string' && entity[f].trim()` ⇒ **占位值「未明」是 truthy 字符串 ⇒ 被当成"已有值"** ⇒ `位置` 永远进不了待查名单（真账 623/623 实体 `location='未明'`、有真位置 **0**）。
另：进度条 `0/623` 不动还有第二个原因——**世界只在 `MESSAGE_RECEIVED` 时推进**，批量借轮次跑 ⇒ 不发消息就永远 0（设计如此，但面板没说明）。
**未修**（见 §7）。

**判据三条**：① 能跑不崩 → ② **不共线**（缺形态只许"不生效"，不许"给错结果/整条停摆"）→ ③ 宁缺勿造。
**禁用清单**：把某本书的文本形态当**必要条件**、把**占位值当判据**、用**词表**判语义、拿**单本覆盖率**当有效性证据。
**唯一被实测证明通用的骨架**：① 书条目正文是唯一必需输入 ② **模型管语义** ③ **引擎管确定性校验（认/反驳/未验证三态）** ④ 形态判据只能加分。

**八本书实测（`demo/audit-mechanism-genericity.js`，可复跑）**：

|---|---|---|
| ① 成员行 → 归属 | **1/8**（只有大荒：324 行） | 静默不写 ⇒ **可用**（加分通道） |
| ② 位置继承 | **3/8** | 位置集退化时**全册位置写死「未明」** ⇒ **垃圾形态**（未修，见 §7） |
