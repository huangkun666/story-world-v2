## 0. 人话版：这会怎么样

你的世界一开局就是**全书实体站在棋盘上**（345 个名号全部入账、全都有分量），不再"开演前先淘汰 313 个"。
模型每轮看到的只是**镜头**——引擎按分量和点名情况每轮挑"该拍谁"（预算内自适应），没拍到的人照样在世界里活、照常被算账，
长期没戏份的退二线（背景化），被点名立刻回场（复归）——轮换算法还在，但它管的是**镜头进出**，不是**资格存废**。
大势也改真：张力照常有自己的一行，另外再给一行真·天下大势（张力+环境+浪尖拼装）。你点头即开工。

## 2. 机制

### C1 资格=入账：开局全量 + 势力净化折叠（编排+引擎层）

**原则（用户 2026-09-09 指令 + leg16/蓝图 §3.7/敲定稿 J 条续持）：全量资格，但势力必须抽象——不能 345 个名号拍平**
（用户原话：「旧插件抽象了 100+ 势力，大量势力互为父子。若都当独立实体：席位被碎片占满、父子同框行动违背常理、分量失真」——收敛=分支做归属限定+升格/降格通道+提取阶段净化折叠）。

- **角色类名号整量入账**（`e_bk_N` 连续编号；同名跳过、dead 不回魂保留）；
- **约束哲学（用户 2026-09-09 拍板）：提示词约束为主，代码只守诚实底线**——净化/折叠的形态纪律进抽取 prompt（项目先例：十三棒 ripples 铁律 8「模型行为类问题靠模板修，不开引擎洞」），引擎不做枚举规则（不搞后缀词表、不猜归属）：
  - 抽取 prompt 形态纪律：`kind` 三值 `faction|character|location`（洲/山/谷等**地名**归 location）；条目可选 `parent`（**书中明述**的上级才填：角色→所属势力、势力→上级势力；未明述不填）；无 `parent` 的势力一律独立入账（万妖盟 vs 妖师宫不靠猜并）；
  - 引擎净化（abstract）：形状净化照旧（非对象拒/字段类型/不可靠即拒绝）；防御性校验（location 不入池；parent 不在册→弃关系+警告；parent 自指/成环→拒+警告）——**不拒绝整包**，守诚实底线即可；
- **初始分量预填**：seed 时按 `computeWeight`（同 settle 口径含张力）为全部入账实体预填 `world.weights`（K7 教训：空权重首轮全员静默/误判）；
- 现状量级（导出世界实测）：345 名号 = 237 角色 + 108 势力（含 ~13 location 误标 + 若干变体系）→ 折叠净化后实体 ≈ 300±；
- **升格/降格通道（分裂/吞并 → 分支转主）与盘算 branch 归属限定 = 排期独立 K**（触发=折叠落地后；三家分晋/田氏代齐为历史原型）。

### C2 镜头=每轮视野（契约层 pack；容量=用户定案 30000 tokens）
- pack 实体段改为**镜头选择器**：按 分量降序 排列 + **例外保送**（本 tick 被点名者 ripples/target/落子对象、在飞盘算属主、近 2 tick 活跃者 置顶）→ **30000 tokens 内取最大前缀**（用户 2026-09-09 定案「现在的大模型绝对有这个能力」；`EVOLUTION_BUDGET_TOKENS` 4k→**30k** 提案改值，报批 #2 联改）；
- **主调用输出上限随幅改**：`max_tokens` 4096→**16384**（同模型同通道；抽取实证：思考型模型 finish=length 截断 @4096、stop 完整 @16384，L128）；
- 未被镜头拍到的实体：仍在账本、分量照常结算、可被事件点名、可被 gate 静默/应答——只是不进本轮 LLM 视野；
- 同口径纯函数 `lensList(world)`（引擎层只读）供渲染"本轮镜头"展示复用（一处定义、多处读取）。

### C3 轮换归位（引擎层 settle/gate）
- **删除「超席强制退」**（POOL_CAP 从 active 语义中移除）；
- **不设全量池顶**（用户 2026-09-09 否决 POOL_TOTAL_CAP=512：「设定上限会把重要的划掉」）——`spawnEntities` 删除超限拒分支（保留校验类拒绝：未知/重名/玩家/位置/源）；SSOT 增长由存储层（K35 冷档/导出）与观测台全册读数兜底；模型幻觉导致超量→**重新抽取重建**（管网已备）；
- 保留：**闲置退休**（连续 20 轮未活跃 + 影响力<0.05 → status=retired，账保留编年「淡出」）、**复归**（被落账点名 → retired 升 active）、**静默/应答门控**（gate 零改动）；
- 语义澄清（写进注释与文档）：**资格=在册**（除非覆灭裁定 dead）；轮换管的是**镜头在场与否**。

### C8 子势力（分支）机制（敲定稿 J 条落地；用户 2026-09-09「还要考虑到子势力的情况」）
- **形态 = 折叠不独立**：书明述隶属的势力名号 **不独立入账**，记入父实体分支表 `entities[].branches`（契约可选字段，平铺直属子名单；深链层级解析排期）；父实体依旧独立入账——分量不因拆子而失真（blueprint §3.7 分量失真之病根防复）；
- **身份链**：盘算增可选 `branch`（分支名，契约可选）——owner 仍是父实体，动作归属具体分支；同一父实体、异分支盘算之间的张力 = **派系暗斗（concealed 的天然舞台）**，蓝图 §3.7 语义落地；
- **子势力照常可行动**：分支名被点名/落子命中 → 视为所属父实体的点名（lifted 语义收拢到父）；分支成员（character.parent=分支名）随势力打包进「麾下成员」；
- **升格/降格通道（排期独立 K）**：分裂/吞并事件落账 → 分支升格为独立实体（承继协议=该分支盘算整体转主 + 人员 parent 重指）、或实体降格为分支——历史原型三家分晋/田氏代齐；
- **渲染**：势力页分支折叠展示（A-3 黑名单合规）。

### C7 实体关联：从属字段（契约层新增；用户 2026-09-09 提问"势力的行动该带上哪些角色"）
- 实体增可选 `parent`（**从属方单存，防双写漂移**）：character→所属势力/分支名 / faction→上级势力名；来源=`bookEntities.parent`（抽取明述）与 newEntities 提议可带 `parent`（校验=目标存在非 dead）；势力侧"麾下成员"=**派生反查**（直属 parent=实体名 ∪ parent∈branches 的分支成员，按分支分组），打包/渲染时扫取——不落第二份账；
- 打包：镜头的势力实体附「麾下成员」简表（含分支成员，按分量序取镜头预算内前缀）——**势力的行动（盘算/事件）天然知道该带哪些角色**；
- 渲染：势力页成员/分支折叠展示（A-3 黑名单合规）；角色卡显示所属势力；
- 触发语义排期（成员被点名→所属势力 lifted？）：随折叠落地后独立 K。

### C4 大势行 + 张力行并带（渲染层）
- **大势行（真·天下大势）**：确定性拼装一句——张力极/方向 + 强度带词（BANDS）+ 环境量危险带 + 浪尖（`derivedFrom` 解析 TOP 来源）——零创作零预测（ANCHOR「走向预测已裁」保持）；
- **张力行**：张力三件套（极/方向/强度）独立一行，不再顶「大势」之名；
- **实体页**：全册展示（345，分页/搜索）+ 「镜头在场」徽（lensList 口径实时名单）+ 计数文案「全册 N · 本轮镜头 M」；
- 暗处/黑名单 A-3 纪律照旧（引擎 id 只进悬停/管理区）。

### C5 观测台口径（引擎层 observatory，只读）
- `residencyStats` 改算**镜头名单内**驻留（新口径：镜头内闲置分位/摸鱼名单）+ 全册计数标注；
- 100t 实体池曲线重跑（345 起步基线），坏账重扫 0 断言保留。

## 3. 验收判据（可测）

## 4. 范围限制（本批不做）

- 小卡（E 条）/ 焦点公式（H 条）/ 日历+跳卷（G 条）/ 复归拉杆——二期药单不变，随读数放行；
- 池无界治理（无池顶后 SSOT 增长到极端量级时如何归档/淘汰）——触发=观测台全册计数读数异常（无硬顶，存储层兜底）；
- 升格/降格通道、盘算 branch 暗斗语义、成员点名→势力 lifted——独立 K 排期（折叠落地后）；
- 大势行的措辞风格库——先上确定性拼装版，措辞随真跑反馈迭代。
