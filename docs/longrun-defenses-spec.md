## 0. 人话版：这会怎么样

世界跑久了会撞上两堵墙：喂给模型的材料涨破上下文，存的账涨破磁盘。本细案给四个表面各装一道闸门——**输入、存储、记忆、成本**——每道闸门都不砍因果链：剪只剪文本，语义靠结构保住。冷历史搬出账本、里程碑当书签：玩家该看到的全看得到，模型该读的永远装得下，每回合花的钱严格线性。所有数字都是提案，先经合成跑出曲线，再拍板。

**总原则：剪枝只砍文本，不砍语义；归档割断的是喂给 LLM 的文本，不是链条本身。**

## 2. 设计

### 2.1 A 输入有界：演化上下文包

1. **预算常量**（提案）：世界步原料 ≤ **4k tokens**；提取输入 ≤ **2k tokens**。
2. **固定打包序**（超限剪枝可预测的前提）：活跃实体简表 → 在飞盘算（含 memory）→ 未决事件 → 最近 2 tick 关闭事件 → 玩家落子事实 → 大势当前值。
3. **固定剪枝序**（超限时按序砍，只砍文本、留标题与指针）：最近 2 tick 事件详情 → 未决事件详情 → 在飞盘算步骤细节（留摘要 + 进度）。
4. **被砍语义**由 §2.3 的 memory / 里程碑承接——不消失，只是不在输入里。

验收：合成冒烟断言"序列化后的世界步原料恒 ≤ 预算"。

### 2.2 B 存储有界：SSOT 有界化 + 三层编年

- **热层**：SSOT 内，事件链全量保留最近 **20 tick**（提案）。
- **温层**：每 **10 tick**（提案）把一段链压成一条**里程碑摘要**（一次小调用，只读热层尾部）；摘要本身是链上节点，带上下游指针；**用户阅读历史的默认粒度 = 里程碑，点开才展开原始条目**（§4.3 的"前端全量展示"是给工程的，不是给人的）。
- **冷档**：SSOT 外，每 **500 tick 或累计 5MB** 轮转一卷（提案）；SSOT 内只留跨库指针；因果链可沿指针跨库回溯，不断。

理由：SSOT 的账目原则（只记"算分量、驱动棋局、支撑窗口"要用的，复盘结论 3）支持把冷历史赶出账本——它已不服务于三个用途。

验收：100 tick 合成跑后 SSOT 字节增长趋缓、冷档至少轮转一卷、任取一个归档事件可沿指针回溯到链。

### 2.3 C 语义保鲜：记忆自动化 + 熵泵三件套

**agenda 记忆由引擎维护，不由 LLM 生成。** 每条盘算带 `memory = {约定, 已兑, 受阻, 转折} + turns_alive`；来源 = 因果链上的关联事件节点（约定=关联事件、兑现=关联合约）；模型只产生事件，不生成记忆；归档时原文被里程碑替代，引用仍可达。理由：模型不可信于记忆——幻觉记忆比遗忘更糟；与"账吃对话、对话不改账"同一哲学；可回查。

熵泵三件套：

1. **增量 Mutation**（已定，实施）：事件必须带数值增量，校验不过 = 坏账，引擎落账时应用——写叙事不写状态视为坏账。
2. **静止衰减**（跟分量引擎一起做）：连续 N tick 无动作 → 分量按比率衰减。提案：人物层 **8 tick / 每 tick -2%**，宏大层 **20 tick / -1%**。**玩家棋子同尺**——站桩，权力照萎缩。
3. **摩擦制造**（跟设定大势层一起做）——**缝在此闭合**：环境量由**引擎**小步推（提案：每 3 tick 一次），越阈值时引擎按 §4.2 **状态驱动**落一条事件（醉话说漏嘴、劳役征发）；模型从头到尾不发明任何东西。熵泵不是第三来源，是状态源事件的引擎发生器。

闭环检查：摩擦事件 → 新处境 → 新盘算诞生挂因（§4.4）→ 世界不冷却；§4.3 生半（≤2/回合）限制速度，不限制来源。

验收：① 40+ tick 盘算的 memory 含第 12 tick 约定引用；② 静止实体分量单调衰减；③ 冒烟期间存在非模型生成的状态源事件注入。

### 2.4 D 成本纪律

1. **调用次数固定**：每 tick = 1 提取 + 1 主调用；归档只在翻页 tick 发生（+1）。调用次数与回合数严格线性。
2. **双预设分工**（复用旧设置）：提取/归档 → flash 级；主调用 → 旗舰级。
3. **世界步异步化**：RP 回复先回给用户，提取 + 主调用 + 结算后台执行，结果经**下一轮注入送达**（对齐 §4.7 时差规矩——本条本来就是异步契约，这里对齐执行结构）。调用失败：重试一次；仍败 → 记台账，世界此 tick 如实不动。
4. 成本曲线 = O(回合数) × 常数；不爆炸的保证 = §2.1 输入有界 + 本条有界调用。

验收：台账成本字段恒等于预期公式（与回合数线性）。

### 2.5 E 度量告警

- **每 tick 台账四字段**：演化上下文 tokens / SSOT 字节 / 热·温·冷规模 / 调用 tokens 与耗时。
- **合成冒烟常设化**（切片 S7 升级为常设工具）：合成 100 tick，断言四件事——输入恒在预算内、存储增长在归档后趋缓、分量不发散（衰减 + 熵泵下仍在合理域）、agenda 寿命分布正常。
- **衔接铁律 5**：GC 数字、热层 N、预算常量等**所有**提案，报批时附本曲线。
