## 3. 版式规格

### 3.1 行（三列）

```
┌──────────────┬────────────────────────────────┬────────────────────────────────┐
│ 名号          │ 归属与来历                      │ 在办的事                        │
├──────────────┼────────────────────────────────┼────────────────────────────────┤
│ 楚星河 角色    │ 天璇圣地 · T6化神中期            │ 借大荒劫气磨砺无上剑心 · 跨洲斩邪 1/5 │
│ 慈航医堡 势力  │ 规模 长城上唯一的医修结社 · 游走于  │ 筹备物资前往大荒边缘遏制死煞瘟疫   │
│              │ 死亡边缘的提灯人 · 不修杀伐…      │ 死守孤城 4/5                    │
│ 黄坤 角色      │ 无来历记载                       │ 击碎死煞绝阵并向薛铁衣复仇 · 殊死一搏 3/4│
└──────────────┴────────────────────────────────┴────────────────────────────────┘
```

- **名号格**：名（600 字重）· 类别（小字）· 状态徽（仅 `retired`/`dead` 时出现）
  ★ **玩家标记不进新行**（原版靠 `.sw2-player` 底纹 + 关系区那句"你的每一步从对话里来。"；后者已按"空态不占版面"退场，
  玩家那一行改由**归属与来历 + 在办的事**自证，判据 J11 锁"不许搬回来"）
- **归属与来历格**：**同源的一串事**，顺序 = 归属（谁的人）→ 实力（97.5%）→ 规模（势力）→ 性质 → 倾向；` · ` 分隔，两行后截断（`-webkit-line-clamp:2`）
- **在办的事格**：只有真在办才有字（`goal · stage 进度/上限`，暗牌带「暗」）；**没有则整格留白**
- 列宽：`212px / minmax(0,1.3fr) / minmax(0,1fr)`，gap 16px，行 padding `7px 12px`
- 在办行加左侧 2px 金色标记 + 底色微亮（`hot`）

### 3.2 工具条（两行，sticky）

- **第一行**：搜索框（flex:1，最小 180px；带 `aria-label` + `enterkeyhint="search"`）+ 类别 chip（全部/势力/角色）+ 筛选 chip（只看在办 13 / 最近动过的 24 / 有名有姓的来历 218 / 无来历记载 403）+ **计数口径钮** + 分组下拉（不分组 / 按归属 / 按位置 / 按类别）
- **第二行**：排序下拉（在办优先 / 最近活跃优先 / 按名号）+ 命中计数（`命中 N / 621　显示第 a–b 条`）
- 分页：一屏 **60** 行，底部「‹ 上一页 / 第 x / y 页 / 下一页 ›」
- ★**计数口径钮**（终审 I1 加，`data-action="ents-scope"` + `data-value` 两态）：chip 上那个数读**哪个口径**——
  「**是全部人名册的数**」（不随筛选变）还是「**当前结果里点它会得到多少**」（与页脚印的「命中 N」同一套数）。
  标签**如实写当前口径**（`计数：全册` / `计数：当前结果`），点一下切到另一个。★为什么非加不可：
  两个口径的数原先**同屏并列**（chip 印全册 621/103/518，页脚印「命中 4」）⇒ 玩家会以为筛选坏了。
  ★`'hit'` 口径的算法**复用 `selectEntityPage` 同一条筛选管线**（`entsRows`）——类别钮 = 把类别那一维换成它的值、
  筛选钮 = 在当前条件上加上这一条；**没有第二份计数实现**。

### 3.3 搜索口径（★这条是"位置不占列"的补偿，不许省）

**位置不占列 ≠ 位置被删**。搜索必须覆盖：`名号 ∪ 归属 ∪ 位置 ∪ 实力 ∪ 规模 ∪ 性质 ∪ 倾向 ∪ 机构`。

### 11.4 ★★ 本笔犯过的错（**这一格比上面所有数字值钱**）

#### 一、构建号踩了**同一颗雷**：与共享禁词锁对撞，而构建号恰在玩家视线内

细案初稿把构建号钉成 **`leg49-entities-three-cols`**——含 `entity`，而 `test/render.test.js` 的
