# assets/ · README 的图

## 这里现在是什么

**三张占位图**（不是真机截图）。它们的作用只有一个：让 README 立刻有版面，
并且把「该拍哪三张、放哪个文件名」写死在图上，**你拍完按同名覆盖即可，README 一个字都不用改**。

> ⚠ **别拿 `docs/*-mockup.html` 渲染出来当截图**。那几份是**设计稿**，页签还是 5 页那一版
> （现在是 8 页：观棋 / 编年 / 大事纪·旧卷 / 角色与势力 / 设定 / 参数 / 快照 / 设置）
> ⇒ 拿它当"界面一览"就是拿一张过期的东西当现状，**本仓纪律不许这么干**（见 `README.md`「它没做什么」）。

## 要拍的三张

| 文件名（**必须同名覆盖**） | 拍哪一页 | 画面里要有什么 |
|---|---|---|
| `shot-1-observatory.png` | **观棋** | 世界近况列表 + 一条点开的故事（当封面用） |
| `shot-2-chain.png` | **编年** | 点事件上的「？」展开的**因果链**（上游怎么来的、下游牵动了谁） |
| `shot-3-params.png` | **参数** | 世界尺度那排旋钮 + 最上面那张「插件总闸」卡 |

### 拍摄口径

- **先硬刷新**（`Ctrl+Shift+R`），并以「参数」页最上面那行 `构建 …` 为准 —— 面板是静态副本，普通刷新会拍到旧版。
- 窗口点 ST 输入栏左边的**魔杖图标** → 「观棋窗口」。
- **宽度 ≥ 1000px**（窄屏会走手机档版面，拍出来是另一套样式，不适合当封面）。
- 拍之前**先把世界跑起来**（总闸开着推几轮），空账的面板没东西可看。
- 深色底、别裁太紧：留一点面板边框，比贴边的截图好看。
- 存成 **PNG**。宽度 1200 左右、单张控制在 **300 KB 以内**（仓库体积）。

### 换完之后

```bash
node --test                      # 判据不受影响（assets/ 不在任何判据的扫描面里）
node scripts/audit-docs.mjs      # 文档守门也不看 assets/（它只清点 docs/）
```

两条都**不该因为换了图而变红**。若真红了，说明动到了别的东西，不是这三张图。

## 为什么单独开一个 `assets/`

不放进 `docs/`：`scripts/audit-docs.mjs` 会清点 `docs/` 的文件数与字节数并与 `docs/index.json` 对账
（守门 R3），往里塞图片会让那份生成物过期、把推送拦下。`assets/` 在它的扫描面之外，放图零副作用。
