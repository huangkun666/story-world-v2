# 界面素材说明

本目录的三张 PNG 当前为占位素材，不是真实宿主截图。README 不将其作为功能、性能或验收证据。

| 文件 | 后续对应的实际画面 |
|---|---|
| `shot-1-observatory.png` | 当前状态总览与展开的事件进展，实际入口为「观棋」 |
| `shot-2-chain.png` | 事件来源和后续影响，实际入口为「编年」中的因果链 |
| `shot-3-params.png` | 运行开关、模型输入与显示范围的参数 |

替换素材时使用同名 PNG，记录实际版本、构建、宿主及视口。桌面截图和窄屏截图分别标注，不将模拟视口当作手机真机，不用历史 HTML 设计稿替代当前实际界面。

截图前先硬刷新，使用有实际数据的场景；公开前检查聊天正文、资料、接口地址与凭据。图片尺寸和压缩以清晰可读为准，不以缩小文字隐藏布局问题。

素材放在 `assets/`，技术设计与验证记录放在 `docs/`。真实截图只证明该画面，不证明连续操作、内存或跨设备体验已通过。
